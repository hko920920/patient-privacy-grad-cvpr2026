# Legacy ZKP Notes (RISC0/Halo2/ICICLE)

This folder contains historical notes for the retired RISC0/Halo2/ICICLE paths.
The current pipeline is SP1-only and exposes separate Detect (statistical
signal) and Attest (trusted key + exact artifact + P1--P4 receipt + Detect)
verification levels. To run a legacy backend, pass `--allow-legacy-backend` to
the CLI.
