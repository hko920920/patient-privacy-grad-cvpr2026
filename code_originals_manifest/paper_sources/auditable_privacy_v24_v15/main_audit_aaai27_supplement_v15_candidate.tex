\section{Scope, Authority, and Reading Guide}
\label{sec:supp-scope}

This supplementary material supports the main paper without expanding its claim authority.
Here DP denotes differential privacy and DP-SGD denotes differentially private
stochastic gradient descent.
The main paper contains the contribution, essential proposition, primary
results, limitations, and closest-work boundary.  This document gives
the longer proof, executable contract, complete coverage/operator matrices
with machine-readable case lineage, retrospective lineage, both executed
routes, all mapping policies, and the exact reproduction surface.  A number appearing here is a
privacy result only when an executed mechanism, runtime, registered
accountant, transformation proof, and requested wording are all bound.  The
Sepsis and Backblaze sections intentionally stop at mapping diagnostics.

The primary object is the post-execution decision
$V_{\mathcal R}(E,q)$: whether frozen evidence $E$ licenses the requested
sentence $q$ under finite registered semantics $\mathcal R$.  The group
conversion is one rule inside that decision, not a new theorem; the output is
neither a new accountant, a design-time mechanism compiler, nor a proof of
arbitrary source code.  Lemma~1 and five fixed deletion witnesses establish
only query and information necessity on this restricted contract; they do not
establish universal minimality or that prior audit engines cannot host the
same rules.

The implementation calls its JavaScript Object Notation (JSON) and Markdown
outputs ``certificates'' in a
few historical filenames.  Scientifically, the public object is a
\emph{non-cryptographic claim-validation report}: hashes expose accidental
inconsistency and staleness, but they do not prove that an evidence producer
disclosed every dependency or executed the described code.

\section{Formal Model and Detailed Proof}
\label{sec:supp-formal}

\subsection{Raw and Generated Adjacency}

Let $\mathcal{D}_R$ be the raw-data domain and let $d_R$ be the shortest-path
metric induced by the requested raw adjacency.  A raw neighboring pair
satisfies $d_R(D,D')=1$.  Let a deterministic transformation
$T:\mathcal{D}_R\rightarrow\mathcal{D}_G$ construct the generated records
consumed by a randomized mechanism $\mathcal{M}$.  The generated metric $d_G$
is likewise the shortest-path metric induced by the accountant adjacency.
For example, an add/remove accountant has distance one when one generated
record is inserted or deleted.

For a generated record $w$, the exported mapping gives its stable identity,
raw-event support $S(w)$, and owner-attribution set $A(w)$.  On a selected
mapping, define
\[
\begin{aligned}
  n_e(e)&=\left|\{w:e\in S(w)\}\right|,
  &\ke&=\max_e n_e(e),\\
  n_o(u)&=\left|\{w:u\in A(w)\}\right|,
  &\ko&=\max_u n_o(u).
\end{aligned}
\]
They summarize one materialized mapping.  A valid stability value instead
upper-bounds
\[
  K^\star=\sup_{d_R(D,D')=1}d_G\!\left(T(D),T(D')\right).
\]
Equality between an observed incidence and $K^\star$ requires a registered
argument covering identities, selection, preprocessing, population,
schedule, and every private branch.  The validator never infers that equality
from the scalar incidence alone.

\subsection{Contract-Relative Consequence}

\paragraph{Proposition 1 (expanded).}
Fix a requested raw unit, $d_R$, and a positive integer $K$.  Assume:
\begin{enumerate}
\item the supplied evidence faithfully describes a deterministic
  transformation $T$ and the executed randomized mechanism $\mathcal{M}$;
\item a registered checker establishes
  $d_G(T(D),T(D'))\leq K$ for every pair with $d_R(D,D')=1$; and
\item a registered accountant establishes that the bound execution of
  $\mathcal{M}$ is $(\varepsilon,\delta)$-DP for generated distance one under
  $d_G$.
\end{enumerate}
Then $\mathcal{M}\circ T$ is $(\epsK,\delK)$-DP for the requested raw
adjacency, where
\begin{equation}
  \epsK=K\varepsilon,\qquad
  \delK=\delta\sum_{i=0}^{K-1}\exp(i\varepsilon).
  \label{eq:supp-group}
\end{equation}
If $K=1$ and the requested and accounted unit, adjacency, and mechanism metric
coincide, the base pair may be reported on the \Direct{} path.

\paragraph{Proof.}
Take arbitrary $D,D'$ with $d_R(D,D')=1$.  By assumption 2 and the definition
of a shortest-path metric, there is a sequence
\[
  G_0=T(D),G_1,\ldots,G_m=T(D'),\qquad m\leq K,
\]
where every consecutive pair is generated-adjacent.  For a measurable output
event $\mathcal{O}$, apply assumption 3 repeatedly:
\begin{align*}
\Pr[\mathcal{M}(G_0)\in\mathcal{O}]
&\leq e^\varepsilon\Pr[\mathcal{M}(G_1)\in\mathcal{O}]+\delta\\
&\leq e^{2\varepsilon}\Pr[\mathcal{M}(G_2)\in\mathcal{O}]
      +\delta(1+e^\varepsilon)\\
&\ \ \vdots\\
&\leq e^{m\varepsilon}\Pr[\mathcal{M}(G_m)\in\mathcal{O}]
      +\delta\sum_{i=0}^{m-1}e^{i\varepsilon}.
\end{align*}
Both terms are monotone in $m$ for $\varepsilon,\delta\geq0$, so replacing
$m$ by $K$ yields Equation~\eqref{eq:supp-group}.  Repeating the argument in
the reverse direction gives the symmetric neighboring relation required by
DP.  Finally, assumption 1 identifies the released random variable with
$\mathcal{M}(T(D))$. \hfill$\square$

The proposition is deliberately conditional.  It is the standard group
consequence of a verified path, not a new group-privacy theorem and not proof
that evidence bytes are truthful.  The validator's contribution is deciding
whether a concrete bundle establishes all three premises for one requested
sentence.

\subsection{Query Separation}

\paragraph{Lemma 1 (expanded).}
Fix registry $\mathcal R$ and evidence $E$.  If
\[
V_{\mathcal R}(E,q_1)\ne V_{\mathcal R}(E,q_2),
\]
then no query-oblivious map $A(E)$ is exact and query-responsive on both
requests.

\paragraph{Proof.}
Because the evidence input to $A$ is identical for $q_1$ and $q_2$, a
deterministic $A$ returns one common tuple.  That tuple cannot equal two
distinct licensed results.  For randomized $A$, exactness requires its output
law to be a point mass at each licensed result, but the query-oblivious input
induces the same law for both requests; two distinct point masses cannot be
equal.  A common positive tuple is therefore wrong for at least one query,
while common abstention loses any allowed query. \hfill$\square$

The lemma does not say that a generic audit or policy engine cannot accept
$q$.  Such an engine can implement $V_{\mathcal R}$.  It says that $q$ cannot
be removed from an exact interface when the requested adjacency changes the
licensed tuple.  The fixed Wireless Sensor Data Mining (WISDM) evidence
provides a concrete witness:
window yields \Direct{}/\Allowed{}/$K=1$, event yields
\Convert{}/\Allowed{}/$K=4$, and owner yields
\Group{}/\textsc{Blocked-Vacuous}/$K=600$.

\subsection{Why Fixed-Slot Replacement Costs a Factor of Two}

\paragraph{Corollary 1 (replacement to add/remove).}
Suppose the raw adjacency replaces the value in one fixed event slot, the
generated record identities are fixed independently of that value, and the
registered local transformation checker establishes that at most $\ke$
generated slots can change.  If $d_G$ is generated-record add/remove distance,
then
\[
  d_G(T(D),T(D'))\leq 2\ke.
\]
Thus $K=2\ke$ is a valid candidate bound under these premises.

\paragraph{Proof.}
For every affected stable identity, changing the generated record value is a
replacement in the generated multiset.  A replacement can be realized by
removing the old record and adding the new record, hence has add/remove
distance at most two.  At most $\ke$ identities are affected, so concatenating
these paths costs at most $2\ke$. \hfill$\square$

The result explains the central non-overlap pitfall: $\ke=1$ implies candidate
$K=2$, not \Direct{}, for the stated replace-one/add-remove metric pair.
Non-overlap removes repeated incidence but does not align the two adjacency
metrics.  A same-number event statement would require an exactly matched
metric, a native event mechanism, or another registered derivation.

The premises are as important as the arithmetic.  If labels choose which
windows survive, global normalization changes every record, validation loss
changes the schedule, or a replacement changes record identities, observed
$\ke$ does not bound the resulting transformation.  Such a bundle is blocked
before numerical conversion.

\subsection{Owner Routes Are Adjacency-Specific}

For a fixed owner-partitioned mapping and raw \emph{owner add/remove}
adjacency, removing one owner deletes at most $\ko$ generated records, so the
candidate generated add/remove distance is $K=\ko$.  This is the WISDM owner
route.  It is distinct from fixed-slot event replace-one, where the factor two
applies.  If the owner query itself is replace-one, if records have multiple
owners, or if removing one owner changes other owners' selected records, the
built-in owner-partition checker is inapplicable; a registered relational
analysis is required.

\subsection{Stable Numerics and the Vacuity Gate}

For $\varepsilon>0$, Equation~\eqref{eq:supp-group} can be written as
\[
  \delK
  =\delta\frac{\exp(K\varepsilon)-1}{\exp(\varepsilon)-1}.
\]
Direct evaluation overflows for large $K$.  The implementation therefore
computes
\[
  \log\delK
  =\log\delta+
   \operatorname{logexpm1}(K\varepsilon)
   -\operatorname{logexpm1}(\varepsilon),
  \label{eq:supp-logdelta}
\]
with the exact $\varepsilon=0$ limit $\delK=K\delta$.  A converted pair is
public only when both values are finite, $\epsK\geq0$, and
$0<\delK<1$.  If $\delK\geq1$, the route and diagnostic may be retained
internally but the release status is \textsc{Blocked-Vacuous}, the public
epsilon/delta fields are absent, and no positive sentence is emitted.

For the WISDM owner query, observed incidence 565 only verifies compliance
with the precommitted public cap $K=600$.  The conversion therefore gives
diagnostic $\epsK=322.096434700$ and
$\log_{10}\delK=134.033097$.  This is far beyond the reportable domain.
Clamping the displayed delta to one is not a privacy result; it is only a
serialization guard accompanying a blocked decision.

\subsection{Decision Procedure}

\begin{algorithm}[t]
\caption{Evidence-to-wording validation for one query}
\label{alg:supp-validator}
\begin{algorithmic}[1]
\REQUIRE report $R$, audit row $A$, mapping file $M$, query $Q$
\STATE Parse with JSON Schema and stricter domain checks.
\IF{types, finite-value domains, units, or required fields are invalid}
  \RETURN \textsc{Blocked-Invalid} without positive wording
\ENDIF
\STATE Reopen $M$; recompute full/selected hashes, row count, unit,
identities, intervals, attribution, $\ke$, and $\ko$.
\STATE Compare recomputed values with $A$, $R$, and all bound artifacts.
\STATE Validate influence completeness, identity, preprocessing, population,
contribution, schedule, selection, and model-selection declarations.
\STATE Match the runtime trace to mapping/pipeline digests and every executed
sampler, clipping, noise, unit, accountant, and secure-mode field.
\STATE Resolve mechanism and accountant ids in the versioned registry;
recompute the base pair.
\STATE Resolve the requested unit route and registered stability method;
derive $K$ in the accountant metric.
\STATE Recompute $(\epsK,\delK)$ when conversion is required.
\STATE Apply issue precedence, assurance rules, and the vacuity gate.
\STATE Redact operational metadata without changing the decision.
\RETURN typed public report; emit supported wording iff release is
\textsc{Allowed}.
\end{algorithmic}
\end{algorithm}

Schema validation is necessary but insufficient.  The implementation rejects
Boolean values in integer fields, non-finite JSON numbers, probabilities
outside their domains, and strings that pass a loose structural schema but
not a registered semantic domain.  It then reopens the mapping rather than
trusting $\ke$, $\ko$, counts, or digests copied into the report.

Private dependencies are fail-closed.  Record-local preprocessing with public
parameters is compatible with the built-in path.  Private global statistics,
label-dependent selection, adaptive schedules, and uncovered model selection
must be public, separately accounted through a registered graph, or covered by
a registered worst-case bound.  An observed branch or a user-supplied
``union'' label is not such a bound.

The positive-path registry shared by the complete routes contains Opacus
1.6.0 R\'enyi differential privacy (RDP) semantics with Poisson add/remove
adjacency and the exact
\path{secure_systemrandom_dpsgd@2.0.0} mechanism.  It binds rational
Bernoulli sampling, the \path{python.secrets.SystemRandom} backend,
discarded-first four-draw Gaussian generation, clipped-gradient sum plus
noise, and a public constant optimizer step with no dataset-size denominator.
The pipeline source and dependency-light accountant checker are separately
hash-bound.  This configuration is labeled
\texttt{known\_attack\_hardened\_secure}: it mitigates a named
floating-point reconstruction class but does not prove
side-channel resistance or faithful execution.  Unknown adapters are
default-deny, and missing runtime observation is
\textsc{Blocked-Unverified} for a concrete-run claim.  A research pseudorandom
number generator (PRNG) preserves numerical diagnostics but produces
\textsc{Research-Only}.

\subsection{Status Product and Precedence}

The result is a product rather than one Boolean:
\[
  (\text{unit path},\text{release},\text{assurance},
    K,\varepsilon',\delta',\text{issues},\text{wording}).
\]
The unit path is \Direct{}, \Convert{}, \Group{}, or \Under{}.  The release
status is \Allowed{}, \textsc{Blocked-Invalid},
\textsc{Blocked-Unverified}, \textsc{Blocked-Vacuous}, or
\textsc{Research-Only}.  Assurance is exactly
\texttt{EVIDENCE\_VALIDATED}, \texttt{EXTERNAL\_UNVERIFIED}, or
\texttt{DIAGNOSTIC\_ONLY}.  The first means that every observable registered
obligation, including a content-bound runtime trace, passes; it remains
conditional on evidence fidelity and is not an attestation label.

When several issues apply, the implemented precedence is
\[
\begin{array}{c}
\textsc{Blocked-Invalid}>\textsc{Blocked-Unverified}\\
{}>\textsc{Blocked-Vacuous}>\textsc{Research-Only}>\textsc{Allowed}.
\end{array}
\]
An external attachment cannot override an unrelated runtime or mapping
failure.  A blocked internal result may retain diagnostics, but the public
view has an empty supported sentence and an explicit ``do not say'' field.
Redaction can remove private provenance; it cannot improve release or
assurance status.

\subsection{Artifact Invalidation and Complexity}

Changing any decision-relevant edge invalidates the old report.  Triggers
include mapping bytes or scenario, selected identities, preprocessing,
population or schedule, contribution policy, mechanism or accountant version,
runtime parameters, requested unit or adjacency, and conversion method.  A
fresh public view is produced from the same internal decision; it is not
independently editable.

Let $B$ be mapping bytes, $R$ all rows, $S$ selected rows, $A$ all
owner-attribution entries, and $P\leq2A$ interval endpoints.  The materializing
implementation hashes in $O(B)$, parses and validates in $O(R+A)$,
canonicalizes the selected mapping in $O(S\log S)$, computes owner incidence
in $O(A)$, and computes exact event incidence by per-owner endpoint sweeps in
$O(P\log P)$ worst case.  Memory is $O(R+A)$.  Registered accountant cost is
additional.  The Backblaze artifact uses a specialized aggregate rescan and
is never passed off as a FULL validation report.

\subsection{Threat Model and Bundle-Only Limit}

The validator targets an honest-but-fallible producer: stale exports,
accidental omissions, mismatched configurations, unjustified unit
restatement, and copy errors.

\paragraph{Proposition 2 (unauthenticated bundle indistinguishability).}
Let $A$ be any deterministic or randomized validator whose entire observation
is a self-reported evidence bundle $E$, query $q$, and registry $\mathcal R$.
Let $w_f$ be a world in which $E$ faithfully describes the transformation and
execution, and let $w_c$ be a world in which a producer copies the same
observable tuple $(E,q,\mathcal R)$ but executes different code, executes
nothing, or hides a dependency.  Then
\[
  \mathsf{Law}\!\left(A(E,q,\mathcal R)\mid w_f\right)
  =
  \mathsf{Law}\!\left(A(E,q,\mathcal R)\mid w_c\right).
\]
Consequently, no bundle-only validator can establish evidence fidelity or
distinguish these two worlds.

\paragraph{Proof.}
Conditioned on either world, $A$ receives the same bit strings and registry.
A deterministic $A$ therefore returns the same value.  For randomized $A$,
couple its internal coins identically; its outputs are equal for every coin
sequence, hence their distributions are equal. \hfill$\square$

Proposition~2 is a boundary result, not a claimed cryptographic contribution.
The implementation can expose inconsistent, incomplete, or stale artifacts,
but a mutually consistent fabrication remains outside its threat model.
Accordingly, \texttt{EVIDENCE\_VALIDATED} denotes observable-contract
validation conditional on faithful evidence, never execution attestation.
Authenticated runtime observation, trusted hardware, formal program
verification, or cryptographic execution proofs add information that breaks
the proposition's identical-observation premise and address stronger threats
\citep{zhang2017lightdp,wang2019shadowdp,wang2020checkdp,shamsabadi2024confidential}.

\section{Evaluation Protocol and Expanded Results}
\label{sec:supp-evaluation}

\subsection{Frozen Oracle and Shared Inputs}

The designed conformance study contains 100 allowed and 100 paired non-allow
cases.  Allowed cases cross five registered path strata, five boundary/scale
levels, and four mapping-evidence contexts.  The contexts use canonical or
irregular half-open supports, add non-selected decoy rows, or permute file
order while preserving selected semantics.  Twenty-five frozen semantic
mutation operators each consume four distinct allowed parents, so every
allowed parent is used once.  Expected tuples come from the frozen operator
catalog and 37-row normative table rather than FULL output.  Every case stores
its path, release/assurance statuses, primary issue, numerical rule, direct
mutation, derived rebinding, and parent.  This localizes omitted obligations;
it does not estimate the frequency of mistakes in published work.

Within each case, every controlled probe receives the same report, audit row,
mapping, and requested claim.  A \emph{non-allow positive} is \Allowed{} on one of the 100 non-allow
cases.  \emph{Valid exact} requires the correct path and numerical pair on an
allowed case.  \emph{Exact tuple} additionally requires assurance, blocked
subtype, and the correct presence or absence of numbers.  \emph{Wrong
same-number} records a converted allowed case that incorrectly reuses the base
pair.  Main-table fractions divide these counts by 100 allowed, 100 non-allow,
or all 200 cases as appropriate; they are deterministic coverage outcomes,
not statistical estimates.

The probes are required-field presence (B0), JSON Schema (B1),
multiplicity-only (B2), mapping-hash binding (B3), registered base-accountant
recomputation (B4), runtime evidence assumed matched to the current static
report (A1), FULL without the vacuity gate (A2), and FULL.  A1 does not repair
mapping, schema, mechanism, accountant, or other static premises.  These are
nested obligation probes, not claims that any one scalar check was designed
as a complete validator.  They are information/capability projections, not
implementations or approximations of National Institute of Standards and
Technology (NIST) validation, estimate-verify-release (EVR), Audit-as-Code, or
public-audit federated learning (FL).

\subsection{Retrospective Development-Failure Lineage}

Before construction, a hash-frozen protocol fixed the inclusion rule and ten
root causes.  An incident had to predate the protocol, affect claim-bearing
output, remain byte-observable in a preserved source/report/archive, and have
a pre-protocol discovery record; newly authored mutations were ineligible.
For each incident the lineage binds the historical source or ZIP member,
discovery anchor, consequence, repaired-control source, and current status.
A production-import-free verifier reopens every file and archive member,
authenticates all discovery anchors and 16 repaired controls, and passes
\AuditRetrospectiveCheckCount/\AuditRetrospectiveCheckCount{} checks.  Three
tamper tests accept the frozen lineage and reject an omitted incident and a
forged archive identity.

This evidence addresses dependence on newly authored mutations by adding
actual preserved failures, but only from this system's development lineage.
It is not an independently sampled paper corpus, does not estimate
prevalence, and does not establish that the ten categories are complete.

\subsection{External Scalar-Statement Scope Comparison}

B5 executes TensorFlow Privacy 0.9.0's official
\path{compute_dp_sgd_privacy_statement} implementation
\citep{tensorflowprivacystatement}.  The environment pins
\texttt{dp-accounting==0.4.3} \citep{dpaccounting043} and hashes the loaded official module.  The
function correctly generates a conditional statement from caller-supplied
scalars; it does not authenticate an arbitrary mapping, pipeline, or runtime.
Accordingly, ``unvalidated positive'' means only that substituting this scalar
statement generator for the evidence validator leaves an external-bundle
contradiction undetected.

This 23-case scalar-compatible comparison is separate from the 200-case
controlled-probe table.  It has a different input contract and numerical
convention, so it is not assigned an exact-tuple rank against FULL; its
15/16 ``unvalidated positive'' count is not an error rate.

The comparison preserves the official function's own numerical convention.
For group statements it can solve for a smaller example-level delta and
freshly target user-level delta.  Those values are not required to equal
Equation~\eqref{eq:supp-group} applied to the fixed base pair.  In the frozen
owner-vacuity case, this yields a finite conditional alternative; FULL would
need a registered, execution-bound adapter for that alternative before
licensing it.

\subsection{Complete WISDM Execution}

The WISDM pipeline uses the public WISDM v1.1 raw accelerometer file
\citep{kwapisz2011activity}.  A public sorted-owner split assigns owners
1--25 to training and 26--36 to testing.  It creates length-200 windows at
stride 100, yielding 7,304 training and 3,506 test records.  All transforms
are record-local with public parameters: sensor values are clipped to
$[-20,20]$ and scaled, each axis and magnitude receive mean, standard
deviation, minimum, and maximum features, and the label is the within-window
majority activity with a lexical tie break.  The split, activity map, feature

\section{Validated Scope and Extension Boundary}

remaining trust boundary: authenticated observation or execution proofs are

and execution are in scope.  The evaluated adapters cover the reported

cross-mechanism generalization require additional independent submissions and
mechanism families.
