# Unit-coupled diffusion noise diagnostics

This directory starts a mechanism class separate from the retired PCM/timestep-allocation branch.

- `NIH_CXR14_UCAN_PUBLIC_DIAGNOSTIC_PROTOCOL_V1.md`: outcome-blind public X-ray gate.
- `coupling.py`: deterministic, data-independent within-unit joint-randomness plan.
- `test_coupling.py`: marginal, pairing, determinism, and fail-closed tests.
- `run_nih_cxr14_ucan_public_diagnostic.py`: real SD 2.1 LoRA full-gradient diagnostic.

All outputs are diagnostic-only.  No private optimizer run or release authorization follows automatically.
