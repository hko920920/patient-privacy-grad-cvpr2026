# CVPR 본학회 비교군과 기존 6편 선정의 정정

- 확인일: 2026-09-09, Asia/Seoul.
- 사용자 질문: 워크숍까지 포함한 6편은 선행 지식용인가. CVPR을 목표로 한다면 최신 최상위 본학회 방법과 비교해야 하지 않는가.
- 범위: 환자 DP 의료영상 diffusion과 환자 집합 membership/exposure 감사 후보.
- 이번 정정은 18·21번의 문헌 검토 범위를 보충한다. 최신 본학회 선행을 충분히 대조했다는 해석은 철회한다. 새 방법의 신규성·경쟁력은 미검증이며, 아래 CDI 등을 대조한 뒤 다시 판단해야 한다.

## 1. 서로 다른 선정 목적

| 목적 | 선정 기준 | 기존 6편과의 관계 |
|---|---|---|
| 기여 중복 확인 | 우리가 새롭다고 주장할 문제·방법을 이미 다뤘는가 | 6편을 고른 원래 목적. 워크숍·저널·공개 원고도 포함할 수 있다 |
| 실험 비교군 선정 | 같은 과제·접근 권한·데이터 조건에서 강한 방법인가 | 최신 관련 본학회 방법을 우선 검토하고, 재현 가능한 강한 기준선을 고른다. 기존 6편이 이를 대신하지 않는다 |
| 선행 지식 습득 | 개념과 분야의 흐름을 이해하는 데 필요한가 | 기존의 먼저 읽을 15편과 관련된 별도 기준. 기여 중복 대조보다 목적이 넓다 |

CVPR 투고 준비에는 첫째와 둘째가 모두 필요하다. 발표 장소만으로 직접 근접성이나 실험 우열을 정할 수 없으며, 본학회 채택도 현재 SOTA임을 자동 보장하지 않는다. 반대로 워크숍이라는 이유로 이미 공개된 아이디어를 신규성 검토에서 제외할 수는 없다. 해당 과제에 맞는 최신 방법·강한 기준선·공정한 비교가 우선이다.

즉 본학회 2편, 저널 2편, 워크숍 2편이다. 이들은 단순 배경 독서보다 기여 중복 확인의 목적이 강하다. 다만 이 6편은 기존 35편 안에서 고른 것이므로, 전체 최신 선행에 대한 완결된 핵심 목록도 아니다.

## 3. 이번 확인에서 드러난 본학회 검토 누락

### CDI: Copyrighted Data Identification in Diffusion Models — CVPR 2025 본학회

[공식 논문 페이지](https://openaccess.thecvf.com/content/CVPR2025/html/Dubinski_CDI_Copyrighted_Data_Identification_in_Diffusion_Models_CVPR_2025_paper.html) · [PDF](https://openaccess.thecvf.com/content/CVPR2025/papers/Dubinski_CDI_Copyrighted_Data_Identification_in_Diffusion_Models_CVPR_2025_paper.pdf)

- 10번 문서 74행에 `set-level MIA·CDI·medical memorization`이라는 묶음 이름은 있었다. 하지만 18번의 35편 URL 목록과 기존 핵심 6편에는 포함되지 않았다. 이름 언급을 방법·가정·결과 대조 완료의 증거로 볼 수 없다.
- 초록과 본문 §4를 확인했다. CDI는 여러 이미지에서 기존 MIA 및 새 특징을 추출하고 점수 함수와 통계 검정으로 데이터 집합의 diffusion 학습 포함 여부를 판단한다. 따라서 **diffusion에서 여러 표본의 증거를 모아 집합 단위 membership을 검정한다는 발상 자체는 이미 선행이 있다.**
- 본문 §4의 설정은 공개된 의심 집합 P와 미공개 대조 집합 U를 같은 분포의 i.i.d.로 둔다. 현재 환자 연구에서 이러한 대조 자료를 확보할 수 있는지, 환자 내 상관과 적은 기록 수에서 어떤 성질이 유지되는지를 따져야 한다. 이 차이가 새 방법의 필요성을 보장하지는 않는다.
- CDI를 핵심 기여 중복 대조 대상으로 추가한다. 원래 조건에서의 재현과, 동일한 환자 단위·접근 권한·대조 데이터 예산으로 적응한 기준선을 구분해야 한다. 기존 방법의 단순 환자 적용만으로 충분하면 새 감사법 주장은 축소해야 한다.
- 초록의 소수 데이터·높은 신뢰도 수치를 환자별 탐지율이나 보편적 오탐 보장으로 바꿔 해석하지 않는다. 이번에 PDF 11쪽 파일의 HTTP 200과 PDF 헤더, 해당 본문을 확인했으며, 전체 부록 정독·코드 재현은 수행하지 않았다.

### Tracing the Roots: Leveraging Temporal Dynamics in Diffusion Trajectories for Origin Attribution — NeurIPS 2025 본학회

[공식 본학회 페이지](https://proceedings.neurips.cc/paper_files/paper/2025/hash/901b713c3d1ecfce0d4556752eed4e02-Abstract-Conference.html) · [PDF](https://proceedings.neurips.cc/paper_files/paper/2025/file/901b713c3d1ecfce0d4556752eed4e02-Paper-Conference.pdf)

- 기존 URL 목록에서 빠진 논문이다. 공식 페이지가 Main Conference Track으로 명시한다.
- 초록과 본문 §§3–5를 확인했다. diffusion 궤적의 시간별 특징을 활용하고, 분포 차이나 생성 이미지가 섞일 때 기존 MIA 평가가 왜곡되는 문제를 다룬다.
- 이 논문의 §3은 white-box 접근과 일부 실제 member 데이터 접근을 가정한다. 우리 방법에 그런 자료를 주지 않으면서 이 방법에만 주거나, 반대로 필요한 자료를 없애 성능을 떨어뜨리는 비교를 피해야 한다. 동일 위협모델에서 가능한 비교와 별도 조건 실험으로 나눈다.
- 환자 집합 감사 자체의 해법으로 확정한 것은 아니다. 최신 공격 특징 및 평가 통제 조건의 대조 대상으로 추가하며, 전체 부록·재현 완료로 기록하지 않는다.

이번 두 누락으로 기존 35편·6편을 최신 본학회 SOTA 조사의 완결 목록으로 사용할 수 없다는 점이 확인됐다. 35편은 18번의 URL 인용을 추출한 역사 목록으로 유지한다. 새 확인 문헌을 당시 검토했던 것처럼 소급하여 넣지 않는다.

## 4. 본학회 방법을 중심으로 비교를 구체화할 우선 축

아래는 현재 비교를 구체화할 주요 예시이며, 새로 확정한 전체 근접 논문 수나 SOTA 순위가 아니다. 대부분은 기존 35편에 이미 있었으므로, 전부 새로 발견한 논문으로 세지 않는다.

| 의료 재식별·memorization 평가 | [MaMI, CVPR 2025](https://openaccess.thecvf.com/content/CVPR2025/html/Tian_Towards_All-in-One_Medical_Image_Re-Identification_CVPR_2025_paper.html) · [InvMM, ICCV 2025](https://openaccess.thecvf.com/content/ICCV2025/html/Ma_An_Inversion-based_Measure_of_Memorization_for_Diffusion_Models_ICCV_2025_paper.html) | 보조 평가 도구로 검토. 재식별·복제 점수를 환자 membership 검정의 대체물로 두지 않음 |

환자 위험 문제의 동기는 Nature와 CheXGenBench 등에서, 환자 단위 DP 구현의 직접 중복은 Kaiser 등에서도 계속 확인한다. 본학회 우선 비교와 발표 형식을 가리지 않는 기여 중복 확인은 함께 진행한다.

## 5. 판정과 다음 작업

1. 기존 6편의 의미를 **기여 중복 대조용 기존 선별**로 정정한다. 입문용 6편이나 CVPR SOTA 비교군 6편으로 부르지 않는다.
2. 18번의 제목에 있는 `전수 대조`를 최신 관련 본학회 문헌을 망라했다는 뜻으로 사용하지 않는다. 이번 점검도 2026년까지의 전수 검색 완료가 아니다.
3. 현재 후보의 exact statistic·baseline을 고정하기 전에 CDI와 최신 본학회 방법의 가정·입력·검정 단위·공개 코드·재현 조건을 대조한다. 환자 데이터라는 적용처 차이만 남으면 CVPR 방법 기여로는 부족하다.
4. 공통 오탐 기준에서 탐지력, 기록 수·상관별 오탐 통제, 비용, 방어 적용 시 효용의 실질적 차이가 있어야 후보를 강화할 수 있다. 최신 본학회 방법보다 유의미하게 해결하는 문제가 확인됐다는 판정은 아직 하지 않는다.
5. 이번에는 문헌 확인과 기록·읽기 페이지 설명을 갱신했다. 실험이나 학습은 실행하지 않았다.
