- 새 DP release·Q 조회·pixel 학습·encoder forward·수신자 탐색 없음. 예상 **15~30분**, 계산 자체는 작고 대부분 연결·검산·기록 시간이다. 실제 실행 계약에서 시간 한도를 결속한다.
- 기존 개발 투자 기준을 유지한다. 미확인/부정적이면 전달 필요성의 범위를 축소하고, 좋은 값이 나올 때까지 encoder·계수·영상 집합을 바꾸지 않는다.

**상위1 완료 기준:** 1-5까지 같은 공개 carrier에서 일반 KD와 DINO-only라는 대안을 허용한 결과를 정리하고, 다음에 검증할 후보와 대조를 선택할 근거를 남기는 것. 결과가 모두 양수일 필요는 없다. ‘완료’는 질문에 답했다는 뜻이며 방법 우위·신규성·논문 성공의 뜻이 아니다.

### 원안의 전체 표와 이번 정리의 차이

원안에는 3목표×2carrier×2release의 공통 zero-anchor 12칸과 source nullspace 진단이 있었다. 그 표 전체를 완료했다고 기록하지 않는다.

- 현재 공통표에서 있는 칸: MT Joint의 합성/공개4칸, KD Joint의 공개2칸.
- 1-5가 채울 칸: DINO-only 공개2칸.
- 남는 합성 쪽 DINO-only2칸·KD Joint2칸은 원래 hard-anchor 결과와 동일한 조건이 아니다. **공통 zero-anchor 결과는 미실행·보류**다. 합성 제작의 추가 가치가 확인되지 않은 상황에서 옛 표를 채우기 위한 자동 재실행은 하지 않는다.
- source 계수를 유지하는 nullspace 방향의 box-constrained 진단도 이번 새 공통 조건에서 완료했다고 하지 않는다. 결합 필요성이 주력이 아닌 현재 경로에서는 **기전 가설상 필요할 때만 상위2에서 재검토**한다.

이것은 원안의 미완료를 숨기는 완료 처리 대신, 공개 carrier 경로에 필요한 비교를 우선하는 **명시적 계획 수정**이다. 필요한 논문 주장에 따라 보류 항목이 다시 필요해지면 별도 범위를 먼저 정한다.

## 상위 2 — 재현과 선행 대비 기여 검증

원계획 후속 A(재현)와 B(선행 대비 차이)를 이 묶음에 넣는다. 반복할 주장을 정하기 위해 **연산·비교의 정의를 먼저 좁힌 후** 제한된 재현으로 연결한다. 기존 선행 자체를 전부 다시 감사하거나 모든 수학적 원인을 완전히 규명하는 무한 선행조건은 아니다.

| 세부 번호 | 작업 | 산출물/완료 기준 |
|---|---|---|
| **2-1** | 현재 MT, 일반 teacher-score KD, 같은 보호 평균을 사용하는 공개 가중라벨/평균 전달 대안을 수식·코드로 대응한다. | **현재 연산 / 기존 대안 / 동일 정보 접근 / 같은 부분 / 남는 차이 / 검증할 예측** 비교표 하나. 현재 MT의 signed-public-label ridge 동치는 이미 확인된 사실로 재사용한다. |
| **2-2** | 2-1에서 남은 차이 하나가 필요하다는 예측을 최소 비교로 확인한다. | 비교군·변경 요소·공통 규칙·성공/축소 판정·비용을 결과 전에 고정한 한 묶음. 이미 같은 연산이라면 가짜 별도 baseline을 만들지 않는다. 지금 새 clipping/loss/계수를 고르지 않는다. |
| **2-3** | 고정한 후보/강한 대조를 다른 공개128 선정에서 한 번 대응 확인한다. | 기존 공개 선정 규칙의 salt만202로 바꾼 집합 하나. 기존 두 DP 요약·목표 유지, 새 noise/합성 없음. 겹치는 영상 수를 기록한다. 같은 P/V의 선정 반복이므로 새로운 환자 cohort 검증으로 부르지 않는다. |

2-2는 강한 대안이 실제로 다른 계산을 만드는 경우에만 실행한다. 2-1에서 현재 연산이 그대로 알려진 특수형이라면, 반복 수를 늘려 신규성이 생긴다고 하지 않는다. 표준 연산의 결합이라도 새로운 사용 조건에서 추가 가치가 있는지는 평가할 수 있으나, 그 기여 가설과 공정한 대조를 먼저 명시한다.

2-1은 기록된 근접연구·공개 코드·원문을 재사용하는 설계 작업이며 예상1~2시간의 계획치다. 2-2의 실행 규모는 남는 차이가 정해지기 전에는 숫자를 꾸며 확정하지 않는다. 2-3은 저장 특징 재사용 시 수치 계산은 작으며 연결·검산 포함 약20~40분을 참고치로 둔다.

**상위2 완료 기준:** 실증적 개선, 강한 대안과의 구체적 관계, 반복 범위, 아직 입증하지 못한 부분이 연결된 기여 후보를 고정하는 것. 결과에 따라 매번 새 논문 제목을 붙이거나 기존 연산을 새 발명이라고 하지 않는다.
