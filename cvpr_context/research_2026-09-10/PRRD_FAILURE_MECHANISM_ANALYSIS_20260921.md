# PRRD seed101 결과의 설계·구현·정보 전달 분석 — 2026-09-21

판정: 현재 결과가 낮은 이유를 단순한 구현 실패나 source 합성학습 부족으로 설명하기는 어렵다. 채택한 관계 제한과 기능 정합은 source에서 작동했고 B/C 목표의 판별 기능도 PNG에 재현됐다. 반면 실제 관계의 추가 이득은 source의 주평가 지표에서 거의 없었고, DenseNet에서는 합성 점별 class 방향이 실제 영상과 맞지 않았다. 수신자의 제한 규칙은 그 약한 합성 점별 분류기로부터의 수정을 제한했다.

이는 설계 전체가 불가능하다는 판정이 아니라, 이번 고정 설정에서 어느 연결이 지지되지 않았는지를 구체화한 사후 분석이다. 새 학습·합성·모델 forward·원영상 접근·계수 탐색·DP·Expert/Reserved 접근은 모두0이다. 기존 통계·특징·예측·loss 기록만 사용했다. 어느 값도 다음 recipe로 채택하지 않는다.

**1. 실제 구현이 무엇을 했는가**

- 공개·사적 점별 통계는 B/C/D에서 정확히 같다. Source는 BioViL-T의 기존 P-only PCA16·bounded point z, 관계는 정규화 전 h의 같은 PCA축에서 대조 후 제한이다.
- 점별 B는 128장을, C/D는 점별64장과 관계32쌍을 쓴다. 이는 계약의 자원 배분 차이이며 오류가 아니다.
- Target/PNG/recipient 모두 beta(B0, C/D1), ridge0.1, kappa0.1의 같은 guarded learner를 쓴다. 제한 내부 M은 각자 자기 통계다. 기능 손실은 고정 source target M_T를 쓴다.
- 기능 손실은 무증강 경로에 한 번만 적용된다. 전체-bank 분모·label/slot 바인딩·작은 선형계 해를 저장 배열에서 독립 재계산했고, 기존 점수·지표와 일치했다.
- 새로운 코드/배열 검사가 모든 소프트웨어 오류의 부재를 증명하지는 않는다. 다만 이번 결과를 설명할 label 뒤집힘, 빠진 관계항, 잘못된 통계/해, 평가 집단 불일치는 확인되지 않았다. 이전 실제 encoder gradient 검증과 최종 PNG 검증도 보존한다.

**2. 실제 관계는 분류기를 바꿨지만, 전체 영상의 순위 이득은 상쇄됐다**

같은 BioViL target의 기존 학습기 내부 상태를 나눠 보았다. w1은 새로 계수를 고른 방법이 아니라 기존 함수가 원래 계산하는 제한 전 해다.

| 기존 내부 상태 | AUROC | AP |
|---|---:|---:|
| 점별 w0 = B | 0.777791 | 0.127907 |
| C의 제한 전 w1 | 0.776658 | 0.124090 |
| C의 최종 제한 해 | 0.777931 | 0.126072 |
| D의 최종 해 | 0.783509 | 0.171633 |

C의 alpha는0.744097이다. 관계를 사실상0으로 만들어서 실패한 것은 아니다. 반대로 source에서 제한을 제거하면 좋아진다는 설명도 이 고정 내부 상태 비교와 맞지 않는다.

V의 양성·음성 조합1,075,752개 중 C는 B가 틀린 순위22,958개를 바로잡았지만, 맞던 순위22,807개를 반대로 만들었다. 순증151개/1,075,752 = AUROC +0.000140이다. 이는 관계의 변화가 없었던 것이 아니라, 개선과 악화가 주평가에서 거의 상쇄됐다는 직접 계산이다. 이 쌍들은 독립 표본이 아니며 이 개수를 유의성 표본 수로 쓰지 않는다. 원 patient-bootstrap C−B 95% 구간은[-0.006667,+0.006583]이다.

관계 제한이 보장하는 것은 F0(w*)−F0(w0) <= rho²/2다. 이 규칙은 관계의 방향이 V AUROC에 유익한지 선택하지 않는다. 이번 source에서는 관계 훈련 위험이0.430250→0.409438로 줄고, V의 환자·class 가중 점별 제곱위험도0.425155→0.421274로 줄었다. 그럼에도 AUROC/AP 우위는 생기지 않았다. 학습 목적·환자 가중치와 주평가의 전체 image-level 순위는 서로 다른 대상이다.

사후 설명 지표로 V의 mixed104명 안에서 환자별 AUROC를 구해 평균하면 B0.615074, C0.642039, D0.637636이다. 같은 환자 bootstrap의 C−B는+0.026965 [0.004515,0.053172], C−D는+0.004404 [-0.018348,0.028105]였다. 이 결과는 관계 신호가 전혀 없다는 단정에 반대되는 정황이지만, 사후 선택한 보조지표이며 주평가나 실제 대응의 독자적 이득을 대체하지 않는다. 목표를 환자 내 순위로 바꾸어 기존 실패를 성공으로 재분류하지 않는다.

**3. 정규화 순서의 이론적 문제와 현재 데이터의 중요한 실패는 같다고 확인되지 않았다**

Q mixed102명의 raw 대조와 기존 point 대조 방향의 cosine 평균은0.9013, 중앙값0.9470이며 음수인 환자는0명이다. 개별 차이는 존재하지만, 설명용 예에서처럼 대부분의 대조 방향이 소실됐다고 이 데이터에서 확인한 것은 아니다. 이 통계만으로 정규화 전 대조가 불필요하다고도 결론내릴 수 없다. E_R의 정식 합성 비교는 아직 실행하지 않았으므로 순서 개선 효과는 분리 검증되지 않았다.

공개 mixed3명으로 정한 source 관계 scale은0.265009다. 그 scale에서 Q의 실제 대응은54/102명(52.9%), 교란 대응은99/102명(97.1%)이 제한된다. 제한 전 평균은 같지만 제한 후 평균 norm은 C0.198514, D0.094900으로 달라진다. 따라서 현재 C−D는 2차 구조만 바꾸는 비교가 아니다. 실제 대응 여부가 대조 크기·제한 강도·평균·2차항을 함께 바꾼다.

D는 무정보나 무작위 label 조건이 아니다. 같은 양성/음성 목록과 점별 정보에 다른 대조 규칙을 사용한다. D가 더 높다는 사실은 현재 C의 추가 가치를 지지하지 않지만, 실제 환자 관계 일반이 해롭다는 증거는 아니다. 무엇이 D의 이득을 일으켰는지까지 단일 교란과 seed로 분리할 수 없다.

|---|---:|---:|---:|---:|---:|
| B | 0.777791 | 0.777578 | 0.127907 | 0.127708 | 0.655% |

| D | 0.783509 | 0.781108 | 0.171633 | 0.160171 | 6.191% |

C의 target/PNG V 점수 Pearson은0.999979이다. B/C의 주된 문제를 목표 기능 복제 부족으로 설명하기 어렵다. D에는 상대적으로 더 큰 source 재현 오차가 있다. 그러나 source 기능 오차가 더 큰 D가 DenseNet에서는 C보다 높았다. 이 pilot에서 source 기능 정합 오차를 전이 효용의 대용 지표로 사용할 수 없다.

PNG 양자화도 이미 반영됐다. C의 source J_func는 float2.7202e−5, PNG1.5023e−5로 작고, PNG V 판별 성능도 유지된다. float에서는 성공했지만 저장 과정에서 source 기능이 붕괴했다는 설명은 맞지 않는다. 이는 양자화가 DenseNet에 전혀 영향이 없다는 증명은 아니며, 별도 float recipient 평가는 실행하지 않았다.

500회를 무한히 늘릴 필요가 없다는 운영 판단의 근거는 source loss가0이라는 뜻이 아니라, 이미 목표 source 판별 기능을 거의 재현했다는 것이다. 미완료 업데이트·NaN·DP잡음·GPU메모리 실패가 이번 주성능 실패의 직접 원인이라는 증거도 없다. 학습은 전 arm500회 완료했고 이번 결과는 비DP다.

**5. DenseNet은 합성영상에서 실제 V와 다른 class 방향을 학습했다**

각 encoder 안에서 합성 점별 양성·음성 평균 차이와 실제 V의 환자·class 가중 평균 차이 사이의 cosine을 계산했다. 서로 다른 차원의 벡터를 직접 비교한 값이 아니다.

| 조건 | BioViL 안에서의 방향 일치 | DenseNet 안에서의 방향 일치 | DenseNet의 합성 점별 AUROC | 같은 점별 해의 V AUROC |
|---|---:|---:|---:|---:|
| B | 0.978741 | 0.204404 | 0.829102 | 0.567975 |
| C | 0.978978 | 0.014165 | 0.886719 | 0.486687 |
| D | 0.979296 | 0.280643 | 0.853516 | 0.610314 |

C는 source에서는 실제 class 차이와 정렬됐지만 DenseNet에서는 거의 직교했다. 수신자는 합성 labels를 어느 정도 구분했으나, 그 방향이 실제 영상에서는 판별에 연결되지 않았다. 이 계산은 V 라벨을 사후 설명에만 사용했으며 합성학습·계수 선택에 사용하지 않았다.

특징 분포에도 차이가 있다. DenseNet의 point norm이 공개 bound 경계(norm >= 1−1e−6)에 있는 비율은 공개 P5.54%, 실제 V5.17%인데, 합성 A93.75%, B95.31%, C94.53%, D93.75%다. 제한 전 affine norm/public scale의 평균도 P0.788, V0.775, C PNG1.187이다. 따라서 합성자료의 수신자 표현은 실제 분포와 다르게 반응한다. 이 현상은 모든 합성 arm에 있으므로 C만의 패배를 설명하는 단일 원인은 아니고, 공통 전이 문제의 구체적인 징후다.

현재 합성 목적에는 수신자 특징이 들어가지 않는다. 통계와 J_func 모두 같은 source 요약에서 계산된다. 같은 source 모멘트를 만드는 두 영상 bank는 J_func에서도 구분되지 않는다. 기능 정합은 유한 오차의 중요도를 바꾸고 source 재현을 개선할 수 있지만, 새로운 다른-encoder 정보나 의료적 의미의 제약을 추가하지 않는다. 이번 관측은 이 구조적 공백과 일치한다. 다만 어떤 시각적 특징/인공 패턴이 원인인지까지 본 분석만으로 특정하지 않는다.

**6. 관계 제한은 수신자에서 성능이 낮은 점별 기준을 강하게 유지했다**

같은 고정 C PNG의 DenseNet 학습기 내부 값을 비교했다.

| 내부 해 | AUROC | AP |
|---|---:|---:|
| 점별 w0 | 0.486687 | 0.046872 |
| 제한 전 관계 w1 | 0.561616 | 0.050812 |
| 최종 guarded 해 | 0.508841 | 0.048571 |

Recipient C의 alpha는0.195127로, 제안된 관계 수정량의 약19.5%만 반영한다. 같은 규칙이라도 source target의 alpha0.744097과 달라진다. 각자 자기 특징·점별 M·관계 통계를 사용하기 때문이다.

수신자의 보호 기준 F0는 실제 V의 판별 성능이 아니라 합성 점별 통계의 제곱 목적이다. C의 w0는 합성 점별 AUROC0.886719를 얻지만 V에서는0.486687이다. 그 w0에서 멀어지는 것을 제한하면 실제 V에 도움이 되는 수정도 줄어들 수 있다. 고정 C bank의 이번 수치에서는 실제로 최종 해가 제한 전 해보다 낮다. 이는 규칙이 구현대로 동작한 결과이며, 수학 상한이 실제 V의 악화를 막아준다는 해석이 틀렸던 것이다.

그렇다고 제한을 빼는 변경을 바로 채택하지 않는다. C의 제한 전0.561616도 기존 B0.567975보다 낮고, source target 단계의 관계 이득 부재도 해결하지 않는다. 합성학습 때 제한을 뺐다면 PNG 자체가 달라졌을 것이므로, 이 내부 해 비교는 전체 guard-off 재학습 제거실험을 대체하지 않는다. D에서는 같은 제한이0.545908의 제한 전 해를0.602826으로 바꾸는 방향이어서 전 arm의 규칙 변경은 더더욱 별도 검증 사항이다.

**7. C−B의 손해와 관계항의 효과를 혼동하면 안 된다**

기존 DenseNet 결과의 정확한 산술 분해는 다음과 같다.

C−B = (C_beta0−B) + (C−C_beta0)
     = −0.081287 + 0.022154
     = −0.059134 AUROC.

C 영상의 점별 부분만 쓰면 B보다0.0813 낮고, 그 위의 관계 학습은0.0222 회복했다. 따라서 최종 C가 낮다는 이유로 관계항이 점별 분류기를 전부 망가뜨렸다고 설명하면 안 된다. C와 D의 point-only 차이도−0.123627이다. 이는 다른 관계 목표로 이미지를 만드는 과정이 수신자가 읽는 점별 정보에도 영향을 주었음을 보여준다. 이 산술은 고정 산출물의 분해이며, 전체 제작 과정의 인과 매개 효과 추정은 아니다.

B의 점별128장에 비해 C/D는64장을 쓴다. DenseNet128차원에서 관측된 centered point rank는 B127, C/D63이다. 원래 의도는 점별 표현의 일부 자원을 관계로 옮겨 더 큰 효용을 얻는 것이었지만, 이 pilot의 C에서는 그 대가를 회복하지 못했다. D는 같은64장으로 C보다 높으므로 장수 부족 하나로 C의 실패를 확정할 수 없다.

**8. 남아 있는 위험 후보와 현재 확정할 수 없는 것**

- 관계 scale은 공개 mixed3명의 최대 norm(q95 inverse CDF)이다. 공개라는 점은 접근 규칙을 지키지만 통계적으로 충분한 보정이라는 뜻은 아니다. 현재 높은 clipping 비율은 확인됐으나, 다른 scale을 비교하지 않아 그것이 실패 원인이라고 확정하지 않는다.
- seed101의 초기 공개 template64개는 모두 해당 질환 label0이다. 음성/양성 합성 slots가 같은 template를 복제하고 label은 최적화 목표로 부여된다. C/D 점별 bank의 고유 template는32개다. 계약대로 실행됐지만, 실제 class 내용의 재현은 source 특징 loss가 만들어야 한다. 이는 전이 취약성의 후보이며 label0을 해부학적으로 정상이라고 부르지 않는다. template나 영상 prior를 바꾼 실험은 하지 않았다.
- source16차원·recipient128차원, 사전학습 도메인, 영상224 출력을 각각 원인으로 확정할 수 없다. source 자체는 V에서 판별력이 있고, DenseNet도 기존 공개 실자료 기준0.618009이므로 둘 중 하나가 단순히 무작위 모델이라는 설명도 맞지 않는다. Source P+Q와 recipient P-only는 접근 정보가 달라 모델 상한 비교로 해석하지 않는다.
- raw 관계와 normalized point의 좌표 의미 차이는 실제다. 평균 방향이 대체로 맞는다는 것만으로 관계 보조 위험이 최종 점수 차이를 정확히 나타내지는 않는다. raw-point 전환이나 새로운 representation은 이번에 실행하거나 채택하지 않았다.
- 약한 label, 촬영 view/device, 환자 변화와 질환 변화의 혼합은 가능한 설명이다. 현재 저장 통계만으로 임상적 원인을 확정하지 않는다.
- 단일 seed, 이미 반복 사용된 V, 사후 다수 진단이다. 기존 primary 비교의 음성 결과를 새 보조지표로 덮어쓰지 않는다. 독립 final, 새로운 DP 결과, 새 알고리즘 우위를 주장하지 않는다.

**9. 설계 판단과 다음 작업의 경계**

실패의 가장 직접적인 설명은 다음 세 가지다.

1. 보존할 실제 관계가 전체 단일 영상 AUROC/AP를 개선하는 유용한 source 수정 방향이라는 전제가 이번 조건에서 지지되지 않았다. 관계 위험·제곱위험·환자 내 순위의 일부 개선과 주평가 우위는 달랐다.
2. 기능 정합은 source의 재현을 잘 만들었지만, 합성영상이 다른 encoder에서도 실제 class 방향을 만들도록 하는 정보는 추가하지 못했다. 실제 수신자 특징의 분포와 방향 차이가 관측됐다.
3. 수신자의 관계 개입 제한은 자기 합성 점별 기준을 보호한다. 그 기준의 실제 성능이 낮을 때 유용한 수정까지 제한할 수 있으며 이번 C에서 그런 고정-bank 현상이 관측됐다.

이는 사후에 모든 원인을 하나로 찾았다는 뜻은 아니다. 하지만 단순 반복·더 긴500회·추가 seed·DP를 자동 실행할 근거가 없다는 판단에는 충분하다. 이번 작업은 분석으로 끝내고 기존 방법·계수·자료·bank는 그대로 보존한다. 다음 설계를 바꾸는 결정은 이 보고서에서 하지 않는다.
