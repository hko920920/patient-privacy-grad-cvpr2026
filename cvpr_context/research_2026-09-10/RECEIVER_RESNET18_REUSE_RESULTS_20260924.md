# ResNet18 추가 개발 수신자의 기존 DP PNG 재사용 결과

2026-09-24 KST. 이번 ResNet18에서도 bank에 따라 A2와 DINO의 순위가 달랐다. 모든 관측을 보존하며 좋은 bank 하나로 방법의 우위를 정하지 않는다. 두 잡음 AUROC 산술평균은 A2 0.603760, DINO 0.615884다. 이 추가 개발 수신자에서도 A2의 약 두 배 제작비용을 정당화할 효용 우위는 확인하지 못했다.

새 합성학습·DP query·Q 픽셀 접근 없이 기존5개 최종 PNG bank와 공개 P 실영상 readout만 평가했다. DenseNet의 기존 불확실한 결합 우위는 그대로 보존한다. 이번 ResNet18 결과는 추가 개발 수신자에서의 사용 조건을 보여주며, 최종 unseen 전이·일반적인 DP 우위·잡음 안정성·독자적 논문 기여를 확정하지 않는다.

A2 DP−A2 공개전용의 AUROC 차이는 +0.106076, +0.081757이며 두 조건부 환자 구간이 모두 양수다. 따라서 동일 A2 제작에서 보호된 Q의 추가 가치가 이 개발 수신자에서도 남은 관측은 보존한다. 반면 네 보호 bank와 공개 P 실영상 readout 사이 AUROC/AP 차이 구간은 모두 0을 포함한다. 공개 실영상보다 유리한 실제 대안이라는 주장까지 확보된 것은 아니다.

## 고정 연산과 검증

- 공개 ResNet18 IMAGENET1K_V1 checkpoint SHA `f37072fd47e89c5e827621c5baffa7500819f7896bbacec160b1a16c560e07ec`, fc=Identity의 avgpool512, 모든 parameter/buffer eval 동결. 의료 fine-tuned checkpoint나 과거 BCE 학습 결과는 선택하지 않았다.
- P/PNG/V 모두 동일한 CPU FP32 tensor short256·center224·RGB 복제·ImageNet 정규화를 사용했다. 공개 첫16장에서 공식 forward와 직접 layer/avgpool 경로가 exact 일치했다.
- P813장/672환자만으로 PCA128·projected norm의 환자 가중 q95를 고정했다. q95=13.4212583, retained variance=0.938763. raw L2/whitening 없음. 현재 DenseNet과 같은 P-only PCA128/q95 원칙이며 옛 v1의 full512/L2 수신 규칙과 동일한 구현이라고 하지 않는다.
- 여섯 readout의 ridge0.1·관계항0·bias 없음. PNG는 class별64장 균등, 공개 실영상은 class0.5×환자 균등×환자/class 내부 방문 균등. 직접 가중 normal equation과 기존 learner의 최대 차이 4.441e-16.
- P 기반 projection과 모든 readout을 V 추출 전에 고정했다. 이후 특징·계수·checkpoint를 고르지 않았다. V5047장/2026환자/양성223장, 기존 draw 재사용, 독립 sklearn bootstrap 최대오차 1.110e-16.
- 최종 PNG·labels·파일 해시, 명부/특징 순서, encoder/readout 불변, 기존 코드·결과·privacy ledger 불변 검증을 통과했다. Q/Expert/Reserved/final receiver 픽셀 접근0.
