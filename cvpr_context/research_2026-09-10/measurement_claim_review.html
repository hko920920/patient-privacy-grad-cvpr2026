측정 불가능 주장 정정과 실제 평가 경로 검토

2026-09-17. 큰 단계 2 / 방향 1의 문제–측정 연결 검토. 측정 경로의 존재에는 긍정적, 현재 private head의 효용에는 미판정이다. 새로운 환자 영상 열람·모델 추론·생성·학습·DP 실행은 없다. 원격 main을 이번 검토에서 조회한 것은 아니다.

1. 정정할 결론과 유지할 결과

“측정할 수 없다”, “전문의 협력이 없으면 방향 1을 종료해야 한다”는 일반화는 철회한다. 두 자동 평가기가 특정 NIH 집합에서 채택 기준을 통과하지 못한 것과, 질환 표현이나 합성자료 효용을 측정하는 모든 방법이 불가능한 것은 다르다.

  • PadChest 검증과 CheXzero 검증의 고정 점수·실패 판정은 유지한다. CheXzero의 target-vs-opposite AUC는 폐기종 0.5900, 기흉 0.4900이다. 현재 목적의 primary 질환 평가기로 채택할 근거를 확보하지 못했다.
  • AUC 0.70/0.60과 신뢰구간 기준은 사전 운영 관문이다. 보편적인 측정 가능성의 경계나 질환 자체의 식별 불가능성을 증명하는 기준은 아니다.
  • 두 검증에서는 생성기를 실행하지 않았다. 따라서 targeted private generation utility의 유무를 판정하지 않았다. 반면 기존 192장의 해당 prompt/reference 아래 pooled 추가 효용 미통과는 별도의 실제 음성 결과로 유지한다.
  • 현재 공동 가설에서 세 번째 classifier·prompt·checkpoint를 바꾸며 통과할 때까지 찾지 않는 중단선은 유지한다. 이 중단선은 향후 근거 있는 새 자료·새 평가 명세까지 금지하는 과학 법칙이 아니다. 탐색한 평가기를 최종 확인에 그대로 재사용하는 문제와, 개발 후 독립적으로 확인하는 절차를 구분한다.

2. 사용자 참고문 중 추가로 고칠 부분

NIH weak label이 이번 낮은 AUC의 주원인이라는 설명은 아직 가설이다. NIH의 텍스트 추출 라벨에 시각적 내용과의 불일치가 있다는 선행 근거는 있다. 그러나 우리 80명씩을 전문가가 재판독하지 않았으므로 실제 라벨 오류량, 기관 간 전이, 동반질환, 군 구성, 표본 불확실성의 기여를 분리하지 못했다. 구현 검산은 라벨의 의미적 타당성을 검증하지 않는다. Oakden-Rayner 원 연구

“NIH 전문의 재라벨에는 폐기종이 없다”는 말은 네 소견 묶음에만 해당한다. 별도로 14개 원래 소견 전체를 판독한 810 PA 영상 묶음도 있다. 또한 전문가가 실영상을 판독한 자료는 새 생성영상의 정답 라벨이 아니다. 실영상 판별력 검증이나 downstream 시험에 활용할 후보이며, 생성 질환의 정확성까지 자동으로 보증하지 않는다.

전문의가 없을 때 기흉 단독 또는 포기라는 양자택일도 이르다. 두 질환의 기존 전문가 주석을 검토하거나, 합성자료의 downstream 효용이라는 다른 주장을 명시적으로 정의할 수 있다. 새로운 측정법이나 데이터셋을 사용하는 것 자체가 논문 신규성은 아니다.

VinDr의 공개 image ID는 SOP Instance UID에서 만들어진 식별자다. 이를 patient ID로 간주할 수 없다. 환자 묶음이 필요한 patient-DP 학습자료로 옮기려면 환자 단위 식별 가능성도 별도로 확인해야 한다. 외부 실영상 reference만 바꾸면 현재 NIH private80이 가진 target-domain 효용이 검증되는 것도 아니다.

4. 논문 주장과 측정 대상을 맞춰야 한다

생성 feature 분포가 개선된다 환자 분리 실영상에 대한 KID/PRDC 등과 다양성·artifact 점검 목표 질환의 의학적 정확성

가까운 선행인 ICCV 2025 DP-LoRA는 §4에서 FID와 합성자료로 학습한 분류기의 real-test 정확도를 함께 사용한다. 따라서 생성 privacy/efficiency 논문 전반이 반드시 한 질환 classifier의 직접 점수에 의존한다는 전제는 틀리다. 이 논문은 의료 환자 DP 자체를 증명한 선행은 아니다. 이번 재확인 범위는 로컬 공식 PDF pp.4–6이다. 공식 PDF

RoentGen도 합성자료의 학습 효용을 평가했다. 이번에 확보한 arXiv v1의 §7은 real/synthetic 학습 구성을 달리한 분류기를 별도 실영상 test에서 비교한다. 출판본의 평가 설명은 전문가 판독과 분포·분류·학습 효용을 구분한다. 이번에 출판본 전체를 재검산한 것은 아니다. arXiv 원문, 출판본

Downstream 비교 후보는 공통 공개 real 학습자료만 사용하는 기준과, 같은 수의 public-head 합성자료 또는 private/pooled-head 합성자료를 더하는 기준이다. 학습량·classifier·seed·모델 선택 절차를 맞추고 단순 real 반복/일반 augmentation 효과와 구분한다. 환자 단위 독립 real test와 반복 실험이 필요하다. private real을 downstream 학습에 직접 넣는 비DP 진단 기준은 별도로 표시해야 하며, 그 경로까지 포함한 모델을 자동으로 patient-DP라고 주장하면 안 된다.

마스크가 있는 실영상은 segmenter의 시험 정답을 제공한다. 현재 text-to-image 생성기는 합성 마스크를 제공하지 않으므로, SIIM 마스크가 있다는 이유만으로 synthetic segmentation 학습 쌍까지 준비됐다고 말할 수 없다. 분할 경로는 paired mask 생성/주석 규칙이라는 추가 설계가 필요하다.

5. 현실적인 결정과 다음 한 단계

연구 종료 판단은 취소하고, 무엇을 측정할지 다시 연결하는 검토를 진행하는 것이 맞다. 현재 두 평가기의 채택 실패와 기존 pooled 생성 효용 미통과는 그대로다. 새 측정 경로의 존재는 우리 방법이 좋아진 증거가 아니다.

우선순위는 NIH 14소견 전문가 라벨의 실제 이용 가능성·target 수·환자 중복을 확인하는 것이다. 폐기종을 사후에 지우거나 곧바로 새 classifier를 돌리는 순서가 아니다. 라벨 명부를 확보하면 모델 점수를 열지 않고 metadata만으로 20–30분 안에 적격 수와 사용 가능한 역할을 산출할 수 있다. 접근 처리 대기시간은 아직 모른다. 졸논 final/census나 reserved confirmation을 개발자료로 자동 재배정하지 않는다.

동시에 전문가 협력 여부에 의존하지 않고 설계할 수 있는 후보는 합성자료의 downstream 추가 효용이다. 이를 채택하려면 reliable real-test 확보와 공정한 증강 비교 명세부터 정해야 한다. 이 명세 작성은 30–45분 예상이며, 학습 실행 시간은 classifier·자료 규모를 정하기 전에는 약속하지 않는다. 기존 두 질환 임상 정확성 주장의 성공으로 바꿔 쓰지 않는다.

전문의 판독이 현실적으로 가능하다는 답변이 오면 직접 소견 평가를 함께 설계할 수 있다. 현재 질환당 latent 32개·판독자 2명을 충분한 표본으로 확정하지 않는다. 그것은 비용과 효과크기에 따라 정할 파일럿 제안값이다.

현재는 문헌에 근거한 측정 대안은 있고, 채택 가능한 실제 자료와 효용 증거는 아직 확보 전이다. 보호 설계·효율이라는 큰 질문을 임의로 “두 질환 classifier 통과 여부”로 대체하지 않는다. 방향 2도 별도의 구체적인 기여 근거 없이 자동으로 시작하지 않는다.

6. 이번 작업의 범위

공식 데이터 설명, VinDr 원문 관련 표, DP-LoRA 평가 절, RoentGen 선택 절을 대조했다. 새 모델 추론·생성·학습·DP·reserved confirmation 소비는 0이다. 새 전문 라벨을 내려받거나 개인정보가 들어가는 접근 양식을 제출하지 않았다. RoentGen 공개 논문 PDF만 보존했다.

이 문서와 최신 상태/HTML의 해석을 정정한다. 이전 실험 보고서·protocol·raw 결과는 수정하지 않는다. 이번 확인은 문서/상태 결속과 선택된 과거 파일 hash 확인이며, 192개 PNG나 전체 환자 pixel을 새로 검산했다는 주장이 아니다.
