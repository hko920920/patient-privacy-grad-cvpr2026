# 2번 결과: 기존 단독 목표 대조 분석

2026-09-28 · Stage2 유지 · 승인 범위 완료 · 기존 결과의 사후 개발 분석

## 판정

**2A는 긍정적인 개발 근거, 2B는 결합 필요성 미확인이다.**

- **2A — DINO-only 대비:** DINO와 공개 전달 ResNet18 목표를 결합한 구성은 DenseNet AUROC가 두 release 평균 **+0.032397** 높았다. 동일 환자 bootstrap 회차에서 계산한 평균 차이의 95% 구간은 **[+0.018705, +0.046884]**다. 계획에 명시한 개발 투자 기준을 충족했다.
- **2B — 공개 전달 RN-only 대비:** 결합의 평균 AUROC 차이는 **−0.006010**, 구간은 **[−0.027338, +0.015116]**이다. 결합이 더 좋거나 반드시 필요하다는 결론은 지지하지 못했다. RN-only의 일반적 우위나 두 방식의 동등성도 입증한 것은 아니다.
- 1번의 일반 teacher-score KD 대비 개선은 별개로 유지한다. 이번 결과로 삭제하거나, 반대로 모든 KD 방식에 대한 우위로 확대하지 않는다.

**다른 모델의 공개 목표를 반영하는 현재 구성에는 실증적 이유가 있다. 다만 그 목표와 DINO를 반드시 함께 맞춰야 한다는 주장까지 확보한 것은 아니다.**

## 실행 범위와 비교 대상

[계획](PUBLIC_TRANSFER_STEP2_EXISTING_CONTROL_PLAN_20260928.md)에 따라 2026-09-24에 완료된 다음 결과만 재사용했다.

| 이름 | 학습 라벨을 결정한 목표 |
|---|---|
| DINO-only | 기존 DINO feature-DP 요약으로부터 만든 DINO 목표 |
| RN-only | 같은 DINO-DP 요약을 공개 P의 모델 간 대응으로 전달한 ResNet18 목표 |
| Joint | DINO 목표와 공개 전달 ResNet18 목표를 정규화한 뒤 같은 비중으로 결합 |

RN-only는 **새로운 사적 ResNet18 요약을 조회한 방식이 아니다.** 세 방식은 release별로 같은 기존 DP 요약, 같은 128장 PNG, 기존 공개 입력, hard-label anchor, 라벨 범위, ridge 및 평가 규칙을 사용한다. 이번에 목표·라벨·이미지를 다시 만들지 않았다.

최종 효용은 **DenseNet의 영상 단위 AUROC/AP**, 불확실성은 **환자 cluster를 함께 재표집한 구간**이다. ResNet18은 목표 제작에 참여한 모델이므로 그 readout을 독립 전이 증거로 더하지 않았다.

## 분석 방법과 재사용의 타당성

기존 2,000회 paired patient-cluster bootstrap 배열을 그대로 사용했다. 각 회차 b에서

```text
mean_delta[b] =
  ((U(Joint_DP1)[b] - U(Control_DP1)[b])
 + (U(Joint_DP2)[b] - U(Control_DP2)[b])) / 2
```

를 계산하고 2.5/97.5 percentile을 사용했다. 두 release를 독립 환자 표본처럼 취급하거나, 개별 CI의 끝점을 평균하지 않았다. 새 환자 재표집이나 지표 재계산도 하지 않았다.

구간은 **지금 고정된 두 DP release와 bank에 조건부**다. DP 잡음 분포 전체의 기대 효용, 여러 합성 초기화에 대한 효과, 독립적인 확인 평가를 대신하지 않는다. 같은 DenseNet/V를 사용한 사후 개발 분석이며, 기존 결과를 이미 본 뒤 계획한 계산이다.

계획에서 검토한 단독 목적함수는 다음과 같다.

```text
L(l) = ||sqrt(W) (B l - t)||²
     + (1e-3 * ||sqrt(W) B||_F² / 128) ||l - l_hard||².
```

단독 모델의 B와 t를 target RMS s로 나누면 data term과 같은 규칙으로 산출하는 regularizer가 모두 1/s²배가 된다. 양의 모델 가중치도 단독 목적 전체에 공통으로 적용된다. 같은 bounds/hard anchor에서는 minimizer가 유지되므로, RMS 표기 차이만을 이유로 단독 대조를 재학습하지 않았다. Joint는 정규화한 두 단독 목적의 같은 비중 결합이다.

## 개발 기준의 명시적 판정

이 기준은 사후 개발 투자 판단이며, 새 확인시험의 사전등록 기준이 아니다.

| 기존 기준 | 2A: Joint−DINO | 2B: Joint−RN |
|---|---|---|
| 두 AUROC 점차이가 모두 양수 | 충족 | 미충족 |
| 평균 AUROC 차이 ≥ 0.01 | 충족 | 미충족 |
| 평균 AP 차이 ≥ 0 | 충족 | 미충족 |
| 평균 AUROC 조건부 구간 하한 > 0 | 충족 | 미충족 |

평균 AP의 점차이 기준을 충족했다는 사실은 AP의 통계적 우위와 다르다. 실패한 2B 기준을 바꾸거나, 두 질문을 하나의 ‘전체 통과’로 합치지 않는다.

## 다음 결정의 범위

1번은 정의한 일반 teacher-score KD 대조보다 현재 목표 전달 구성이 유용하다는 개발 근거다. 이번 2번은 **공개 RN 목표를 반영하는 이득과 DINO/RN 결합의 필요성을 구분**했다. 두 결과는 서로 다른 질문에 답한다.

이 결과만으로 새로운 원리, 최종 방식, 논문 기여를 확정하지 않는다. 공동 목표의 필요성·잡음 안정성·full-network 학습 전이도 미확인이다.

다음 3번 후보는 **동일한 라벨 계산을 허용했을 때 공개 영상 128장으로도 되는지**다. 공개 carrier 선정과 공통 regularizer를 먼저 고정해야 하며, RN-only라는 강한 대안을 무시하지 않도록 비교 범위를 정리할 필요가 있다. 이번 작업에서는 3번을 시작하지 않았고, Expert/Reserved도 사용하지 않았다.
