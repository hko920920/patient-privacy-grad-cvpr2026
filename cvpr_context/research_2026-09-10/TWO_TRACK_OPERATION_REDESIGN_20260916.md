# 보호 설계·효율과 보호 평가: 연산부터 다시 만든 두 후보

**후속 실제 구현·검증 완료:** [방향1 잔차층의 환자 분리 개발평가](TRACK1_CAPACITY_RESULTS_20260916.md). 비DP head의 MSE가 base대비3.1384%, 단순16차원대비 .4467% 감소했다. 아래 미실행 문구는 설계 당시 이력이며 DP 효용·생성 품질·신규성은 여전히 미검증이다.

2026-09-16. 현재 **2번: 근접 선행 대조와 논리적 설계**. 이번 작업은 문헌·수식·설계 검토이며 새 GPU·학습·공격 실험은 0이다.

**더 진행할 구체 후보는 있다. 우선순위는 방향1의 ‘고정 생성모델의 작은 잔차 보정층을 환자별 보호 통계로 학습’이다.** 비용을 줄이는 연산과 그 대가를 명시할 수 있기 때문이다. 방향2는 교차 증류 방어의 어느 데이터 경로를 고쳐야 하는지 판단하는 평가로 구체화했지만, 직접 선행이 더 강하게 겹쳐 추가 기여를 좁히는 작업이 남았다. 어느 쪽도 현재 성능 우월이나 CVPR 신규성이 검증된 것은 아니다.

이전 두 배분 규칙 v0의 불리한 결과는 [완료 보고서](TWO_TRACK_DEEPER_CHECK_20260916.md)에 그대로 보존한다. 그 규칙의 계수·예산을 바꿔 살리는 작업으로 이어가지 않았다. 졸논 목표 변경 허용과 두 방향 병행이라는 사용자 지시는 유지한다.

## 1. 이번에 실제로 한 일

세 담당자가 보호 학습, 보호 평가, 직접 중복 여부를 나눠 원문을 대조했고, root가 수식·개인정보 단위·비교 조건을 재검토했다. 새로 확인한 문헌은 기존 79편 장부와 별도의 추가 검토이며 과거에 모두 읽었다고 소급하지 않는다. 논문 전체 재현이나 모든 페이지 정독도 주장하지 않는다.

## 2. 방향1 — 반복 DP 미세조정 대신 환자별 통계로 작은 생성 보정층 학습

### 문제와 해결 원리

가까운 직접 비교는 [ICCV 2025 Differentially Private Fine-Tuning of Diffusion Models](https://openaccess.thecvf.com/content/ICCV2025/papers/Tsai_Differentially_Private_Fine-Tuning_of_Diffusion_Models_ICCV_2025_paper.pdf)이다. 공개 모델을 이용하고 학습 파라미터를 줄이는 접근은 이미 있다. 우리가 바꾸려는 부분은 **사적 자료를 이용한 비선형 backbone 경로의 반복 갱신**이다. 환자당 사진·noise 반복이 늘 때 이 비용이 커지는 문제는 특별한 환경을 만들어야만 발생하는 문제가 아니다.

공개 고정 모델을 `f0`, 동일 forward에서 나오는 공간 특징을 `h0`라 한다. 공개적으로 고정한 projection `P`와 작은 timestep basis `b(t)`를 사용한다.

```text
phi(z_t,t,c,s) = b(t) ⊗ P h0(z_t,t,c,s)
fW(z_t,t,c,s) = f0(z_t,t,c,s) + Wᵀ phi(z_t,t,c,s)
```

`s`는 공간 위치다. W는 위치마다 따로 두지 않고 공유한다. 입력에 대해서는 비선형인 동결 특징을 쓰고, W에 대해서만 선형이다. `W=0`이면 원래 공개 모델이다. 원래 LoRA의 동등 변환이 아니라 **더 좁은 함수족을 선택하는 설계**이다.

환자 u마다 사진·noise·공간 위치를 평균해 다음 통계를 만든다. 출력 parameterization은 원 모델과 맞춘다. 아래는 epsilon 예시이며 v-prediction과 섞지 않는다.

```text
r = epsilon - f0
A_u = mean(phi phiᵀ)
B_u = mean(phi rᵀ)
A = sum_u A_u / N0
B = sum_u B_u / N0

L(W) = constant - 2 tr(WᵀB) + tr(WᵀAW) + lambda ||W||F²
W* = (A + lambda I)^(-1) B
```

따라서 **고정 특징·정해진 유한 noise 표본·이 함수족 안에서는** 두 통계만 있으면 손실의 W 의존 부분과 최적해를 구할 수 있다. 절대 손실값에는 W와 무관한 잔차 제곱 평균도 필요하다. 이 부분은 기대가 아니라 이차손실의 대수적 성질이다. 다만 target domain을 이 작은 함수족이 잘 표현한다는 것은 가설이다. 환자 평균 목적과 이미지 평균 목적도 다르므로 비교군에 같은 목적을 준다.

### 보호 연산과 정확한 범위

공개 고정 척도로 A/B를 하나의 벡터로 만들고, 환자별로 한 번 joint clipping한 뒤 합계에 Gaussian 잡음을 넣는다. `svec`는 대칭 행렬의 비대각 항에 sqrt(2)를 곱해 Frobenius norm을 보존한다.

```text
s_u = concat(svec(A_u)/a0, vec(B_u)/b0)
w_u = min(1, C/||s_u||2)
release = [sum_u w_u s_u + Normal(0, sigma² C² I)] / N0
```

독립적으로 고정된 feature·전처리와 공개 고정 분모 N0에서 환자 추가/제거 민감도 상계는 C/N0이다. 환자 교체에서는 2C/N0에 맞춰 잡음을 정해야 한다. 표준 Gaussian 메커니즘이며 새로운 DP 정리는 아니다. 보호된 A/B를 복구한 뒤 PSD projection·ridge로 W를 구하는 것은 후처리다. 이 회계는 **해당 사적 적응 단계**를 다루며 공개 기반 모델의 과거 학습 참여까지 제거하지 않는다.

사진 수가 많은 환자라도 최종 벡터 norm을 제한한다. 여러 픽셀을 독립 환자로 세지 않는다. private count, feature 선택, 척도·C·ridge 선택, private validation을 무료 처리해서도 안 된다. 새 사적 통계를 계산하거나 사적 자료로 선택하면 별도 비용이 필요하다. 공개적으로 정한 값 또는 이미 보호된 값만 후처리로 이용할 수 있다.

Joint clipping 후의 A/B는 같은 환자 가중치 w_u가 붙은 **재가중 목적**이다. Gaussian과 PSD 처리를 거친 해는 noisy surrogate의 해다. 원래 목적의 정확한 최적해나 clipping bias 제거라고 부르지 않는다.

### 어디서 이득이 생기고 어디서 실패하는가

이 설계는 private backbone backward를 없앤다. 그러나 **같은 동결 head를 DP-SGD로 학습해도 backbone backward는 없다.** 그러므로 ‘역전파 제거’를 one-shot 통계 방식의 독자적 이득으로 세면 안 된다. 두 비교를 분리한다.

- **전체 DP-LoRA 대비:** 더 작은 함수족을 감수하고 backbone 역전파를 제거하는 품질–비용 절충.
- **같은 head의 DP-SGD 대비:** 동일한 표현·캐시·보호 단위에서 반복 최적화와 충분통계 보호 중 무엇이 유리한지.

공간 공유 때문에 보호할 좌표 수는 `d(d+1)/2 + 4d`이다. 설명용 d=64이면 **2,336개 통계 좌표**이고 head 파라미터는 256개다. ‘256개에만 잡음을 넣는다’는 표현은 틀린다. 통계 차원은 해상도와 별개지만 backbone forward·픽셀 누적 비용은 해상도와 함께 증가한다. 많은 noise 표본을 써야 하거나 d² 누적이 비싸면 총시간 이득도 줄어든다.

오차를 감당할 조건도 설명할 수 있다. clipped Gram에 ridge를 더한 `H=A_C+lambda I`, 그 최소 고유값을 kappa라 하고, 최종 후처리까지 포함한 통계 오차를 E_A/E_B라 하면 다음 표준 섭동식이 성립한다.

```text
W_hat - W_C = (H+E_A)^(-1)(E_B - E_A W_C)

if ||E_A||op <= kappa/2:
||W_hat-W_C||F <= (2/kappa) (||E_B||F + ||E_A||op ||W_C||F)
```

따라서 작은 feature 차원, 충분한 잔차 표현, 안정적인 Gram이 함께 필요하다. 차원을 줄이면 통계 잡음 부담은 줄지만 표현력이 떨어질 수 있다. 약한 고유값과 큰 잔차 head는 잡음에 취약하다. 이 식은 새 정리도 생성 품질 보장도 아니다. Denoising loss 감소와 생성영상 품질·임상 효용은 별도로 확인해야 한다.

## 3. 방향2 — 교차 증류 방어에서 실제로 고쳐야 할 데이터 경로 평가

### 어떤 방어의 어떤 전제를 보는가

| 실제 방법 | 연산·보장·평가 위치 | 이번에 구분하는 것 |
|---|---|---|
| [DualMD/DistillMD](https://arxiv.org/html/2410.16657v1), §§3.2–3.3, Eq.6–7, Algorithm 2 | 사진을 두 집합으로 나눠 teacher를 학습하고 반대 집합의 noisy input에 대한 출력을 student target으로 사용. Eq.6은 다른 shard를 test처럼 보는 가정이다. | 해당 사진 제외, 같은 환자의 모든 사진 제외, student의 원본 입력 재사용은 서로 다른 조건이다. |
| [Diffusion Soup, ECCV 2024](https://arxiv.org/html/2406.08431v1), §5.1 Prop.3, §6.2 | disjoint 자료의 모델을 합치고 조건부 NAF·복제 억제를 논한다. | NAF는 patient-DP가 아니다. 원래 sample 보장의 전제를 환자 전체 보호로 자동 확대하지 않는다. 원 정리를 반박한 것이 아니다. |

예를 들어 한 환자의 K장이 두 shard에 각각 독립적으로 1/2 확률로 배정되고 K≥1이면, **두 teacher 중 적어도 하나가 그 환자의 사진을 전혀 안 보는 확률**은 `2^(1-K)`다. K=10이면 약 0.195%다. 미리 지정한 teacher 하나가 안 보는 확률은 `2^(-K)`로 다르다. 이는 **가정한 분할의 정확한 조합 확률**일 뿐 공격 성공률이 아니다. 균형 고정 분할·기관별 분할에는 그 분할에 맞는 계산이 필요하다.

### 이 현상 자체는 이미 알려져 있다

직접 반론까지 확인했다. [SELENA](https://www.usenix.org/system/files/sec22-tang.pdf) App.A.3 Remark 7은 상관된 자료의 공격을 논한다. [Aerni et al.](https://arxiv.org/html/2404.17399v1) App.B.3는 다른 teacher가 본 near-duplicate의 누출이 self-distillation에 남는 것을 직접 분석한다. [Students Parrot Their Teachers, NeurIPS 2023](https://papers.nips.cc/paper_files/paper/2023/file/8b07d224a643b02e7571e083578a86d2-Paper-Conference.pdf) §3.1/App.D.1은 private teacher·private student·self-distillation을 나누고 비민감 teacher 아래 학생 입력의 누출도 다룬다.

따라서 **환자별 분할, teacher/student 4셀, 학생 입력 누출의 존재**만으로 새 평가 기여라고 말할 수 없다. 이 점이 방향2를 지금 당장 큰 실험으로 넘기지 않는 이유다.

남긴 구체 질문은 **“환자 단위 teacher 분할만 바꿀지, student 입력 단계까지 보호할지 결정할 수 있는가”**다. 교사 학습 원장과 학생 입력 원장을 감사용 참값으로 분리하고, 같은 배경·정책에서 각 경로의 참여 개입을 비교한다. 외부 공격에는 원장을 주지 않는다. 원형 방어, 표준 환자 분할, 독립 공개 reference 또는 student-DP 같은 기존 수리를 위험·효용·총비용으로 비교한다.

추가 가치가 되려면 알려진 누출을 다시 보여 주는 데서 끝나지 않고, **어떤 수리가 필요한지 예측하고 그 선택이 기존 단순 수리보다 나아지는 조건**을 설명해야 한다. 현재는 그 운영 질문까지 구체화했으며 새 진단법이나 성능 개선을 확정하지 못했다. 현재 보유한 non-DP LoRA 모델은 DistillMD가 아니므로 이 방어의 결과로 전용할 수도 없다.

## 4. 다음 한 작업과 왜 방향1부터인가

방향1은 바뀌는 연산, 정확한 비용 제거, 표현력의 대가와 잡음의 실패 조건이 연결되어 있다. 그래서 다음 작업은 **기존 공개 기반 모델의 작은 잔차 함수족이 목표 영상의 적응 신호를 실제로 담는지**에 집중한다. 이전 배분 규칙이나 관계 특징을 조금씩 바꾸는 작업으로 돌아가지 않는다.

먼저 forward 특징 위치·목적·환자별 통계·same-head 비교를 구현 명세로 고정한다. 구현 및 원 코드 대조에는 **약 30–60분의 작업 시간**을 예상한다. 실행시간은 기존 장치에서 짧은 feature 추출을 실측한 뒤 `총 forward 수 × 실측 단가 + 통계 누적·평가 비용`으로 보고한다. 아직 새 후보의 처리량을 측정하지 않았으므로 수백 시간이나 몇 배 가속을 확정하지 않는다.

첫 검증의 질문은 **“DP를 넣기 전에도 이 작은 표현이 의미 있는 적응을 담는가?”**다. 같은 head의 비보호 회귀, 기반 모델, 기존 비보호 LoRA의 차이를 보되 생성 품질을 단일 loss와 혼동하지 않는다. 그다음 같은 표현의 DP-SGD와 보호 통계를 대조하면 표현 부족과 보호 알고리즘 문제를 나눌 수 있다. 이 순서는 후보의 연결을 확인하는 계획이며 모든 강한 baseline의 실패를 먼저 요구하는 관문이 아니다.

방향2의 연구 질문도 유지한다. 다만 알려진 결과와 구별되는 보호 선택 원리를 더 좁히기 전에는 teacher/student 대량 학습을 자동 다음 작업으로 놓지 않는다. 이는 방향 폐기가 아니라 현재 근거와 준비 정도에 따른 순서다.
