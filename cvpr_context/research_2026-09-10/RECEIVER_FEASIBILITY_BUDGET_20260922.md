# 첫 A1/A2 비교 예산 결정 — 2026-09-22

**각128장·200회·seed101, A1/A2 총2bank로 정한다.** 이전500회안의40% 학습량이다. 200회는 계산비와 첫 가설 확인을 절충한 개발 선택이며, 최소 필요량·최적값·수렴 보장이 아니다.

사용자의 “정해” 요청에 따른 예산 결정이다. 이번에는 코드나 목표를 바꾸거나 GPU/학습을 실행하지 않았다. [A1 목표·실행 연결](RECEIVER_A1_TARGET_RUNTIME_RESULTS_20260922.md)의 기술 증거와 과거 음성 결과는 보존한다.

## 고정 규모와 일정

| 항목 | 첫 비교 |
|---|---|
| Bank | A1(BioViL), A2(BioViL+두 번째 공개 encoder), 각1개 |
| 영상·label | 각128장, 음성64/양성64 |
| Seed | 101 하나 |
| 조건 | 고정 head/변환 K4 |
| Update | 각200회 |
| Microbatch | 16 |
| Optimizer | 기존 AdamW lr0.01, weight_decay0, betas0.9/0.999, eps1e-8 |
| 합성 목적 | 조건별 CE gradient cosine + anchor0.01 + TV0.0001 |
| A2 결합 | equal-weight mean, smooth-max 추가 없음 |
| 산출물 선택 | 마지막200회 PNG, 중간 checkpoint 효용 선택 없음 |

공개 template, 초기화, BioViL 목표·head·변환·P-only PCA16/q95, 환자/class 가중치를 유지한다. 준비된 A1 P/Q 목표는 다시 추출하지 않는다. 두 조건은 동일한 update 수·영상 수를 사용하지만 **A2는 encoder가2개이므로 같은 총FLOPs/GPU시간의 비교는 아니다.** 추가 계산량을 함께 보고한다.

## 200회용 pyramid

500회 스케줄을200회에 비례해 압축한다. 단순히 기존 학습을200회에서 자르지 않는다.

| 잔차 해상도 | 활성화 update |
|---|---:|
| 8 |1|
|16|33|
|32|65|
|64|97|
|112|129|
|224|161|

마지막224 수준은161–200의40회 학습한다. 단계별 길이는32/32/32/32/32/40이다. 기존500회의80/80/80/80/80/100 비율을 유지한 것이다. 표현할 수 있는 최종 해상도를 줄인 것은 아니지만, 각 수준의 최적화 횟수는 줄어든다.

## 시간과 상한

- **A1 합성 약39.3분**: 실제 전체128/K4 update 평균11.781초×200. 대략31–49분은 계획용 변동 범위이며 통계적 구간이 아니다.
- **A2는 미측정**이다. A1 시간에 단순히2를 곱한 값을 실측처럼 쓰지 않는다. 두 번째 encoder가 연결되면 제한된 공개 비용 확인 한 번으로 안내한다.
- 합성 실행 상한: **A1 60분, A2 120분**. 각 worker의 시작·학습·checkpoint·PNG 저장을 포함한다. 합성 합계상한180분은 예상완료시간이 아니다.
- 미완료 A2 모델/target 준비와 수신자 평가는 별도다. 따라서 현재 전체 작업의 총예상시간을 확정하지 않는다.
- 상한에 도달하면 검증된 checkpoint에 멈춘다. 서로 다른 완료step의 결과를 같은200회 비교로 보고하거나 상한을 자동 연장하지 않는다.

A1 200회는204,800 image-forward/102,400 image-backward다. A2는 encoder마다 같은 횟수이며 총409,600F/204,800B다. 이 image-evaluation 합계는 서로 다른 architecture의FLOPs 동일성을 뜻하지 않는다.

## 결과 전에 고정하는 개발 판정

두 bank가 모두200회 완료·PNG 고정된 후 같은 V의 BioViL·DenseNet readout을 함께 읽는다. DenseNet은 개발 receiver이며 unseen이라 부르지 않는다.

다음을 모두 만족하면 **추가 반복을 검토할 개발 신호**로 분류한다.

1. DenseNet A2−A1 AUROC ≥ +0.02.
2. DenseNet A2−A1 AP ≥ 0.
3. BioViL A2−A1 AUROC ≥ −0.02.

이는 투자 판단을 위한 시작 기준이지 문헌에서 보장된 성공선이 아니다. 동일한 기존 환자 bootstrap 배열로 구간도 보고하되, CI가0을 포함한다는 이유로 동시에 상반된GO/STOP 규칙을 적용하지 않는다. 한 seed의 point estimate가 이 기준을 충족해도 효용 입증이나 논문 완성이라고 하지 않는다.

조건 미충족이면 이번200회 recipe의 기준 미충족/혼합 결과로 남긴다. 500회 자동 연장, 새seed, coefficient/encoder 탐색이나 DP를 자동 실행하지 않는다. 200회 음성 결과로 해당 방향 전체가 불가능하다고 단정하지 않는다.

기존B500회 및 공개 실자료 readout은 참고값으로만 병기한다. 서로 다른학습 예산을 동일 조건의 개선 증거로 쓰지 않는다.

## 실행 전 남은 최소 변경

이번 결정은 기록만 했다. 현재 검증된 runtime은 여전히500회와 기존 활성화 일정을 요구하므로, 이전 `main_proposal_job.json`을200회 job인 것처럼 실행하면 안 된다.

다음 구현은200회 일정과 checkpoint의 논리적 step 복원이 같은 규칙을 쓰도록 연결하는 것이다. 공개 목표 재추출이나 기존검사 전체 재실행은 하지 않고,32/33 등 바뀐 활성화 경계와 재개 상태만 작은 CPU 검사로 확인한다. A2 adapter/목표 준비는 별도 미완료다.

구체 budget은 `code_working/_reports/receiver_feasibility_budget_20260922_v1/budget.json`에 저장했다. 이 결정을 새코드·실제목표 hash와 결속한 후 첫 비교를 실행한다. 이번에는 새학습·V평가·A2실행·DP/final0이다.
