## 이번 비교가 답하는 범위

목표 기능 자체: BioViL target에서 C−B AUROC는 +0.000140, C−D는 -0.005577이다.
합성자료에서의 source 결과: BioViL PNG에서 C−B는 +0.000479, C−D는 -0.003051이다.
기존 수신자 결과: DenseNet C−B는 -0.059134, C−D는 -0.093984로 이전 음성 결과와 같다.

1. 목표 분류기 전체가 무용한 것은 아니다. B/C 목표의 BioViL AUROC는 약0.778로, 이 V에서 단일 영상 판별 신호가 있다. 다만 실제 관계를 더한 C−B는 +0.000140이고 조건부 95% 구간 [-0.006667, +0.006583]은0을 포함한다. AP는 소폭 낮다. 실제 대응 C가 교란 D보다 유용하다는 근거도 확보하지 못했다.
2. B/C의 source 성능은 합성자료에서 잘 재현됐다. C는 target0.777931에서 PNG0.778057로, AP도0.126072에서0.126031로 거의 같았다. B도 차이가 작다. D에는 AUROC 약0.002401과 AP 약0.011462의 감소가 있다. 이 결과는 B/C가 유용한 source 판별 기능을 합성자료에 담지 못했다는 설명과 맞지 않는다. 다만 J_func를 끈 제거실험은 없으므로 이 재현이 기능 정합 항 하나의 인과 효과라고 하지는 않는다.
3. 관계의 추가 가치와 전이는 구분해야 한다. 목표 단계의 C−B가 이미 거의0이므로 문제를 전이 실패 하나로만 설명할 수 없다. 동시에 source에서의 높은 성능이 DenseNet의 C0.508841로 이어지지 않았으므로, 다른 encoder의 재사용 가치도 확인되지 않았다. 서로 다른 표현의 성능 차이만으로 전이 실패의 단일 원인을 확정하지 않는다.
4. 현재 목표를 같은 설정으로 더 오래 복제하는 학습을 자동 확대할 근거는 이 비교에서 얻지 못했다. 요청된 비교를 완료하고 멈춘다. 단일 seed101과 반복 사용된 개발 V의 결과이며, 관계 활용 전체가 불가능하다는 결론은 아니다.

이 결과로 세 지점의 실제 판별 성능을 나눠 확인할 수 있다. 이번 비교는 관계 자체·표현·보강 계수·영상 실현 중 실패 원인을 하나로 확정하거나, source 결과만으로 모든 다른 모델 전이를 불가능하다고 판정하지 않는다. 새 학습·seed·loss·DP를 자동으로 추가하지 않았다.

## 무엇을 계산했는가

- 기존 B/C/D target 통계와 최종 PNG source 특징을 재사용했다. 기존 source 기능 정합 값을 같은 학습 규칙으로 재계산했다.
- B beta0, C/D beta1, ridge0.1, 상대 반경 rho²=0.1·w0ᵀMw0를 유지했다. 목표/PNG는 각각 자기 모멘트의 같은 guarded learner를 사용한다.
- 점별 BioViL 특징 z와 P-only PCA16·전처리를 유지했다. raw 특징으로 점수 체계를 바꾸거나 새로운 projection을 만들지 않았다.
- 부재했던 BioViL V point 특징만 frozen/eval/no-grad, microbatch16으로 추출했다. Q/P 원영상·Expert/Reserved 접근은0이다.
- 기존 DenseNet 예측은 원파일 해시를 확인해 그대로 사용했다. 새 recipient 모델 실행0, 합성/분류기 optimizer update0이다. 여섯 readout은 기존 작은 선형계의 결정론적 해다.
