# 2-2R2 — 공개 대응 가중치 교차 결과

**결론: ‘환자 균등 대응 가중치가 HR와 강화 KD를 함께 개선한다’는 사전 가설은 통과하지 못했다. HR에서는 환자 균등이 유리했지만, 강화 ACKD에서는 오히려 class 균형이 유리했다. 같은 환자 균등 가중치에서 HR의 추가 AUROC 이득은 남았다.**

이번은 기존 HR 성능을 새로 높인 실험이 아니다. 실제 개선이 관측됐던 구성의 원인을 대조한 실험이다. 결과는 가중치의 효과가 recipe에 따라 다르다는 현재 조건의 관측이며, 이것을 새 보편적 설계 원리나 CVPR 기여로 자동 전환하지 않는다.

## 실행 범위

최초 공개128과 기존 DP1/DP2를 고정했다. HR-B와 ACKD-U 각각 두 release의 새 라벨4개를 계산하고 봉인한 뒤 DenseNet·ResNet18의8readout을 평가했다. 기존 HR-U, ACKD-B, DINO-only의12readout은 bitwise 그대로 재사용했다.

- U: 각 공개환자 총가중치 균등, 환자/class·방문으로 나눔.
- B: 각 class 총가중치0.5, class 안에서 환자·방문 균등.
- 변경 대상은 공개 모델 사이의 **대응 회귀 가중치**다.
- 질환 학습용 class 균형, H_D/H_R·ridge0.1, 공개 source midpoint, λ 수치, 첫 공개128, RN-only label solver는 유지했다.
- HR의 fitted 평균/절편은 대응 가중치 변경의 결과로 바뀐다. ACKD의 실제 공개 RN anchor는 고정했다.
- 새 Q/noise/release/pixel 학습/model forward/Expert/Reserved는0이다.

## 무엇이 확인됐는가

1. **기존 HR에서 환자 균등 대응 가중치는 실제 효용에 기여했다.** 그 한 설정을 B로 바꾸면 이번 두 보호 head에서 DenseNet AUROC가 낮아졌다. 공개 대수상 큰 차이가 있었다는 진단을 넘어, 현재 HR 안에서의 성능 효과를 확인한 것이다. AP의 평균 구간은0을 포함한다.

2. **‘KD에도 같은 가중치만 주면 개선된다’는 예측은 반대 방향으로 나왔다.** 따라서 양성6명에 대한 가중치 집중만으로 HR와 ACKD의 성능 차이를 공통 설명하는 가설은 이번 조건에서 지지하지 않는다. 새 가중치 grid나 λ 탐색으로 이 판정을 바꾸지 않는다.

3. **같은 U에서 HR가 더 좋다는 관측은 남는다.** 두-release 평균 AUROC 차이 +0.060416이고 각 release 차이도 양수다. 이는 현재 전체 연산 구성의 차이이며 clipping·중심화·환자 평균 중 특정 요소가 원인이라는 증명은 아니다.

4. **같은 B에서는 차이가 작고 미확정이다.** HR-B−ACKD-B의 평균 +0.007334, 구간0포함이다. 따라서 어떤 대응 가중치에서도 HR의 추가 가치가 동일하게 유지된다고 주장할 수 없다.

5. **가중치와 recipe의 상호작용은 이 고정 설정에서 관측됐지만, 새 중심 기여로 승격하지 않는다.** 이 interaction은 사전에 보조 대비로 정한 값이다. 두 기존 보호 실현·한 carrier·재사용 V에 조건부이며, 일반적인 DP noise 분포나 다른 cohort로 일반화되지 않았다.

원래 HR-U−ACKD-B 격차 +0.035346은 두 경로로 분해된다.

- HR-U−HR-B + HR-B−ACKD-B = +0.028012 +0.007334.
- HR-U−ACKD-U + ACKD-U−ACKD-B = +0.060416 −0.025069.

이처럼 분해 경로에 따라 항의 크기와 부호가 달라진다. ‘기존 이득의 몇%가 가중치 때문이다’처럼 유일한 인과적 비율로 해석하지 않는다.

## 통계·검산·범위

영상 AUROC/AP이고, 같은2,000회 환자-cluster paired bootstrap을 사용했다. 각 회차에서 DP1/DP2의 metric 차이를 계산하고 그 차이들을 평균했다. 예측 앙상블이나 서로 독립인 환자 cohort로 취급하지 않았다. 구간은 고정 carrier·라벨·두 보호 실현에 조건부다. 보조 비교 전체를 하나의 확증적95% 주장으로 사용하지 않는다.

- 입력20개·기존/실행 코드28개·과거 보고서10개 해시 불변.
- 새 목표4개는2-1R2의 봉인된 설계 목표와 bitwise 일치.
- 기존12개 예측/부트스트랩 재사용값도 bitwise 일치.
- 라벨 KKT 최대2.22e-16, ridge primal/dual3.61e-16, bootstrap 독립 witness1.11e-16.
- 모든 대비와 CI를 저장 배열에서 다시 계산한 오차0.
- 새 라벨 봉인 이후에만 V 평가가 실행됐음을 접근 로그로 확인.
- 목표/라벨 계산1.312초,8readout/부트스트랩7.407초. 코드 연결·검산·보고까지의 전체 실측은 finalization.json과 아래 완료 기록에 남긴다.
- 추가 결과 약4.36MiB(최종 보고 전). GPU 학습 없음.
- 실행 중 실패·재시도·결과에 따른 설정 변경 없음.

기존 첫선정 HR−DINO DP2 음수, 원래2-3 보류,2-3R1의 AKD 비교 미확정은 그대로다. 이번 결과를 근거로 이를 통과 처리하지 않는다.

## 다음 번호와 한정된 작업

**다음 제안은 2-1R3: 공개 기준값 항과 전달 연산의 차이를 한 번 분해하는 설계 정리다. 예상15~25분.** 이번의 공통 가중치 가설은 종료한다. 곧바로 가중치 반복이나 새로운 성능 조합을 실행하지 않는다.

범위는 기존 공개 행렬·보호 head·이번 고정 결과와 앞서 확인한 CME/POST 연산을 재사용하는 것이다. 새 V 평가·라벨·Q·release·receiver는0이다.

구체적으로, 같은 U에서 두 식을 ‘source class 차이에 작용하는 선형 연산’과 ‘공개 기준값 항’으로 나눈다. HR의 mapped 기준값과 ACKD의 실제 공개 라벨 기준값이 서로 다르다는 점을 명시한다. 가중치 변경은 HR에서는 이 두 부분을 함께 바꾸지만 ACKD에서는 실제 공개 기준값을 고정했으므로, 다음에 어떤 항을 고정해야 한 가지 질문에 답할 수 있는지 정한다.

산출물은 **표준 조건부 평균 전달로 설명되는 부분 / 아직 분리되지 않은 항 / 필요하다면 대조 하나의 정확한 설계**다. 새로운 원리를 발명한 것처럼 이름 붙이지 않는다. 이 정리에서 같은 연산으로 귀결되면 동치로 기록하고 가짜 새 baseline을 실행하지 않는다. 추가 대조의 필요성이 없으면 더 많은 변형 실험으로 이어가지 않는다. 연구 전체의 독자적 기여는 여전히 별도 판단 대상이다.

이번2-2R2는 허용된4라벨·8평가로 종료했다. 다음 설계는 아직 실행하지 않았다.
