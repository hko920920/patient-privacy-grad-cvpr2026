# 전 과정 재검토: 연구 진단과 논문 기여의 연결

2026-09-18. 큰 단계 2의 방향 검토. 새 학습·모델 추론·생성·환자 영상 접근·DP 실행은 없다.

**판정: 문제의 가치는 남아 있지만, 현재 진행을 ‘CVPR 기여에 잘 수렴하고 있다’고 평가할 근거는 부족하다.** 최근 작업은 실행 오류와 일반화 문제를 좁히는 데 유용했지만, 원래 제안한 보호·효용·전체 비용상의 이득을 입증하지 못했다. Rwide의 양성 결과까지 포함해도 이 판단은 바뀌지 않는다. 현재 작업 방식을 그대로 연장하기보다, 관측된 진단을 하나의 기여 가설과 공정한 연구 설정으로 다시 연결해야 한다.

이는 현재 문제를 폐기하거나 다른 주제가 더 유리하다고 결정한 것이 아니다. 새 알고리즘 발명을 필수로 요구하지도 않는다. 사용자에게 앞선 각 단계의 타당성을 설명하면서, 그 단계들이 논문 중심 주장에 얼마나 기여했는지를 더 엄격하게 구분했어야 한다.

## 1. 처음의 목표와 실제 이동

[원래 목적](RESEARCH_PURPOSE.md)은 의료 생성모델의 환자 보호 보장과 재사용·재학습 판단이었다. 공격은 보호 평가의 수단이었다. 이후 별도의 환자 공격 기여를 탐색했고, 사용자는 9월 16일 원래 졸논 목표의 변경도 허용하면서 보호 설계·효율과 보호 평가 개선 두 방향을 선택했다. 목표 변경 자체는 승인된 연구 판단이다.

현재 방향1에서 보존할 중심 질문은 다음이다.

> 공개 생성모델의 표현을 재사용해 사적 환자자료를 적은 계산으로 보호하면서도 유용한 합성자료를 만들고, 같은 자료 접근권과 환자 DP에서 기존 적응보다 유리한 효용–비용 절충을 얻을 수 있는가?

‘작은 head를 반드시 성공시킨다’, ‘SSP가 반드시 DP-SGD를 이긴다’, ‘새 DP 수학을 발명한다’, ‘기흉 AUROC를 어떤 방법으로든 높인다’는 이 질문과 동일하지 않다.

| 경로 | 실제로 추가한 근거 | 아직 추가하지 못한 기여 |
|---|---|---|
| 환자 E/U 공격·집계·개입 진단 | 기존 공격의 사용 조건과 제한, 일부 반응·집계 효과 | 기존 강한 방법을 넘어서는 환자 노출 평가법 |
| 계산 배분·순차 감사 v0 | 근접 선행과의 중복, 고정 비교에서 자체 초안의 음성 결과 | 새 배분 규칙의 효율 우위 |
| frozen 특징 + full64 head | 제한된 함수족에서 denoising MSE 감소, 충분통계 해의 실제 구현 | 실제 생성 효용, 환자 DP의 유리한 전체 절충 |
| 초기 SD2.1 head의 환자 DP 비교 | same-head DP-SGD가 MSE 이득 상당 부분 유지, joint-SSP의 floor 손실 확인 | SSP 우위, 공개전용 대비 사적 추가 효용 |
| 공개 E4 의료 backbone | 기본 흉부 형태와 sampling 적용 경로 확보 | 질환 정확성 또는 새 생성 방법 기여 |
| 의료 head의 192장 비교 | public head의 일부 KID 개선 | pooled의 private incremental utility |
| 환자 사용 감사·두 평가기·expert 라벨 확보 | 독립 역할, 실패한 평가 방식의 범위, 보존 가능한 최종 실영상 test | 사적 생성 효용 자체 |
| 512장 downstream 비교 | 현재 head 구성의 효용 관문 실패, Dreal의 제한적 양성 대조 | private synthetic이 public/real 기준보다 낫다는 근거 |
| 기존 LoRA 공개/pooled 대조 | 다른 기존 적응 구성을 실제 시험, 해당 고정 구성도 관문 실패 | head 용량만이 원인이라는 증명 또는 사적 추가 효용 |
| 고정 분류기 학습자료 재추론 | eval에서도 학습영상 구별력 유지, 큰 일반화 차이 | 일반화 실패의 단일 원인 |
| Rwide 실자료 범위 확대 | 동일 분류기에서 확대 real pool의 개발 성능 개선 | 합성 전달, 보호 방식, 기존 방법 대비 비용–효용 기여 |

각 진단이 아무 의미 없었던 것은 아니다. 다만 서로 다른 질문의 양성 결과를 합산해 하나의 privacy 방법이 점점 검증됐다고 해석해서는 안 된다.

## 2. 가장 중요한 누락: 원래 보호 방식의 성적도 다시 봐야 한다

[초기 환자 DP 결과](TRACK1_PATIENT_DP_RESULTS_20260916.md)는 이후 의료 backbone 실험보다 앞선 일반 SD2.1 조건이다. 따라서 ‘지금까지 DP를 한 번도 실행하지 않았다’는 전체 역사 서술은 틀리다. **초기 고정 특징의 DP denoising 실험은 수행했고, 현재 의료 생성/downstream 경로의 DP 확대는 수행하지 않았다.**

full64 개발 MSE는 다음이었다.

| 방법 | MSE, 낮을수록 좋음 |
|---|---:|
| 공개전용 | 0.1740411864 |
| private80 비DP | 0.1740069294 |
| 같은 head의 환자 DP-SGD | 0.1743888460 |
| joint-SSP | 0.1788939244 |

SSP의 선택된 eigenvalue floor가 무잡음 대조에서도 적응을 크게 약화시켰다. 잡음 Gram을 안정화할 필요와 신호 손실 사이의 문제가 실제로 관측됐다. DP-SGD 역시 공개전용보다 좋은 private increment를 확보하지 못했다.

이 결과는 모든 SSP의 실패나 의료 E4 위 DP 결과가 아니다. 그러나 현재의 원형 보호 solver를 유망한 완성 방법처럼 전제해서는 안 된다는 직접 근거다. 이후 분류기 일반화 개선이 이 문제를 해결한 것도 아니다.

비용도 동일하다. full64 fit만 보면 SSP 약 0.015초, 같은 head DP-SGD 약 0.534초였지만, 둘은 같은 캐시를 사용했고 이전 특징 추출에는 약 314.7초가 들었다. 그 추출 시간에는 학습/평가 범위가 포함되므로 이를 새 방법의 정확한 학습 속도비로 단순 환산하지 않는다. **작은 solve 구간의 배수는 전체 학습·생성 비용의 배수가 아니다.** 동일 head DP-SGD에 반복 UNet backward 비용을 부과하는 비교도 잘못이다.

따라서 현재 남은 문제는 두 개다. 유용한 private adaptation을 합성자료에 전달하는 문제와, 그 효용을 보호하면서 실제 총비용 절충을 개선하는 문제다. 하나의 진단 양성으로 둘을 동시에 해결했다고 할 수 없다.

## 3. Rwide는 무엇을 바꿨고 무엇을 바꾸지 않았나

[최신 Rwide 결과](TRACK1_REAL_SUPPORT_DIAGNOSTIC_RESULTS_20260917.md)는 허용 학습 pool을 672명·813장에서 2,699명·5,910장으로 넓혔다. 기흉 양성 환자는 6명에서 120명으로 늘었고, 같은 400 step·세 seed에서 개발 AUROC는 0.544610에서 0.679434, AP는 0.051669에서 0.103542로 개선됐다. AUROC 차이의 환자 paired bootstrap 구간은 [+0.084156, +0.187751]이다. 이는 실자료 범위 대조에 유의미한 양성 개발 근거다.

그러나 추가 2,027명은 이전 classifier-selection을 진단 학습에 전용한 자료다. private80의 합성영상이나 DP 모델이 아니다. 이 모델을 원래의 공개전용 baseline으로 교체하면 자료 접근 조건이 달라진다. private80에 대한 기존 효용 실패도 유지된다.

Rwide는 ‘같은 분류기·약한 개발 라벨에서 어떤 자료 범위에도 성능이 나올 수 없다’는 설명을 약화시킨다. 하지만 다음을 확정하지 않는다.

- 양성 6명 또는 반복 노출만이 유일한 원인이었다.
- 더 많은 환자를 생성기에 넣으면 합성 효용도 회복된다.
- 기존 head/LoRA 생성물은 사실 유용했다.
- 현재 0.6794가 충분한 임상 성능이나 경쟁력 있는 benchmark 성능이다.

학습 환자 범위, 영상 다양성, 동반소견, 반복 노출 등이 함께 변했다. 같은 개발자료를 반복 사용한 이력과 고정 학습 모델에 조건부인 불확실성도 유지한다.

## 4. 가까운 선행과 비교하면 무엇이 남는가

아래는 이번에 공식 논문·저자 자료에서 재확인한 근접 범위다. 전 문헌의 부재를 증명한 신규성 전수조사가 아니다.

| 이미 있는 접근 | 현재 기여에서 구분할 사항 |
|---|---|
| [DP-LoRA, ICCV 2025](https://openaccess.thecvf.com/content/ICCV2025/html/Tsai_Differentially_Private_Fine-Tuning_of_Diffusion_Models_ICCV_2025_paper.html) | 공개 LDM의 일부 parameter를 LoRA로 DP 적응하고 생성 품질과 downstream 효용을 평가한다. ‘작은 adapter + DP + downstream’만으로 차별화되지 않는다. |
| [DP-LDM, TMLR 2024](https://arxiv.org/abs/2305.15759) | 잠재 공간 및 선택적 attention 적응으로 DP 생성의 비용·효용을 다룬다. 작은 부분만 업데이트한다는 일반 명제는 이미 있다. |
| [DP-MEPF, TMLR 2023](https://openreview.net/forum?id=R6W7zkMz0P) | 공개 perceptual 표현으로 private 통계를 한 번 보호해 생성 학습에 재사용한다. 공개 표현과 one-shot 보호 자체는 신규 원리가 아니다. |
| [Private Evolution, ICLR 2024](https://proceedings.iclr.cc/paper_files/paper/2024/hash/96ddb8106a3f47a4b2ed755b3edd865a-Abstract-Conference.html) | 생성모델의 추론 API만으로 DP 합성자료를 만드는 학습 없는 경로가 이미 있다. 사적 backbone backward를 없앴다는 사실만으로도 새 기여가 되지 않는다. 고정 크기의 합성자료와 재사용 가능한 적응 생성기라는 출력 차이, 반복 추론 비용을 구분해 비교해야 한다. |
| [PDA-DPMD, ICML 2022](https://proceedings.mlr.press/v162/amid22a.html) | 공개 loss의 geometry와 사적 DP gradient를 결합한다. 공개 곡률을 쓴다는 사실만으로 새로운 solver라 할 수 없다. |
| [DPImageBench](https://arxiv.org/abs/2503.14681) | 공개 자료 접근, 생성기, downstream validation/test 분리를 맞춘 비교와 기존 효용 평가의 문제를 연구한다. 엄밀한 평가·split 관리 자체만으로 새 benchmark 기여가 되지는 않는다. |
| [Mind the Privacy Unit](https://arxiv.org/abs/2406.14322) | 사용자 단위 학습과 다중 기록의 보호가 기존 연구 대상이다. 환자 단위 clipping을 적용한 사실과 전체 응용 기여를 구분해야 한다. |

이것이 ‘원리가 알려졌으므로 응용 기여는 불가능하다’는 뜻은 아니다. **환자 단위 보호, 필요한 생성 적응 능력, 전체 계산비용을 함께 만족하는 구체적인 구성과 재현 가능한 이득**은 기여 후보가 될 수 있다. 알려진 solver가 가장 좋다면 그것을 사용해도 된다. 새 수학이나 모든 baseline의 실패가 방법 제안의 선행 조건은 아니다.

현재는 그 이득이 미확보다. 또한 성공 조건이 ‘어떤 수치든 SOTA보다 높음’인 것도 아니다. [CVPR 2026 reviewer 지침](https://cvpr.thecvf.com/Conferences/2026/ReviewerGuidelines)은 SOTA 정확도 미초과만으로 거절하지 말고 신규성과 잠재 영향을 함께 보도록 한다. 이 연구의 부족한 점은 단순 순위가 아니라, 주장할 추가 가치와 이를 뒷받침하는 증거가 아직 연결되지 않았다는 점이다.

## 5. 연구 운영에서 바로잡을 점

### 5.1 실험의 국소적 타당성과 전체 전략을 혼동했다

평가기 검증, 안전한 classifier 진입점, LoRA 대조, Rwide는 각각 답할 질문이 있었다. 그러나 ‘이 검사는 타당하다’에서 ‘이 길이 논문을 만드는 데 계속 최선이다’로 넘어갈 근거는 별도다. 후자를 매번 재검토하지 못했다.

실패를 보존하고 final을 닫은 것은 옳았다. 반대로 자료 확보, hash/산술 검산 통과, 기본 형태 안정화를 방법 기여에 가까워진 정도로 과대평가하면 안 된다. 검산 수는 실험의 신뢰성을 돕지만 효과 크기나 새 지식을 늘리지 않는다.

### 5.2 핵심 적용성과 측정 경로를 더 일찍 연결했어야 한다

초기 MSE 검사는 저렴한 구현·표현력 확인으로 타당했다. 하지만 생성과 목적에 맞는 downstream 효용이 중심이라면, 그 연결이 실제로 작동하는지도 더 일찍 확인할 필요가 있었다. 이후 ‘MSE 감소 → 형태 생성 → KID → 질환 분류 점수 → downstream’으로 측정 경로가 길어졌다.

이를 결과 조작으로 볼 근거는 없다. 다만 전제가 추가될 때마다 기여까지 필요한 일이 늘어나는 전략상의 비용이 있었다. 두 평가기 실패를 측정 전체의 불가능으로 확대한 판단, head 실패를 용량 부족·새 task-aware 방법 필요로 확대했던 판단도 근거를 넘었다.

### 5.3 개발 단계의 수정과 최종 확인의 엄격함을 구분해야 한다

고정 실행의 결과는 그대로 보존한다. 그 뒤 개발자료에서 자료 구성·학습량·모델을 근거 있게 바꾸는 것은 허용되는 연구다. 변화가 반드시 새 알고리즘이어야 하는 것은 아니다.

반면 결과가 나올 때까지 조건을 바꾸면서 같은 확인 실험으로 포장하면 안 된다. +0.01·2/3 seed는 자원 투자를 위한 사전 규칙이며 효과 부재의 과학적 증명은 아니다. 한 번 미통과했다고 모든 관련 개발을 금지하거나, 미통과를 취소하려고 기준을 낮추는 두 극단을 피한다.

### 5.4 우리 설정의 어려움이 곧 분야의 새로운 문제는 아니다

공개 양성 6명, private80, 작은 bank, 현재 classifier recipe는 우리가 택한 실험 조건이다. 그 조합의 실패가 곧 기존 분야가 해결하지 못한 일반 문제를 뜻하지 않는다. Rwide에서 더 넓은 실자료가 도움이 된 사실도 그 자체로 새 보호 방법 기여는 아니다.

실제 사용 시나리오와 연결된 공개/사적 접근 조건을 정해야 한다. NIH 내부의 역할 분할은 통제된 privacy 연구에 쓸 수 있지만, 서로 다른 병원에 대한 domain adaptation 또는 사적 자료만의 고유 정보라고 부르지는 않는다.

## 6. 현재 기여 장부

| 논문에서 말하고 싶은 것 | 현재 판정 |
|---|---|
| 작은 head를 정확하게 학습·적용할 수 있다 | 구현 및 제한적 denoising/생성 변화 근거 있음 |
| 공개전용보다 사적 자료를 쓴 합성자료가 유용하다 | 두 고정 head/LoRA 개발 구성에서 관문 미통과 |
| 그 추가 효용이 환자 DP에서도 유지된다 | 현재 의료 생성 경로에서는 미시험 |
| SSP가 같은 head DP-SGD보다 좋다 | 초기 조건에서는 반대 결과 |
| 제한된 표현이 강한 DP 적응보다 유리한 전체 비용–효용을 준다 | 아직 대조 결과 없음 |
| 새로운 일반 평가 현상/해결법을 발견했다 | 현재 단일 설정의 진단만으로는 부족 |
| 더 넓은 real pool이 같은 classifier의 개발 성능을 개선한다 | Rwide에서 확인. 비DP 자료 범위 진단 |
| 현재 결과만으로 CVPR 중심 기여를 서술할 수 있다 | 부족 |

따라서 현재 상태는 **실험 기반과 여러 진단은 확보했지만, 핵심 기여 가설은 아직 검증되지 않은 탐색 연구**다. 실험을 많이 했다는 이유로 논문 완성 단계라고 부르지 않는다.

## 7. 지금 권고하는 방향과 다음 작업의 기준

보호 설계·효율이라는 목표를 즉시 버릴 근거는 없다. 다만 원형 full64/SSP의 성공을 전제로 추가 실험을 이어가는 방식도 권하지 않는다. 현재 반복적인 후속 진단 목록은 자동 실행하지 않는다.

**유지할 기여 후보는 ‘공개 표현을 재사용해 사적 backbone 학습 부담을 줄이면서, 실제로 쓸 수 있는 합성 효용을 환자 DP 아래 제공하는 구성’이다.** 이것은 아직 후보이며 현재 full64 구성의 채택 선언이 아니다. 이 후보를 검토하려면 아래 네 가지를 같은 설계에서 닫아야 한다.

1. **사용 목적·자료 접근:** 제공하려는 것이 합성자료/생성기인지, 한 개 분류기인지 분명히 한다. 공개 pool과 보호 대상 환자 pool, 개발자료의 접근·선택 이력을 고정한다. Rwide 자료를 묵시적으로 공개화하거나 과거 selection을 다시 미사용 validation으로 부르지 않는다.
2. **작동할 이유:** 이미 관측된 어떤 제약을 어떤 기존/변형 구성으로 바꿀지 설명한다. 원인 전체의 증명이 먼저 필요하지는 않지만, 단지 다른 설정을 아직 안 해봤다는 이유는 부족하다. 현재 증거로는 자료 범위의 영향이 관측됐고, 이를 생성 적응으로 옮겼을 때의 결과는 미확인이다.
3. **핵심 결과 표:** public-only, 같은 특징의 강한 patient-DP-SGD, 적절한 patient-DP LoRA를 동일 보호·자료 접근에서 비교한다. 표현 구성의 가치와 SSP solver의 가치를 분리한다. 사적 backbone 학습 제거가 핵심이면 Private Evolution의 추론 기반 경로도 가까운 비교 대상이고, 공개 특징·일회 보호가 핵심이면 DP-MEPF와의 차이도 설명해야 한다. 출력물과 접근권을 맞춰 필요한 기준선을 정하되 모든 방법을 지금 일괄 실행할 필요는 없다.
4. **효용과 비용:** 공개전용 대비 사적 추가 효용, 동일 품질에서 줄어드는 adaptation 비용 또는 동일 비용에서 얻는 효용을 함께 정의한다. 특징 추출·공개 준비·fit·생성을 분리하고, 총비용 및 재사용 시 상각 비용을 구분한다. 출력이 단일 분류기뿐인 사용 목적이라면 직접 환자-DP 분류기와의 실용 비교도 검토하되, 재사용 가능한 합성자료/생성기와 무조건 같은 제품으로 취급하지 않는다.

이 표의 중요한 칸을 채우거나 채울 가능성을 직접 판별하는 실험을 다음 패키지로 묶어야 한다. 단순히 또 하나의 전처리·loss·score 이상을 발견하는 것으로 끝나는 패키지를 기본 다음 단계로 삼지 않는다. 그렇다고 지금 당장 현재 실패 구성을 DP로 확대하라는 뜻은 아니다. 현재 데이터 접근 조건에서 non-DP 전달 가능성을 판단할 설계가 먼저 필요하며, 비용 측정·선행 대조는 그 설계와 함께 수행할 수 있다.

현재 감사만으로 새로운 adapter, 새 환자 pool, 추가 generator 학습을 선택하지 않았다. 원래 문제를 유지할지와 무엇을 구현할지는 별도의 근거 있는 연구 선택이다. 여기서 새 주제의 성공 확률이 더 높다거나 지금 주제의 성공 확률이 높다고 수치화할 근거는 없다.

**현재 운영 결정:** 기존 full64와 고정 LoRA의 음성 결과 보존, 의료 생성 경로 DP 확대 보류, expert final 532명·reserved 4,213명 보존. 다음은 끝없는 추가 진단이 아니라 위 기여 후보의 자료 접근·비교·효과·비용을 하나로 묶는 설계 판단이다. 이미 보유한 기록으로 가능한 판단은 이번 문서에서 완료했다.
