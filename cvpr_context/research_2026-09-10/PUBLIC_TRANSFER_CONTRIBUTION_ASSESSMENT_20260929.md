# HR 공개 전이 후보의 기여 가능성과 비교 과제

**판단: 관찰된 문제, 실제 개선 결과, 구현된 접근이 연결된 기여 후보가 있다. HR와 공개 영상 라벨 최적화를 주력 검증 후보로 다룰 근거가 충분하다. 대표 선행연구 대비 우위와 CVPR에 충분한 기여의 크기는 남은 비교로 확인한다.**

기록일: 2026-09-29, Asia/Seoul. 연구 단계 2. 이번 작업은 대화 판단과 근거를 기록하는 문서 작업이다.

## 1. 사용자와 확인한 판단

사용자는 다음과 같이 이해를 확인한 뒤 **“우선기록”**을 요청했다.

> 문제점도 잇고 기존 연구 대비 현 상태 완벽하진 않지만 결과도 잇고 우리가 가져갈 접근방안도 잇고 기여도 만들수 잇을거같다 이말맞지 ?

확인한 의미는 다음과 같다.

- **문제:** 같은 DP 정보를 다른 영상 모델에 전달하더라도 전달 방식에 따라 후속 성능이 달라지는 현상을 관찰했다.
- **결과:** 현재 HR 구성은 보정 KD 대조군보다 높은 개발 성능을 보였고, 공개 영상 선정을 바꾼 경우에도 일부 주요 비교의 이득이 유지됐다.
- **접근:** 공개 데이터로 다른 모델의 분류기를 재구성하고, 그 목표를 고정된 공개 영상의 soft label에 담아 전달하는 구현이 있다.
- **기여 가능성:** 강한 기존 방법과의 공정한 비교 및 추가 평가에서 이득이 유지된다면, 성능과 활용성 측면의 기여로 발전시킬 수 있다.

CVPR 제출 목표를 유지한다. 현재 판단은 **실험 근거가 있는 기여 후보**이며, 기존 대표 논문 대비 우위·일반적 효능·채택 가능성을 확정한 판단은 아니다.

## 2. 주력으로 검증할 주장

> 이미 공개된 DP 모델의 정보를 다른 영상 인코더로 옮길 때, 공개 데이터로 분류기를 재구성한 뒤 라벨을 최적화하면 기존 예측 모방 방식보다 후속 모델의 성능을 더 보존할 수 있다.

현재 HR은 기존 DINO 보호 head와 공개 자료를 사용해 ResNet18 목표를 재구성하고, 공개 영상 128장의 bounded soft label을 계산한다. DenseNet은 재사용된 개발 평가 모델이다. 현재 학습기는 고정된 특징 위의 ridge 분류기다. ResNet18은 목표 구성에 참여하므로 독립 전이 검증 모델로 세지 않는다.

위 문장은 검증할 주장이다. “공개 영상의 라벨 최적화”, “추가 비공개 데이터 접근 없는 후처리”, “픽셀 최적화 생략”을 각각 새 원리로 주장하지 않는다.

## 3. 실제로 보존할 실험 근거

각 수치는 기존 두 DP 출력에 대한 **DenseNet AUROC 차이의 평균**이다.

| 대조 | 첫 공개128 선정 | 공개128 재선정 |
|---|---:|---:|
| HR − CKD: 공분산 보정 KD | +0.028844 | +0.021664 |
| HR − ACKD: 공개 기준값 보존과 공분산 보정 | +0.035346 | +0.033434 |
| HR − DINO-only: 원래 source 목표만 사용 | +0.022776 | +0.025617 |

- CKD·ACKD 대비 평균 개선의 조건부 95% 신뢰구간은 두 선정에서 모두 양수였다.
- DINO-only 대비 첫 선정의 DP2 점차이는 −0.002719다. 재선정의 AKD 대비 구간은 0을 포함한다. 모든 대조·모든 조건에서 우위가 확정된 결과로 요약하지 않는다.
- 재선정은 기존 선정과 환자 97/128명, 영상 95/128장이 겹친다. 같은 P/Q/V 및 같은 두 DP 출력을 사용했으므로 독립 코호트나 새 DP 잡음 반복으로 세지 않는다.
- 환자 cluster bootstrap 구간은 현재 DP 출력과 라벨에 조건부다. 반복 개발 선택이나 DP 잡음 모집단 전체의 불확실성을 포함하지 않는다.

근거: [2-2R1 보정 KD 비교](PUBLIC_TRANSFER_2_2R1_KD_CORRECTIONS_RESULTS_20260928.md), [2-3R1 공개 영상 재선정](PUBLIC_TRANSFER_2_3R1_SELECTION_REPEAT_RESULTS_20260928.md), [2-2 head 재구성](PUBLIC_TRANSFER_2_2_HEAD_RECONSTRUCTION_RESULTS_20260928.md).

### 설정 의존성도 함께 보존

최근 2-2R2에서 HR의 환자 균등 대응 가중치는 class 균형보다 평균 AUROC +0.028012였지만, ACKD에서는 같은 변경이 −0.025069였다. 두 방법을 함께 개선한다는 사전 가설은 실패했다.

같은 class 균형 설정의 HR-B − ACKD-B는 +0.007334, 조건부 95% CI [−0.000112, +0.014755]였다. 따라서 이득의 설정 의존성을 확인해야 한다. 향후 비교에서는 더 강했던 ACKD-B와 CKD를 유지하고 각 방법에 동등한 개발 기회를 준다.

근거: [2-2R2 가중치 교차](PUBLIC_TRANSFER_2_2R2_WEIGHT_CROSSOVER_RESULTS_20260929.md).

## 4. 직접 연결되는 선행연구와 비교 질문

| 선행연구 | 이미 알려진 요소 | 현재 후보가 입증할 추가 가치 |
|---|---|---|
| [KIP / Label Solve, ICLR 2021](https://arxiv.org/html/2011.00050v3) | 고정 영상의 라벨 최적화, 다른 커널로의 전이 | 동일한 보호 정보를 목표로 제공한 기존 라벨 최적화보다 HR을 거치는 전이가 유리한가 |
| [POST, ICML 2025](https://arxiv.org/html/2506.16196v1) | 공개 자료로 DP 학습 정보를 전이하며 예측과 기준 모델 대비 변화량을 전달 | 해당 전이 원리를 영상 설정에 적용한 강한 대조보다 성능이 좋은가 |
| [Dosser, ICCV 2025](https://openaccess.thecvf.com/content/ICCV2025/html/Zheng_Improving_Noise_Efficiency_in_Privacy-preserving_Dataset_Distillation_ICCV_2025_paper.html) | 보호된 신호를 재사용해 후처리로 데이터를 증류 | 같은 개인정보 예산에서 합성 비용을 줄이면서 후속 모델 성능을 유지하거나 높이는가 |
| [DPPL, AAAI 2025](https://ojs.aaai.org/index.php/AAAI/article/view/35395) | 공개 인코더와 DP 프로토타입을 이용한 불균형 분류 | 직접 DP 분류기를 만드는 대안에 비해 전이용 데이터가 어떤 활용 이점을 주는가 |

현재 CKD·ACKD는 내부 연산 대조다. POST 원논문은 LLM 방법이므로 영상 적용판을 구성한다면 변경점을 밝혀야 한다. 현재 비교를 KIP·POST·Dosser·DPPL 원논문 전체의 재현 및 승리로 표시하지 않는다. 평균 임베딩과 signed-public-weight의 기존 연산 동치도 [2-1 선행·연산 비교](PUBLIC_TRANSFER_2_1_OPERATION_COMPARISON_20260928.md)에 기록돼 있다.

## 5. 다음 연구의 우선순위

1. **같은 보호 출력으로 비교한다.** 기존 라벨 최적화, 일반 KD, 강한 보정 KD, HR에 같은 공개 데이터·모델 접근·영상 수와 동등한 설정 탐색 기회를 부여한다. 기존 결과를 재사용하고, 주장과 연결되는 유한한 비교 묶음 및 판단 기준을 먼저 정한다.
2. **전체 방법의 활용 이점을 비교한다.** 효율성이나 전이용 데이터의 필요성을 주장한다면 Dosser 계열 및 직접 DP 분류기 대안과 전체 개인정보 예산·데이터 접근 조건을 맞춘다. 특징 추출과 목표 구성까지 포함한 전체 비용을 측정한다. 새로운 비공개 데이터 접근이 필요한 대안은 첫 번째 고정 출력 비교와 구분한다.
3. **기여의 범위를 결과에 맞춰 정한다.** 방법과 대조를 동결한 뒤 독립 평가에서 확인할 범위를 정한다. 표준 구성요소를 쓴다는 이유만으로 후보를 폐기하거나, 모든 원인을 완전히 증명할 때까지 원인 대조를 계속 추가하지 않는다.

이 목록은 대화에서 확인한 연구 우선순위다. 구체적인 다음 실험 묶음·실행 일정·예산은 이번 기록에서 새로 확정하지 않았다.

## 6. 현재 실행 상태와 기존 결과의 관계

- 이번 작업: 문서 기록. 새 실험·학습·라벨 계산·V 평가·Q 접근·DP release·Expert/Reserved 접근 0.
- 연구 단계 2와 기여 미확정 상태를 유지한다. 실행 중인 연구 작업은 없다.
- 마지막 완료 실행은 [2-4B 공개 prototype](PUBLIC_TRANSFER_2_4B_PUBLIC_PROTOTYPE_RESULTS_20260929.md)이다. 구현 검산은 통과했지만 표준 PCA보다 낮은 공개 목표 총오차의 근거는 확보하지 못했다.
- 마지막 실제 개발 효용 결과는 2-2R2다. 이번 긍정적 후보 판단을 2-4B의 성능 성공으로 바꾸지 않는다.
- 철회된 2-1R3 자동 후속 권고를 재개하지 않는다. 과거 판정과 완료 실험은 그대로 보존한다.
