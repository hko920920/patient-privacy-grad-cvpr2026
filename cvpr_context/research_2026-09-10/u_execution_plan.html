U 조건 중심 실행 계획 — 관측 사진과 학습 사진의 간극

사용자 승인 후 수행 상태는 U 실험 실행 기록을 따른다. 아래 표의 미실행 상태는 계획 작성 당시의 이력이다.

2026-09-14. 상태: 실행 준비를 위한 계획안. 데이터 분할·새 공격 구현·의료 모델 학습·성능 검증은 아직 완료되지 않았다. 이 문서는 최근 대화에서 정한 U의 우선순위를 구체화한다. 설계 v0.1의 후보 수치는 출발값이며, 실제 cohort와 비교 범위는 아래 첫 단계에서 고정한다.

핵심 질문: 감사자가 가진 사진은 학습에 없지만 같은 환자의 다른 사진은 학습됐을 때, 기존 방법이 포착하는 신호와 추가로 포착할 수 있는 신호는 무엇인가? 그 차이가 이미지 DP와 환자 DP의 보호 비교에 어떤 영향을 주는가?

참여 정답은 실험에서 수행하는 추가 미세조정 기준이다. 공개 base의 전체 사전학습 데이터에 대한 참여 여부까지 판별했다고 주장하지 않는다.

2. 첫 작업: U 자료와 평가 역할을 학습 전에 나눈다

  1. 파일이 있는지와 기존 무결성 기록을 대조하고, 후보별 중복·유사 복제와 촬영 구분을 점검한다. 구분할 메타데이터가 없으면 그 한계를 남긴다.
  2. 적격 환자마다 최소 네 장을 분리한다. 학습에 배정할 두 장과 U 감사에 사용할 두 장을 고정하고, hash와 역할을 manifest에 남긴다.
  3. 같은 적격 기준의 환자 풀에서 참여/미참여를 무작위로 배정한다. 사진 수·질환·촬영 조건 차이가 membership 정답을 대신하지 않도록 분포를 확인한다.
  4. 공격 점수 fitting, 방법 선택, threshold 보정, 시험은 환자 단위로 분리한다. 같은 환자는 두 모델에서도 같은 평가 역할을 유지한다.
  5. 다른 환자와의 반응 대조 bank는 별도 환자로 정하고 대상·보조 학습에서 제외한다. 알려진 비참여 보정 자료와 대조 bank를 공격자에게 어느 범위까지 허용하는지 명시하고 비교 방법에도 같은 보조정보 기회를 준다.
  6. 환자 수와 보정 해상도·시험 오탐률의 신뢰구간을 검토해 파일럿 인원을 고정한다. 작은 표본을 최종 1% 오탐 성능의 정밀 검증으로 쓰지 않는다.

산출물은 적격 환자 집계, 제외 사유, 실제 분할 manifest, 역할별 인원표, cohort hash, 첫 실행 설정이다. 내부 평가용 학습 정답 목록은 공격 feature에 넣지 않는다. 학습에 없는 사진이라는 사실만으로 그 환자가 nonmember라고 라벨링하지 않는다.

3. 두 모델로 환자 특성과 참여 효과를 점검한다

평가 역할별로 적격 환자를 A/B 그룹에 균형 배정하고, 초기화·공통 학습 배경·기여 사진 수·총 학습 예산을 맞춘다.

대상 모델 A 환자의 학습용 두 장 B 환자의 학습용 두 장 모든 U 감사 사진
모델 1 포함 제외 제외
모델 2 제외 포함 제외

한 환자의 U 사진은 두 모델에서 그대로 쓰지만, patient membership 정답은 바뀐다. 고정된 외모·질환·촬영 특성만으로 맞힌 결과와 학습 참여에 관련된 반응을 구분하는 데 도움을 주는 진단이다.

공통 학습 배경이 필요하면 후보·대조 환자와 겹치지 않는 별도 public_development 자료로 구성한다. 대상 모델별로 평가하므로, 모델 1에 대한 감사에 모델 2의 응답이나 학습 목록을 추가 입력으로 주지 않는다.

이 두 모델은 여러 환자의 포함을 함께 바꾸므로 단일 환자만 차이 나는 DP 인접 데이터 실험이 아니다. 같은 환자의 두 결과를 독립 환자 두 명으로 세지 않는다. 후속 확인에는 새로운 배정·독립 학습 seed가 필요하다. 첫 두 모델만으로 일반화나 기전 인과관계를 확정하지 않는다.

4. 최소 구현과 새 후보의 실제 동작

먼저 기존 모델 adapter와 환자 평가기를 연결하고, 8–16명 정도의 작은 입력으로 파일·차원·gradient·점수 방향·메모리·실행 시간을 점검한다. 이 크기의 실행은 성능 검증이 아니다.

새 후보는 U 사진 C와 D로 다음을 수행한다.

  1. C에서 공개 base보다 추가학습 모델의 반응이 더 커지는 작은 conditioning 입력 조정을 찾는다. 모델 weight는 업데이트하지 않는다.
  2. 그 조정을 C와 다른 사진 D에 적용해서 반응이 전달되는지 측정한다. 최적화와 평가의 noise도 분리한다.
  3. 같은 조정이 비슷한 다른 환자 사진에도 주는 효과를 빼서, 일반적인 영상 개선과 구분할 후보 점수를 만든다.
  4. D에서 조정을 찾고 C에 적용하는 방향도 계산해 합친다.

8차원·6회 입력 최적화 등 세부 출발값은 기존 후보 설계를 따른다. token mask, scheduler, 기준 prompt와 reference 선택을 실행 전에 고정한다. 이 점수가 참여 환자에서 더 유효한지는 실험할 가설이다.

처음에는 기존 loss/SecMI의 단일 사진·mean/max 집계, 공개 encoder-only, 같은 접근의 선형 gradient 관계, 새 점수 단독을 비교한다. 이어 같은 분류기와 개발자료에 기존 feature만 준 경우와 새 점수를 추가한 경우를 비교한다. m=2의 top-1은 max와 같으므로 별도 방법처럼 수를 부풀리지 않는다.

대상 모델의 의료 학습 적합성도 점검한다. 현재 B0가 off-domain이므로 짧은 non-DP 학습이 정상적으로 흉부 영상에 적응했는지 확인한 뒤 보호 효과 해석으로 확장한다.

5. 기여 판정에 필요한 강한 대조를 붙인다

초기 결과로 구현을 확인한 뒤, 방법 선택용 개발 자료에서 주장에 가장 가까운 대안을 비교한다.

  • conditioning 최적화: MoFit 원형의 검증 범위와 비용을 명시하고, 한 사진에서 구한 입력을 다른 사진에 적용하는 변형도 대조한다.
  • 집합 추론: CDI의 핵심 feature·fitting·reference 절차를 보존한 환자 변형과 비교한다.
  • 영상/gradient 신호: CLiD·PFAMI·GSA/Tracing 등 현재 접근권에서 적용 가능한 강한 대표를 선정한다. 단순 loss만 이긴 결과를 기존 공격 전체의 우위로 표현하지 않는다.
  • 표준 관계·집합: 동일 feature의 선형 관계·moments·집합 모델 등 실제 기여의 대안 설명을 점검한다.
  • 난이도 보정 또는 효율성을 주장하면 Quantile, 저비용 공격 등 해당 축의 비교를 보완한다. 공통 환자 threshold 보정과 Quantile 원형 공격은 구분한다.

이 목록은 모든 방법을 모든 조건에 즉시 전수 실행하라는 뜻이 아니다. 직접 맞닿는 강한 대안을 선정하고 적용·변경·제외 근거를 비교군 검토에 연결한다.

모든 결과는 같은 환자·관측 장수·대상 모델에서 비교한다. 동일한 보정 환자를 각 방법에 사용해 방법별 threshold를 정한 뒤 고정하며, 보정 환자는 개발·시험 환자와 분리한다. test에서 실제 FPR·TPR와 95% 구간을 함께 보고, 환자 반복·학습 seed 의존성을 보존한다. 연산 예산은 target/base forward·backward, reference 검색·점수 fitting을 포함하고 메모리와 초/환자도 측정한다.

제거 실험은 다른 사진으로의 전이 제거, base 차이 제거, 다른 환자 대조 제거, 선형 관계로 대체, 조건을 맞춘 다른 환자로 bag을 구성하는 분석이다. 분석자가 정답을 이용하는 진단 대조를 실제 감사자의 입력 선택으로 혼동하지 않는다.

7. DP 보호 비교와 졸논 공유

확인된 U 분할에 대해 non-DP, image-DP, patient-DP 모델을 비교한다. 동일한 숫자의 image epsilon과 patient epsilon을 같은 보호 수준으로 취급하지 않는다. 기존 설계의 M1-G8 대 M2-P8처럼 공통 patient epsilon/delta 회계 목표를 맞춘 비교와 효용·비용 곡선을 중심에 둔다. M1-I8은 이미지 단위 예산의 비교 역할을 별도로 표시한다.

각 방법은 동일한 정보·관측·연산 조건에서 공통 절차로 보정한다. model별 fitting/보정이 달라지면 그 비용과 허용 자료를 보고한다. 낮은 노출이 생성 품질 붕괴 때문인지 함께 확인한다. 공격 실패를 DP 인증·더 타이트한 수학적 보장으로 해석하지 않는다.

기존 졸논 K5/K10 manifest·회계·공격 계약은 별도다. 현재 K10 cap 밖 U 후보는 제한적이므로, 졸논용 체크포인트를 U 본실험에 자동 재사용한다고 약속할 수 없다. 데이터 처리·학습 코드·비교 도구는 공유하고, 학습 manifest·기여 수·보호 회계·모델 설정이 실제로 일치하는 체크포인트만 공유한다. 기존 K5의 공격 NOT_RUN 규칙은 이번 계획으로 변경하지 않는다.

m=2 U가 첫 중심이며, E는 같은 모델의 대조로 남긴다. m=5·부분 겹침 P·다른 데이터/모델은 핵심 검증과 표본·실측 예산을 본 뒤 확장한다.

8. 수행 순서와 다음 산출물

순서 완료 기준 현재 상태
1. U 자료 점검·분할 설계 역할별 실제 적격 수, 파일/중복 확인, 분할표와 실행 설정 메타데이터 상한만 확인됨
2. 최소 adapter·후보·비용 기록 구현 작은 입력 검증과 측정 보고서 신규 후보 미구현
3. non-DP 두 모델 진단 학습 적합성, E/U 기본 비교, 참여 교환 진단 미실행

첫 실제 작업의 산출물은 U 적격 환자 집계 + 분할표 + 최소 실행 설정이다. 장시간 학습과 최종 전체 비교군의 일정을 지금 확정하지 않고, 첫 실행의 학습 시간·방법별 초/환자·메모리를 측정해 총 예산을 갱신한다. 이 문서 작성은 그 실행을 완료했다는 뜻이 아니다.
