# A13 — REDIFFUSE

검토: pp.3–6 선택 본문, Algorithm 1·Tables 1–3. 해당 범위의 방법·결과 대조이며 전 페이지 정독/모델 실행은 아니다.

**방법.** 원 이미지를 variation API에 여러 번 넣어 재생성 결과를 평균하고 원본과의 차이로 membership을 추론한다. 원 주력 실험은 n=10, pixelwise difference를 ResNet18로 학습하며 알려진 라벨 20%를 사용한다.

**결과·한계.** SD 표의 AUROC .81–.82, TPR@1%FPR 20.6–21.7%는 이 조건의 결과다. 평균화 정리는 unbiased denoising 등의 가정 아래 성립하며 비학습 이미지와의 분리 자체를 보장하지 않는다.

**우리 비교.** image-to-image API 조건의 직접 ICML25 기준선. text-to-image-only와 별도 비교한다. API 10회에는 여러 denoising step이 포함되므로 PIA의 forward 2회와 같은 질의 단위로 세지 않는다.
