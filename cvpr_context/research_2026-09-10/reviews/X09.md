# FETA-Pro — USENIX Security 2026 학습 비교군

DP-FETA의 spatial central image에 DP random Fourier feature 평균을 추가한다. noisy frequency 평균을 맞추는 보조 GAN generator의 합성영상으로 diffusion 모델을 추가 warm-up하고, 원 private 영상으로 DP-SGD를 수행한다. central image·frequency 평균·private fine-tuning 세 비용을 합성한다. [Algorithms 1–2, pp.5–7](../pdfs/X09.pdf#page=5)

Table 4의 Camelyon ε=1은 FID 31.0, accuracy 84.0%로 DP-FETA 52.8, 77.3%보다 좋다. CIFAR ε=10 FID는 69.0으로, 공개 사전학습을 쓰는 다른 논문의 더 작은 FID와 무조건 순위 비교할 수 없다. [p.8](../pdfs/X09.pdf#page=8)

Table 8은 CIFAR private fine-tuning 20.5시간과 peak memory 96.3GB를 보고한다. 추가 warm-up은 작아도 전체 학습이 가볍다는 뜻은 아니다. [p.13](../pdfs/X09.pdf#page=13)

공개자료 없는 학습 또는 private prototype/frequency curriculum을 주장하면 직접 비교가 필요하다. label별 parallel composition은 sample이 한 class에 속할 때의 논리이므로, 다중 질환·여러 영상의 같은 환자에 그대로 적용하지 않는다. 검토: pp.5–8, 13 방법·결과 발췌; 증명 전체·공식 코드 실행 미완료.
