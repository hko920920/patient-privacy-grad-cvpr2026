# MedSign — 졸논 워터마크 선행

병리 token attention에서 clustering으로 국소 영역을 고르고 scaling해 watermark가 진단 영역을 덜 바꾸도록 학습한다. MIMIC-CXR와 안저 영상에 적용한다. [p.5](../pdfs/E03.pdf#page=5)

MIMIC 평균 bit accuracy .95와 PSNR 39.71, 질환 classifier confidence 변화 .59 percentage point를 보고한다. bit 정확도는 낮은 FPR의 watermark detection TPR와 다르며, confidence 변화가 작다고 모든 임상 정보의 보존이 입증되는 것은 아니다. [Tables 1–2, pp.7–8](../pdfs/E03.pdf#page=7)

병리 보존 watermark 기여와는 직접 충돌하지만 membership inference나 환자 DP 보장은 아니다. 현재 CVPR patient audit와 분리해 졸논 선행 기록에 연결한다. 검토: pp.5, 7–8 방법·표 발췌; 미재현. [MICCAI 원문](https://papers.miccai.org/miccai-2025/0673-Paper0428.html)
