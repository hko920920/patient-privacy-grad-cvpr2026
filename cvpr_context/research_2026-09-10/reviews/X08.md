# DP-FETA — 공개자료 없이 DP warm-up

private 영상들을 Poisson sampling하여 clipping한 평균 영상 또는 noisy pixel histogram의 mode 영상을 만든다. 이 DP central image로 augmentation을 하며 warm-up한 뒤 원 private 자료로 DP-SGD fine-tuning한다. central image 질의와 fine-tuning을 합성하고, 이미 DP 처리한 영상의 재사용은 post-processing이다. [Algorithms 1–3, pp.4–6](../pdfs/X08.pdf#page=4)

MNIST·FashionMNIST·CelebA·Camelyon을 평가한다. 평균적으로 FID 33.1% 감소, utility 2.1% 증가를 보고하지만 여러 데이터셋의 평균이며 CXR 환자 성능이 아니다. augmentation 없는 warm-up, Stage II만 사용, 공개 ImageNet warm-up과의 ablation을 제공한다. [p.8](../pdfs/X08.pdf#page=8)

표본 간 variance가 크면 평균/mode가 유용한 구조를 잃는 한계를 명시한다. 환자 평균 prototype으로 DP 학습을 개선하겠다는 방향은 이 논문 및 후속 FETA-Pro와 직접 충돌한다. 환자 adaptation에는 central query와 gradient 양쪽의 contribution bound를 바꿔야 한다. 검토: pp.4–6, 8, 13 발췌; 공식 코드 링크 확인, 실행 미완료. [원문](https://arxiv.org/abs/2504.01395), [저자 코드](https://github.com/SunnierLee/DP-FETA)
