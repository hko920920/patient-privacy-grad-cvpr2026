# PFDM — 공유 모델과 local refinement의 보장 범위

client는 private clean data로 local denoiser를 학습해 보관하고, clipping한 데이터에 forward noise를 적용한 것만 server에 전달한다. Server denoiser는 이 DP 데이터로 학습하며 생성 때 client의 private denoiser가 세부 내용을 복원한다. [§4, p.4](../pdfs/C01.pdf#page=4)

본문 p.5의 LDP는 datum별 설명이고, p.6은 label을 공개 정보로 가정한다. 공유 server model의 보장을 local clean-data 모델과 그 최종 출력 전체의 patient DP라고 확대하면 안 된다. 현재 중앙 학습의 환자 add/remove 설정과 바로 호환되지 않는다.
