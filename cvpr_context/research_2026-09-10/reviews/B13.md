# RAPID — 공개 trajectory 검색을 사용하는 DP 학습 기준선

공개 데이터를 사전학습용과 검색 DB용으로 나눈다. contrastive feature extractor로 가까운 공개 trajectory를 검색하고 중간 denoising 구간을 건너뛴 뒤, 비공개 영상에 대한 후반부 denoising을 DP-SGD로 학습한다. 생성 시에도 검색을 사용한다. LoRA 적용 하나로 대체되는 방법은 아니다. [§3·Algorithms 1–2](../pdfs/B13.pdf#page=3)

실험은 32/64 해상도이며 공개 EMNIST/ImageNet/FFHQ와 비공개 MNIST/CIFAR/CelebA를 사용한다. DPDM batch 8,192, RAPID/DP-LDM 기본 batch 64처럼 조건 차이가 있으므로 고정 계산량 결과와 원래 권장 설정 결과를 구분해야 한다. hyperparameter 탐색의 privacy 비용을 계산하지 않았다고 본문이 명시한다. [§4.1](../pdfs/B13.pdf#page=6)

부록 A의 증명은 한 record 교체에 대한 sensitivity 2C/B와 Gaussian RDP다. 환자 전체 추가·삭제 보장으로 자동 전환되지 않는다. 공개 DB에 private-role 환자가 들어가거나, private 중간값을 별도 공개하는 구현이면 원래 증명 조건을 다시 확인해야 한다. [부록 A/B](../pdfs/B13.pdf#page=14)

비교 준비에는 공개 데이터 수·환자 분리, KB 생성 비용·용량, 특징 추출기, sampler/step 수, 학습량과 inference 비용을 포함한다. 현재 CXR 조건에서 공개 DB를 공정하게 마련할 수 있는지 먼저 판정하고, 동일 조건이 가능한 별도 학습 기준선으로 편성한다. 논문의 FID를 로컬 SD2.1과 직접 대조하지 않는다.
