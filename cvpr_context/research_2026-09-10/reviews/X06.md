# X06 — DPImageBench

검토: CCS 2025 공개본 pp.4–7의 선택 부분, p.12 결과. 공식 저장소 commit과 텍스트 코드 확보; 실행 없음.

**방법.** DP noise를 input/model/output 단계로, 공개자료 활용을 전체/선별/API로 나누어 DPDM, DP-LDM, DP-LoRA, PrivImage, PE 등 구현·평가를 통일한다. 공개 pretraining과 backbone, DP hyperparameter 차이를 통제하며 utility 검증의 test-set tuning 문제를 지적한다.

**결과·한계.** Table 9에서 공개 data 선택 방식만 달라도 같은 DP-LoRA의 CIFAR accuracy가 69.7–78.2로 달라진다. 이는 표에 있는 논문 최고점의 단순 순위가 알고리즘 효과와 다를 수 있음을 보여준다. 민감한 validation release의 DP 문제는 ‘같은 분포’ 자체가 아니라 어떤 개인의 정보에 의존해 무엇을 공개하는지가 기준이다.

**우리 대조.** DP-LoRA/RAPID/최신 DP 계열을 같은 backbone·공개자료·patient privacy budget·compute에서 비교하는 기반이다. benchmark 구현은 원저자 완전 재현과 구별한다. 개인 단위 adjacency를 바꾸면 기존 image-level accountant를 그대로 쓸 수 없다. 기존 다운로드 목록에서 빠진 DP-FETA와 후속 FETA-Pro도 별도 확인한다.
