# RPGen — AAAI 2026, 공개 본문 일부만 확보

공식 초록과 검색에 노출된 공식 PDF 본문·Table 1/2를 직접 확인했다. 로컬 PDF 요청은 실패했으므로 전체 방법·증명 검토 완료로 표시하지 않는다. [공식 논문](https://ojs.aaai.org/index.php/AAAI/article/view/38016), [공식 PDF](https://ojs.aaai.org/index.php/AAAI/article/download/38016/41978)

공개 classifier로 얻은 private class histogram에 DP noise를 넣어 공개 데이터를 선택하고, 그 subset에서 adversarial model perturbation(AMP) 사전학습으로 parameter perturbation 내성을 만든 뒤 DP fine-tuning한다. public-to-private domain의 robustness transfer가 핵심이다. 공개 자료 선택은 PrivImage와도 겹치므로 AMP와 선택을 분리한 ablation이 필요하다.

공식 Table 1의 CIFAR ε=10은 CNN accuracy 73.4%, FID 26.5; ε=1은 70.3%, 28.5다. 공식 Table 2 nonprivate CNN 77.1%, FID 19.8과 함께 읽어야 한다. 원래 DP-LDM의 다른 public pretraining 성능과 그대로 순위를 매길 수 없다.

공개자료 domain mismatch나 DP noise robustness 개선을 주장하면 필수 최신 비교 후보다. 현 단계는 **부분 원문 검토**이며 accountant·학습 module·코드 재현은 미확인이다.
