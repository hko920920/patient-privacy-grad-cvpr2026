# A03 — CheXGenBench

검토: PDF pp.5–7, 9, 방법 §2.3–2.4 및 Table 3. TMLR 2026 공개본. 코드 실행 없음.

**방법·결과.** 11개 CXR 생성 모델을 MIMIC-CXR 237,388개 학습 이미지로 비교한다. 생성 충실도에는 RAD-DINO, 정렬에는 BioViL-T를 사용하고 분류·분할·보고서 생성의 유용성을 평가한다. 개인정보 실험은 학습 프롬프트 2,000개마다 10개 결과를 생성하고 각 입력에서 최대 Re-ID 점수와 최소 거리를 취한다. ResNet50 Siamese Re-ID, 픽셀·잠재 거리, 평균·최대·고정 임계값 초과 건수를 함께 보고한다.

**대조 판단.** ‘의료 생성물에 Re-ID를 적용’, ‘privacy/fidelity/utility 통합’, ‘평균 외 최대 위험’은 이미 포함돼 있다. 그러나 생성물과 학습 이미지의 높은 유사도는 환자 membership의 오탐률 보장과 다르다. 고정 임계값의 초과 건수만으로 환자별 실제 노출률을 확정할 수 없다. 10회 생성의 최대값이라는 선택 효과도 반영해야 한다.

**우리 비교.** 픽셀·RAD-DINO·Siamese Re-ID와 평균/최대 집계를 기본 비교군으로 포함한다. 동일 생성 횟수, 프롬프트 정보, 검색 gallery 크기에서 비학습 환자로 임계값을 보정한다. RAD-DINO의 NIH 사전학습 중복과 표본수에 따른 FID 추정 오차를 별도 기록한다. 최신 생성 backbone의 비DP 유용성 기준으로 참고하되, 서로 다른 전체학습/LoRA 모델의 표 수치를 우리 SD2.1과 직접 순위화하지 않는다.

근거: [원문](https://arxiv.org/abs/2505.10496), pp.6–7, 9 Table 3. 문서의 거리 방향 설명 일부와 표 화살표가 일치하지 않아 구현 시 거리/유사도 방향을 명시해야 한다.
