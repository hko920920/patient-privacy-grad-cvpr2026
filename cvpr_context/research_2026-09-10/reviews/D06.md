# Hourglass Diffusion Transformers

계층적 hourglass와 고해상도의 local attention을 사용해 pixel 수에 대해 선형으로 증가하는 계산 구조를 만든다. 해상도에 맞춘 noise schedule도 필요하다. ImageNet128의 DiT-B 규모에서 architecture ablation과 50k sample FID/FLOPs를 비교한다. [pp.4, 6](../pdfs/D06.pdf#page=4)

고해상도 일반 생성 아키텍처 선행이며 DP mechanism이나 patient audit가 아니다. SD LoRA에서 데이터 보호 단위를 비교하는 현재 실험에 backbone 전체 교체를 강제할 이유가 없다. 고해상도 연산 효율을 기여로 바꾸면 직접 설계 대조가 필요하다. 검토: 방법·평가 설정 두 페이지 발췌; 전체 결과·재현 미완료. [ICML 원문](https://proceedings.mlr.press/v235/crowson24a.html)
