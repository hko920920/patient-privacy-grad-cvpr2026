# DP-FedEmb — 생성 대상은 영상 임베딩

여러 사용자를 virtual client로 묶고, 매번 초기화되는 local classification head는 버리며 backbone update만 clipping·집계·노이즈 처리한다. 영상 자체를 합성하는 diffusion 모델이 아니다. 사용자 재그룹화 여부에 따라 보호 대상과 adjacency가 달라진다. [pp.3–4](../pdfs/B03.pdf#page=3)

Table 1의 recall 72.37%, ε=3.90은 1,000만 사용자와 round당 약 13.1만 사용자를 가정한 외삽 회계다. 작은 실제 데이터셋에서 그 ε로 학습했다고 읽으면 안 된다. 실제 약 98,960명 규모를 다룬 Table 2는 ε=24.86, δ=10⁻⁵ 조건이다. [pp.7–8](../pdfs/B03.pdf#page=7)

우리 연구에서는 공개 backbone·user update 학습의 선행으로 사용한다. 합성영상 FID 직접 비교군에는 넣지 않는다. 검토: pp.3–4, 7–8의 방법·실험 가정 발췌; 미재현. [CVPR 2023 원문](https://openaccess.thecvf.com/content/CVPR2023/papers/Xu_Learning_To_Generate_Image_Embeddings_With_User-Level_Differential_Privacy_CVPR_2023_paper.pdf)
