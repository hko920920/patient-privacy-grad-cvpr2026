# How to DP-fy Your Data — 비교 설계용 종설

102쪽 종설 중 diffusion 학습, Private Evolution, 방법 선택, image quality 평가 절을 읽었다. DP fine-tuning, DP query로 공개자료 선택, inference API 기반 PE의 접근 조건과 비용이 다르다는 체계가 유용하다. noise/augmentation multiplicity와 공개 사전학습도 기존 방법군으로 정리된다. [pp.41, 43, 48](../pdfs/B18.pdf#page=41)

IS는 real data와 직접 비교하지 않고 FID도 feature distribution을 근사하므로 downstream clinical utility나 membership를 대체하지 못한다. 고해상도 visual quality와 실제 private 분포 재현을 구분해야 한다. [p.50](../pdfs/B18.pdf#page=50)

종설의 ‘현재 SOTA’ 표기는 개별 원문 및 더 최신 논문으로 갱신해야 한다. 본 작업은 실제 DP-LoRA, RAPID, DP-FETA, FETA-Pro, RPGen 원문을 별도 대조했다. 검토: pp.41, 43, 48, 50 선택 절 발췌; 102쪽 전체 검토로 표시하지 않으며 독립 실험 baseline도 아니다. [원문](https://arxiv.org/abs/2512.03238)
