# A23 — DCM-DeID

검토: ICCV25 pp.3–6 선택 본문, Table 1. 해당 범위의 방법·결과 대조이며 전 페이지 정독/모델 실행은 아니다.

**방법.** Re-ID 영역 masking, 의료 feature의 최소 codelength와 ID/semantic code 분리, diffusion 재합성을 결합한다. 학습/평가 Re-ID backbone을 분리한다.

**결과·한계.** 동일 공격 success-rate 10/20%에서 여러 downstream 성능을 비교하고 외부 데이터에서도 검증한다. 학습은 8×4090 약3일이다. 이 지표는 nearest-gallery Re-ID이고 patient membership FPR이 아니다.

**우리 비교.** 의료 익명화로 방향을 틀면 반드시 이길 메인 직접 선행이다. 단순 identity/semantic 분리나 조절 가능한 trade-off를 신규성으로 주장할 수 없다. 현재 patient-DP 학습/감사 주제와는 보호 대상·출력 조건이 달라 별도 방어 축으로 둔다.
