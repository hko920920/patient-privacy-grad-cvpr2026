# A26 — PRSS

검토: CVPR25 pp.3–5, 7 선택 본문. 해당 범위의 방법·결과 대조이며 전 페이지 정독/모델 실행은 아니다.

**방법.** 첫 denoising 단계의 memorization 신호로 prompt 최적화를 작동시키고, 원 prompt 예측을 새로운 기준점으로 삼는 re-anchoring을 한다. LLM semantic prompt search와 결합하는 추론 방어다.

**결과·한계.** SD1.4의 선정된 500개 prompt(300개 이상 암기 분류), SSCD/local copy와 CLIP utility를 사용한다. 이러한 선정 집합 성능은 일반 의료 환자 발생률이 아니다. semantic search에는 후보 생성 비용도 포함된다.

**우리 비교.** 공개모델을 고정한 inference 방어를 택하면 직접 CVPR 기준선. 병명 prompt와 의료 utility에 전이해야 한다. 단순 guided sampling·prompt 변경으로 복제를 줄이는 주장에는 명확한 중복이 있다.
