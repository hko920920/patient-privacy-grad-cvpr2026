# A15 — MaMI

검토: pp.4–7 선택 본문: 모듈·학습·Tables 2–5. 해당 범위의 방법·결과 대조이며 전 페이지 정독/모델 실행은 아니다.

**방법.** 입력 modality에 따른 low-rank 파라미터를 생성하고 여러 의료 foundation model의 local prior를 Re-ID에 전달한다. multi-slice scan은 특징을 평균한다. 환자 ID 분류와 triplet loss로 학습한다.

**결과·한계.** ChestXray14 CMC Rank-1 91.49%, Packhäuser 88.21%를 보고한다. 이는 실제 이미지의 검색 정확도이며 생성모델 누출률이 아니다. 공개 encoder DINOv2/RAD-DINO의 pair-AUC와 직접 숫자 비교하면 안 된다.

**우리 비교.** 의료 Re-ID의 직접 CVPR25 강한 비교군. 공식 weights/환자 학습 중복을 확인한 뒤 frozen detector로 사용하고 환자 비중복 calibration을 둔다. 재학습 시 논문의 4×4090 약2일 비용을 참고하되 우리 비용으로 확정하지 않는다.
