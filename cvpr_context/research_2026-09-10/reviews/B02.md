# P3SGD — 환자 단위 학습의 CVPR 선행

환자를 sampling하고 각 환자 영상으로 local SGD를 수행한 뒤 환자별 model update를 clipping하여 평균과 Gaussian noise를 적용한다. 환자 단위 보호가 핵심이며, 한 번의 환자 평균 gradient와 여러 local step의 update clipping은 같은 알고리즘이 아니다. [방법 pp.4–5](../pdfs/B02.pdf#page=4)

적응적 noise 선택에는 exponential mechanism을 사용한다. 따라서 선택 과정의 privacy cost까지 포함해야 한다. 병리 분류 ResNet18에서 adaptive 설정 accuracy 95.23%, ε=6.97, δ≈5×10⁻⁴를 제시하며 환자는 1,000명이다. δ와 모집단이 현재 CXR 설정과 다르다. [실험 p.7](../pdfs/B02.pdf#page=7)

‘환자 단위 clipping을 의료영상에 적용’은 이미 CVPR 2019의 기여다. 분류 모델이므로 최신 diffusion 생성 품질의 직접 SOTA는 아니며, 환자 DP 학습 구조의 필수 선행으로 인용한다. 검토: pp.4–5, 7 방법·표 발췌, 미재현. [공식 원문](https://openaccess.thecvf.com/content_CVPR_2019/html/Wu_P3SGD_Patient_Privacy_Preserving_SGD_for_Regularizing_Deep_CNNs_in_CVPR_2019_paper.html)
