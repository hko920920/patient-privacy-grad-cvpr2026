# Patient-level Machine Unlearning in LDMs — 미해결 근접 선행

공식 OpenReview PDF의 검색 노출 내용에서 첫 페이지와 p.3의 Table 1·실험·결론을 직접 확인했다. PDF와 API의 전체 접근은 제한되어 p.2 방법 수식을 확인하지 못했다. [공식 원문](https://openreview.net/pdf?id=x83b7ybcB1)

환자 단위 diffusion unlearning의 privacy–utility trade-off를 세 전략으로 평가하고 KL-Away를 제안한다고 명시한다. 따라서 ‘환자 단위 forget을 diffusion에 처음 적용’한다는 피벗은 이 선행을 검토하기 전 주장할 수 없다.

Table 1은 원 모델의 patient identifiability 15.8%, clinical classifier AUC .88과 KL-Away 7.2%, .83, SISS 6.8%, .52를 대조한다. 이 AUC는 membership가 아니다. 동일 Re-ID network로 forget set을 구성하고 익명화도 평가하는 순환성을 저자 스스로 명시한다. 유한 생성물에서 발견되지 않은 환자가 이후 드러날 수 있다는 한계도 있다.

unlearning은 기존 학습 영향의 제거, DP는 인접 학습 데이터에 대한 출력 분포 보장이다. 둘을 같은 ε baseline처럼 비교하지 않는다. 우리 현재 audit 방향의 직접 공격 SOTA는 아니지만, 삭제·익명화로 방향을 바꿀 경우 반드시 방법 원문을 해결해야 한다. 검토 수준: **공식 원문 일부**, 전체 분석 미완료.
