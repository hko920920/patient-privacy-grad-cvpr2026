# DP-LoRA — private fine-tuning의 필수 기준선

공개 데이터로 사전학습한 LDM의 QKV 및 출력 projection에 LoRA를 넣고, 비공개 영상의 per-example DP-SGD와 noise multiplicity를 결합한다. 따라서 DP+LoRA나 noise multiplicity 자체는 새 기여가 아니다. [§§2–3](../pdfs/B08.pdf#page=2)

주요 비교는 MNIST·CIFAR·CelebA/HQ이며, 환자 단위 DP 실험은 아니다. Table 12의 대표 최적 설정은 rank 16으로, 현재 로컬 rank 8과 같지 않다. 학습 모듈·공개 사전학습·해상도·noise multiplicity를 맞춰야 보호 단위의 효과와 모델 용량 효과가 분리된다.

Table 10에서 CelebA64는 k=4→8일 때 시간이 70→140분/epoch로 늘지만 FID는 8.41→8.94다. multiplicity 증가는 항상 성능 개선을 보장하지 않는다. Table 15·18은 DPImageBench의 재현값과 원 논문 수치의 큰 차이를 직접 보여준다. 최고 보고 숫자끼리의 단순 대조를 피해야 한다. [Tables 10·12·15·18](../pdfs/B08.pdf#page=7)

필수 arm은 원형 record-DP LoRA, 동일 backbone의 patient-DP 적응형, 공개 조건을 맞춘 DP-LDM이다. 환자 adjacency와 회계는 별도 검증한다. 고정된 DP 모델을 반복 질의하는 post-processing은 학습 DP 예산을 추가로 소비하지 않으며, 논문의 관련 설명을 재질의당 학습 예산 소모로 해석하지 않는다.
