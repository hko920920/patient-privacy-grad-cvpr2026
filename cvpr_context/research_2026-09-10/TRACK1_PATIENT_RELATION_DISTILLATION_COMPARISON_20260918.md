# 두 설계 비교: 환자 관계 보존 증류를 주력으로 권고

작성: 2026-09-18. 범위: 사용자가 붙여 준 GPT 설계 v2, 직전 assistant 설계, 저장된 결과·명부, 가까운 선행 원문, 별도 CPU 대수 검산.
상태: **주력 설계에 대한 비교·권고 완료. 새로운 성능 결과 또는 동결된 GPU 실행 계약은 아니다.**

## 1. 결정

주력으로는 **환자 관계 보존 DP 증류**를 선택하는 것이 더 타당하다. 직전의 캐시 기반 조건 대조 diffusion 적응은 후순위로 남기고, 두 방법을 동시에 개발하거나 억지로 결합하지 않는다.

이 판단의 근거는 관계 보존안의 성공 확률이 더 높다는 실증이 아니다. 관계 보존안은 보존할 정보, 그 정보를 사용하는 학습 목적, 정보의 제거 대조를 직접 연결한다. 반면 직전안에는 조건별 denoising energy 개선이 생성영상의 실제 분류 효용으로 전달되는지라는 미확인 연결이 여전히 길게 남는다.

| 비교 항목 | 캐시 기반 조건 대조 diffusion | 환자 관계 보존 증류 |
|---|---|---|
| 직접 최적화하는 것 | 같은 영상의 정답·오답 조건 denoising energy 차이 | 명시한 점별·환자 내 대조 분류 위험을 결정하는 통계 |
| 확실히 분석 가능한 연결 | 고정 noise bank에서 캐시와 head loss/gradient의 등가성 | 고정 특징의 이차 위험과 그 최적 선형 분류기의 근사 |
| 여전히 필요한 실증 | energy → 생성 내용 → 요청 라벨 → 분류기 → 실영상 효용 | 특징 통계의 이미지 실현, 실제 일반화, 다른 encoder로의 재사용 |
| 가장 구별력 있는 대조 | 동일 head/LoRA의 조건 loss 유무 | 같은 mixed 환자의 class별 목록을 고정하고 대응만 교란 |
| 가까운 선행 | HardNeg-DiffusionITM, DPT, DP-LoRA, 기존 cached SGD | PSG, LGM, DP-NTK, DP-KIP, Dosser, 사용자 관계를 보호하는 합성자료 |
| 이미지 출력의 필요성 | 생성모델 출력 자체가 목적이나 기존 전달 실패가 남음 | 다른 encoder에서도 학습자료로 쓸 수 있음을 보여야 필요성이 성립 |
| 현재 권고 | 실패 판정이 아니라 설계 우선순위 하향 | 아래 교정을 포함해 주력으로 구체화 |

두 안 모두 새 DP 정리 자체를 기여로 요구하지 않는다. 기존 원리를 문제에 맞게 연결하고, 강한 비교군 대비 의미 있는 효용과 대가를 보여주는 기여는 가능하다.

**선택할 논문 주장:**

> 환자 내 라벨별 평균 특징의 대조 위험을 환자 단위로 보호해 압축하고, 합성영상·대응관계·관계 학습 규칙으로 전달함으로써, 점별 증류가 보존하지 않는 학습 정보를 증류에 쓰지 않은 시각 encoder에서도 활용하게 한다.

이는 “모든 환자 관계”, 시간 경과, 인과적 질환 변화, identity 제거, 임상적으로 정확한 영상 편집을 보장하는 주장이 아니다. 또한 아직 실증된 기여가 아니라, 방법과 핵심 비교를 함께 선택한 검증 대상이다.

## 2. 현재 결과가 제공하는 근거와 제공하지 않는 근거

Rwide의 저장 결과는 같은 기존 학습 설정에서 개발 AUROC 0.544610 → 0.679434, AP 0.051669 → 0.103542의 개선이다. 이는 더 넓은 실제 학습자료가 유용했음을 보여준다. 환자 대응이 개선의 원인이거나, 고정 encoder의 16차원 특징에도 같은 신호가 보존된다는 증거는 아니다.

이번에 이미 사용된 expanded_training_manifest_private.csv의 metadata를 독립 집계했다.

| 출처 | 환자 | 영상 | 양성 환자 | 양·음성 모두 보유 |
|---|---:|---:|---:|---:|
| 기존 public real | 672 | 813 | 6 | 3 |
| 과거 classifier-selection, 사적 출처 | 2,027 | 5,097 | 114 | 102 |
| 합계 | 2,699 | 5,910 | 120 | 105 |

2,027명을 새 공개자료로 바꾸지 않는다. 이들은 원 private_train 출처이며 classifier calibration과 Rwide 학습의 소비 이력이 있다. 새로운 증류 분기는 이 자료 접근을 명시하는 별도 개발 연구다. 기존 private80 head/LoRA 결과와 자료량까지 같은 방법 비교인 것처럼 쓰지 않는다.

관계 통계에 실제로 기여하는 사적 환자는 102명이다. 공개 3명을 정확한 통계로 함께 합치고 전체 mixed 평균을 사용하면 분모는 105가 된다. 사적 평균과 공개 평균을 별도 가중하는 방식도 가능하나 두 정의를 혼용하지 않는다.

## 3. v2에서 맞는 수학

공개 고정 특징은 ||z||₂≤1, 환자별 class 평균 m_ic와 2차 모멘트 A_ic를 정의한다. 각 class가 있는 환자들을 동일 가중하고 class를 동일 가중하는 점별 위험은

F_point(w) = 1/4 ∑c E_i|c E_x|i,c (wᵀz(x) − (2c−1))²

이다. Mixed 환자의 δ_i=(m_i1−m_i0)/2에 대해 β/2 E_i (wᵀδ_i−1)²를 더하면,

H=(A₀+A₁)/2+βC,  v=(m₁−m₀)/2+βδ̄

가 맞다. 표본별 평균과 환자별 평균을 바꾸면 다른 목적이므로 그대로 명시해야 한다. 임의 CPU 배열에서 직접 위험과 이차 전개 최대 차이는 4.44×10⁻¹⁶이었다.

양·음성 존재 bit와 mixed bit, 각 class 평균·모멘트, δ·C를 결합하고 대칭행렬의 off-diagonal을 √2배하는 등거리 svec를 사용하면:

- point-only query의 add/remove 환자 감도 상한은 √6;
- relation 포함 joint query의 상한은 3;
- 서로 반대인 단위 특징을 가진 mixed 환자에서 joint norm 3을 실제 달성한다.

d=16의 joint 좌표 수는 3+3(136+16)=459이다. 기존 표준 [analytic Gaussian calibration](https://proceedings.mlr.press/v80/balle18a.html)을 사용하면 ε=8, δ=10⁻⁵, 감도3의 합계 좌표별 표준편차는 약 1.800687이다.

| 차원 | 관계 통계 잡음의 RMS L2 길이 / 102 | 같은 잡음 / 105 |
|---|---:|---:|
| 16 | 0.217651 | 0.211432 |
| 32 | 0.417765 | 0.405829 |

이 값은 sqrt(E||noise||₂²)이며 좌표당 RMSE가 아니다. 좌표별 표준편차는 102분모에서 약 0.01765다. Count 잡음, 사후 feasibility 보정, 신호 크기를 제외한 계산이므로 SNR 또는 성능 예측으로 해석하지 않는다. Point-only B에는 자기 감도 √6의 잡음(같은 예산에서 합계 표준편차 약1.470255)을 허용해야 한다.

서로 다른 전체 class 모집단과 mixed 모집단의 목표를 분리한 것도 맞다. 한 균등 pair bank의 모든 영상을 양쪽 목적에 동시에 쓰면 불필요한 평균 등식이 생긴다. 단, **두 물리적인 bank만 유일한 해결책은 아니다.** 하나의 영상 pool에 서로 다른 역할·가중치를 주어도 가능하다. 핵심은 두 모집단의 함수를 분리해 표현하는 것이다.

## 4. 구현 전에 반영할 세 가지 수학적 교정

### 4.1 대응 교란이 바꾸는 것은 평균 방향이 아니라 관계 2차 모멘트다

같은 mixed 환자들의 양성 평균 목록 p_i와 음성 평균 목록 n_i를 고정하고, n_i의 대응만 permutation하면:

δ̄_true = δ̄_shuffle

이다. Point 통계도 그대로다. 달라지는 것은

C = 1/4 E[p_ip_iᵀ+n_in_iᵀ−p_in_iᵀ−n_ip_iᵀ]

의 cross-moment다. 따라서 C 방법과 D 방법 사이에는

v_C = v_D,  H_C−H_D = β(C_C−C_D)

가 성립한다. 이 설계에서 실제 환자 대응은 **대조 방향들의 이차적 가중과 상관구조**에 작용한다.

이것은 약점만이 아니라 무엇을 시험하는지가 명확하다는 장점이다. 다만 “새 질환 평균 방향을 추출한다”라고 쓰면 틀린다. 같은 환자의 안정적 배경이 차분에서 상쇄된다는 설명만으로 실제 대응이 교란 대응보다 성능이 좋다는 정리도 나오지 않는다. 교란으로 늘어난 변동이 다른 정규화 효과를 줄 수도 있다.

D는 mixed 환자의 class별 centroid 목록에서 대응만 바꿔야 한다. 특히 사적 관계의 효과를 분리하려면 사적102명의 대응만 교란하고 공개3명의 대응은 C와 동일하게 유지하는 편이 명확하다. 전체 영상 목록을 환자 구분 없이 섞으면 방문 수·환자 가중치·mixed 모집단까지 바뀌어 다른 대조가 된다. Cross-patient shuffle의 DP 감도를 patient-local query의 3으로 복사하지 않으며 D는 우선 비DP 기전 비교로 둔다.

### 4.2 보존하는 것은 class-centroid 대조이며 모든 방문 쌍이 아니다

양성·음성 방문을 환자 안에서 독립 추출한다면,

E[(wᵀ(z⁺−z⁻)/2−1)²]
= (wᵀδ_i−1)² + 1/4 wᵀ(Σ_i1+Σ_i0)w.

v2의 C_i=δ_iδ_iᵀ는 오른쪽 첫 항의 위험을 보존한다. 방문 내 분산 항은 관계 목적에 포함하지 않는다. 이를 오류로 보고 무조건 새 통계를 더할 필요는 없다. 목적을 **환자별 class 평균 대조**로 정확히 좁히면 현재 식이 유효하다.

합성 pair도 통계적 대조의 대표물이다. 동일한 가상 환자를 방사선학적으로 정확하게 표현하거나 실제 환자와 일대일 대응한다고 가정하지 않는다.

### 4.3 불가능한 noisy 목표와 직접 통계 분류기의 안정성은 구분한다

**2026-09-18 정정:** 이전 제목의 “유효한 모멘트로 보정해야 한다”는 의무 표현은 과했다. 실현 불가능한 noisy 목표 M̃에도 min_S ||M(S)−M̃||²는 정의된다. 제거할 수 없는 잔차가 남을 수 있지만, 그 사실만으로 잘못된 알고리즘이 되는 것은 아니다. 실제 유계 특징의 모멘트는 최소한

A_c − m_cm_cᵀ ⪰ 0,  C − δ̄δ̄ᵀ ⪰ 0,
tr(A_c)≤1, tr(C)≤1

을 만족한다. 이런 통계적 조건을 만족하는 것과 해당 encoder의 실제 이미지로 실현되는 것은 다르다. Count의 noisy normalization에는 분모의 public floor 등 정의역·처리 규칙을 사전에 정해야 한다.

이전 CPU 검산에는 한 가지 결정적 보정을 구성했다: 평균을 unit ball로 제한하고, (A−mmᵀ)의 음의 고유값을 제거한 뒤, 남은 trace를 1−||m||² 안으로 제한한다. 이것은 선택 가능한 DP 후처리이며 최근접 projection 또는 이미지 존재 증명이 아니다. 채택한다면 B와 C에 같은 규칙을 적용하고 bias를 기록한다. 실제 성능을 본 뒤 보정 유무를 고르는 근거로 사용하지 않는다.

실제 합성영상의 특징으로 구성한 H_S는 PSD다. 그러므로 λ>0의 실제자료–합성자료 최적점 섭동 bound는 noisy 목표를 투영하지 않아도 적용할 수 있다. 반면 raw noisy H̃를 직접 역행렬에 넣는 분류기는 별도 문제다. H̃+λI의 양의 정부호성이 필요하며, PSD 투영 또는 사전에 정한 ridge 안정화 등을 명시해야 한다. Indefinite H̃에 원래 λ를 분모로 한 bound를 무조건 적용할 수는 없다. 어떤 bound도 AUROC 개선을 보장하지 않는다. 오차는 privacy/count noise, 채택한 보정, 이미지 실현으로 구분한다.

또 32개 등가중 특징의 centered covariance rank는 최대31이다. d=32의 full-rank 목표를 class당32장 또는32 pair delta로 정확히 맞추는 것은 일반적으로 불가능하다. d=16은 이 rank 장애가 없으나 이미지 feature manifold의 실현 제약은 남는다.

## 5. 가장 중요한 논문 대조: 다른 encoder에서도 쓰이는가

**동일 encoder와 동일 이차 목적이라면 noisy H,v를 공개하고 w=(H+λI)⁻¹v를 계산하는 편이 더 직접적이다.** 이것은 약하게 만들어 이겨야 하는 baseline이 아니라 동일 정보를 사용한 정확한 surrogate readout이다. 실영상 AUROC의 수학적 상한이라는 뜻은 아니다. 영상 표현 제약이 정규화로 작용해 held-out AUROC가 높아질 가능성은 있다.

그러므로 합성영상의 필요성을 보여주는 비교를 마지막 선택 사항으로 미루면 안 된다.

- Encoder E₁에서 증류하고, matching에 쓰지 않은 공개 encoder E₂에서도 영상과 pair 정보를 사용해 학습한다.
- E₂에서도 relation loss를 사용하는 것이 정당하다. 출력 계약에 pair 정보와 learner rule이 포함되기 때문이다.
- E₂는 증류 목적, 합성영상 선택, 최적화 checkpoint 선택에 쓰지 않는다.
- 같은 encoder에서는 direct noisy-moment predictor와 증류 readout의 차이를 보고 압축·실현 손실을 계량한다.
- 기존 ResNet18 BCE에서 pair를 무시한 전이는 secondary로 둔다. 이것의 성공은 “관계를 제공하지 않아도 쓸 수 있는 이미지”라는 추가 장점이다. 실패했다고 정당한 pair-aware cross-encoder reuse까지 부정하지 않는다.

고정 E₁에서만 좋아지고 cross-encoder 전달이 없다면, 환자 관계를 활용한 feature predictor 가능성은 남아도 **재사용 가능한 시각 증류자료**라는 주장은 확보되지 않는다. 이 기준을 처음부터 핵심 결과표에 넣는다.

공개 encoder와 projection은 private 자료로 선택하지 않는다. 보존 정리는 같은 고정 feature·전처리 위험에 관한 것이다. 합성 쪽에만 augmentation을 적용하면서 실자료 고정 모멘트와 정확히 같은 위험이라고 쓰지 않는다. Augmented 위험을 택한다면 실자료와 합성자료의 augmentation 평균·pair coupling까지 동일하게 정의해야 한다.

## 6. 선행 대조: 원문의 목록만으로 신규성을 확정할 수 없다

|---|---|---|
| [PSG, NeurIPS2022](https://arxiv.org/abs/2211.04446) | 판별적 정보를 이용한 compact private synthetic set | 판별 정보 선택 자체가 아니라 환자 내 관계의 추가 가치 |
| [LGM, NeurIPS2025](https://arxiv.org/html/2511.16674v1) | 고정 self-supervised encoder, 선형 분류 gradient matching, image pyramid와 augmentation, 다른 encoder 전이 | 선형 학습신호와 전이 자체가 아니라 보호된 관계 위험의 보존 |
| [CovMatch, NeurIPS2025](https://arxiv.org/html/2510.18583v1) | 이미지–텍스트의 선형 대조 목적을 centered cross-covariance 정합으로 연결하고 다른 architecture 전이를 평가 | 관계 2차 통계 정합·전이 원리 자체를 신규성으로 쓰지 않기; 환자 쌍에 대한 가장 가까운 연산 대조 포함 |
| [DP-NTK, JAIR2024](https://doi.org/10.1613/jair.1.15985) | finite feature 통계를 보호하고 synthetic 최적화에 재사용 | one-shot 후처리 자체가 아니라 무엇을 추가 보존하는지 |
| [DP-KIP-ScatterNet, TMLR2024](https://arxiv.org/abs/2301.13389) | kernel ridge와 DP dataset distillation | 이차 학습 연결·DP 증류 자체를 신규성으로 쓰지 않기 |
| [Dosser, ICCV2025](https://arxiv.org/html/2508.01749v1) | DP 학습신호 추출과 반복 증류 최적화의 분리, informative projection을 통한 noise 효율 | cached/저차원/추출 후 반복 최적화만으로 차별화하지 않기 |
| [DP pairwise learning, IJCAI2021](https://www.ijcai.org/proceedings/2021/446) | pairwise 목적과 DP의 결합 | 직접 predictor를 넘어 영상·관계 산출물의 재사용 가치 |
| [PATH, 2026 preprint](https://arxiv.org/html/2602.02766v1) | 사용자 단위 DP와 개별 행 이상의 사용자 내 이력을 보존하는 tabular synthesis | “독립 행이 아닌 사용자 관계를 보호한다”는 광범위 최초 주장 금지 |
| [InfoDist, MICCAI2024](https://papers.miccai.org/miccai-2024/400-Paper0484.html) | 의료 합성영상의 선택·증류와 downstream 활용 | 의료+증류 자체를 기여로 쓰지 않기 |
| [Private Face Distillation, 2026 preprint](https://arxiv.org/html/2607.27764v1) | geometry/topology를 보존한 proxy image 공개, identity decoupling | 관계를 영상으로 옮긴다는 광범위 신규성 금지; 해당 privacy 설명을 자동으로 patient-DP와 동치 취급하지 않기 |

특히 DP-KIP, Dosser, PATH, CovMatch를 빠뜨리면 주장 범위가 과도해진다. 모든 논문을 첫 구현에서 재현하라는 뜻은 아니다. 같은 자료·예산의 강한 점별 증류와 direct private predictor에 더해, §11의 관계 사용 가능 moment-matching 대안과 연산을 대조한다. B가 임의의 약한 자체 baseline에 머물거나, 관계를 쓸 수 있는 기존 원리를 제외하면 알고리즘 우위의 근거가 부족하다.

따라서 원문의 “기여 세 개”를 각각 독립적으로 새 원리라고 제시하지 않는다. 더 설득력 있는 핵심은 **patient-local 관계 위험을 보존하는 재사용 가능한 시각 자료를 구성했고, 같은 접근·개인정보 예산의 점별 방법보다 유용했다**는 하나의 방법 기여다. 두 bank, bounded query, perturbation 분석은 이를 성립시키는 구성·근거다.

## 7. 권고하는 한 묶음의 연구 비교

새로운 진단을 하나씩 통과해야만 다음 결정을 내리는 무기한 순서로 만들지 않는다. 처음부터 다음 결과표를 얻는 하나의 비교로 묶는다.

**출력 조건:** A 공개 point128 / B 공개+사적 point128 / C point64+실제관계32pairs / D point64+교란관계32pairs.

**공통 조건:** 공개 encoder·projection·이미지 표현·초기화 대응·허용 augmentation·총128장·최적화 예산을 일치시킨다. 데이터는 public672와 private-origin2027로 명시한다. C/D는 사적 mixed102명의 대응만 다르게 하고 공개 mixed3명은 동일하게 둔다.

**가장 가까운 관계 대안:** 표준 차분-feature moment matching은 C의 관계 연산과 같은 조건에서 동일할 수 있다. 이를 다른 이름의 약한 arm으로 만들지 않고 §11처럼 동일성을 먼저 인정한다. Paired joint moments를 직접 맞추는 구성이 실제로 다른 경우에만 동일 접근·총privacy budget의 비교로 명세한다. A/B/C/D는 정보 가치의 제거 대조이며, 그것만으로 모든 관계 사용 가능 선행보다 새로운 알고리즘이라고 주장하지 않는다.

**같은 패키지의 평가:**

1. E₁의 real point/real relation readout 및 direct moments와 각 synthetic readout: 실제 통계의 정보, 합성 실현 손실, 실제 개발 성능을 함께 측정한다. 이전 Rwide0.679를 다른 encoder의 상한으로 복사하지 않는다.
2. C−B, C−D: 같은 개발 환자에서 AUROC/AP, paired patient-cluster uncertainty, bank별 효과를 보고한다. 같은 C 영상의 relation-loss 유무도 포함하되 어느 bank가 점별 학습에 쓰이는지 명시한다.
3. E₂의 pair-aware 전이: C−B, C−D를 동일하게 본다. E₂ 결과는 E₁ 합성 최적화에 피드백하지 않는다.
4. 기존 ResNet18 BCE 전이: 영상만 배포했을 때의 secondary 효용으로 보고한다.
5. DP 단계의 A/B/C 및 direct noisy-moment predictor: 총 privacy budget을 맞추되 각 방법은 자기 감도·좌표 수를 사용한다. D에 잘못된 patient-local DP를 붙이지 않는다.

첫 비DP 비교에서 한 bank의 우연을 또 후속 진단으로 넘기지 않도록, 계산량을 확인한 뒤 고정된 소수 paired initialization(예:3)을 전체 패키지의 일부로 사전 포함하는 편을 권한다. 아직 실행시간·encoder·β·λ·projection·학습량이 동결된 것은 아니므로 지금을 실행 준비 완료라고 쓰지 않는다. 이는 남은 구현 명세 항목이지 새 연구 주제를 더 찾아야 한다는 뜻은 아니다.

DP 결과를 위한 여러 noisy summary 공개는 composition을 적용한다. 하나의 공개 summary로 여러 합성 초기화를 최적화하는 것은 postprocessing이지만, private 결과를 보며 summary/encoder/seed를 고르는 선택은 자동으로 면제되지 않는다. 과거 비DP 접근과 결과가 소급해 보호되지는 않는다.

## 8. 결과에 따른 고정된 해석

| 결과 | 유지할 판단 |
|---|---|
| C가 B·D보다 낫고 E₂에서도 관계를 활용하며 DP 아래 유지 | 선택한 시각적 환자 관계 증류 기여를 직접 뒷받침 |
| C가 B보다 낫지만 D와 차이가 없음 | 관계 목적·추가 bank의 이득 가능성; 실제 환자 대응 보존의 기여는 미확보 |
| E₁에서만 좋고 E₂에서는 전달되지 않음 | 특정 feature의 관계 predictor 가능성; 재사용 가능한 이미지 자료 주장은 미확보 |
| 비DP에서는 전달되나 같은 예산의 DP B보다 약함 | relation 차원·표본·잡음의 대가가 현재 이득보다 큼; patient-DP 효용 기여 미확보 |
| B와 C 모두 전이되지 않음 | 현재 통계·특징·이미지 실현 구성의 음성 결과; 자동으로 다음 adapter/encoder sweep을 시작하지 않음 |

“어떤 결과든 논문이 된다”는 약속은 하지 않는다. 대신 어떤 결과가 선택한 기여를 지지하는지를 명확히 하고, 결과를 본 뒤 다른 성공 정의로 바꾸지 않는다. 실패의 모든 원인을 알아내야 방향을 제안할 수 있다는 요구도 하지 않는다.

## 10. 반대 권고문까지 받은 뒤의 재검토 — 2026-09-18

사용자가 GPT의 새 글(캐시 조건 대조를 주력으로 권고)을 전달해 두 추천의 충돌을 다시 검토했다. 그 글의 기술 설명 대부분은 타당하다. 그러나 그것이 캐시안의 실증적 우위나 더 높은 논문 성공 확률을 입증한 것은 아니다. 직전 assistant의 “관계안이 낫다”도 같은 수준의 우위를 확인한 답처럼 단정해서는 안 된다.

### 10.1 이번에는 선택 기준을 먼저 명시한다

상위 목표는 보호 설계·효율에 관한 **의미 있는 논문 기여**다. 원래 생성기·분류기 코드를 적게 바꾸는 것은 구현 비용의 장점이며, 반드시 유지할 연구 목표라는 추가 사용자 제약은 없다.

우선순위 판단은 다음 네 기준을 공통 적용한다.

1. 실제 private information transfer와 환자-DP라는 상위 목표에 연결되는가.
2. 강한 기존 방법을 허용한 뒤에도 추가로 입증할 내용이 구체적인가.
3. 내부 최적화 지표와 실제 재사용 효용 사이의 간격을 대조로 드러낼 수 있는가.
4. 원자료 접근·초기 추출·최적화·출력 제작·downstream까지 포함한 비용을 정직하게 비교할 수 있는가.

**이 기준에서 주력 설계 권고는 관계 보존 증류로 유지한다.** 이는 새로운 효용 증거에 따른 승자 판정이 아니라, 정보 보존의 추가 가치를 중심으로 기여를 조직하겠다는 연구 선택이다. 구현 연속성이 최우선인 목표라면 캐시안이 더 합리적일 수 있다. 두 기준을 말없이 바꾸며 “객관적으로 더 낫다”고 반복해서는 안 된다.

관계 손실을 새로 정의했다는 이유만으로 관계 보존의 필요성이 입증되지는 않는다. 따라서 수식 연결만으로 관계안을 우위라고 한 이전 설명의 강도는 낮춘다. 유지할 이유는 수식의 존재 자체가 아니라, 실제 환자 대응이 제공하는 추가 정보와 그 시각적 재사용을 같은 점별 자료 아래 직접 평가하는 기여를 선택했기 때문이다. 캐시안도 의미 있는 전체 효용–비용 우위를 얻으면 충분히 연구 기여가 될 수 있으며, 표준 대수 사용만으로 배제하지 않는다.

### 10.2 같은 대상을 비교한 것이 아니었던 부분

로컬 캐시 상세안 §6의 실제 조건은 head 적응 public32/private80이다. GPT 새 권고는 이를 P=기존 공개자료, Q=former-selection2027로 바꾸는 새 실험을 제안했다. GPT는 로컬 상세 문서를 보지 못했다고 명시했으므로 이를 허위 검토라고 비판하지 않는다.

하지만 **Qwide 버전 캐시안의 우선순위**는 원 private80 캐시안에 없던 자료 접근 변경을 포함한다. 관계안의 Qwide 사용은 새 가정으로 세면서 캐시안의 Qwide 확대는 기존 조건 유지라고 세면 안 된다.

두 주력 후보를 동일 자원에서 판단하려면 public672/813, private-origin2027/5097, 같은 method-development 및 expert/reserved 보존이라는 정책을 양쪽에 공통으로 가정해야 한다. 이것은 비교를 위한 정의이며 실제 환자 역할 변경이나 새 실험 실행은 아니다. 기존 Q80 head/LoRA 실패는 새 Qwide 셀을 대신하지 않는다.

또 private point 정보는2027명 전체에서 오지만, 양성 환자는114명이고 mixed는102명이다. “2027 대102”만으로 두 방법의 질환 유효 표본을 비교할 수 없다. Mixed102는 private 양성114명의 약89.5%다. 그렇다고 relation 통계의 작은 분모와 추가 DP 좌표 비용이 사라지는 것은 아니다.

### 10.3 GPT의 캐시 설명에서 받아들이는 부분

- 조건부 MSE도 조건을 학습한다. 새 목적의 차이는 같은 영상의 반대 조건과의 상대 오차를 명시적으로 요구하는 것이다.
- A/B/Q에서 조건별 D(W)를 계산하고 비선형 Ψ에 chain rule을 적용하는 것은 정확하다.
- 비선형 전후의 평균 순서, 유한 observation bank, 환자 clipping/DP 회계 경계 설명이 맞다.
- 같은 head의 MSE/CC, 같은 CC의 head/LoRA, 같은 head/CC의 직접/feature-cache/stat-cache 비교는 서로 다른 질문이며 분리하는 것이 맞다.
- 관계안의 위험 보존이 선택한 encoder·surrogate 밖으로 자동 전이되지 않는다는 비판도 맞다.

[HardNeg-DiffusionITM](https://arxiv.org/html/2305.16397v3)은 positive/negative denoising 학습에 직접 근거를 제공한다. [DPT](https://arxiv.org/html/2403.04321v2)는 판별적 tuning을 생성 정합성 개선에 활용했다. 따라서 캐시안은 목적 선택의 문헌 근거를 갖는다. 다만 이 선행은 우리256-parameter output head의 효용을 검증하지 않는다.

### 10.4 캐시안에 유리하게 계산된 세 가지 비대칭

**영상의 필요성:** 현재 주장 자체가 private synthetic downstream utility라면 “왜 직접 DP 분류기를 공개하지 않는가?”는 두 안 모두 받는 질문이다. 캐시안은 generator를 계속 만든다는 이유만으로 이 질문에서 면제되지 않는다. 추가 조건 생성·다른 learner 재사용·자료 접근 정책 등에서 영상 출력의 목적을 설명해야 한다. 반대로 관계안의 다른 learner가 pair metadata를 사용한다고 부당한 평가 변경이 되는 것도 아니다. 그 메타데이터가 출력 계약의 일부이기 때문이다.

**Backbone 계산 제거:** 기존 [환자-DP 실행 기록](TRACK1_PATIENT_DP_RESULTS_20260916.md)에 same-head DP-SGD가 이미 A/B cache로 새 backbone0F/0B였다고 기록돼 있다. 당시 full64 fit은 평균 약0.534초였고 이전 특징 추출은314.687초였다. 서로 다른 작업량의 시간을 속도배수로 비교하지는 않지만, 원래부터 추출 비용을 포함해야 했다는 사실은 분명하다.

새 캐시안의 실질적 확장은 영상별 두 조건의 통계를 보존해 비선형 조건 목적까지 계산하는 것이다. 기존에도 없던 UNet backward를 새로 제거했다고 세지 않는다. Feature-cache baseline 역시 강하게 구현해야 한다. 추가 조건 추출·Gram 누적·저장/IO 비용을 포함한 총비용 우위는 아직 측정하지 않았다.

**가정의 개수:** 관계안의 관계 유용성·이미지 실현·전이를 각각 나누어 세면서 캐시안은 “조건 loss가 생성 효용으로 연결” 하나로 묶으면 복잡도 비교가 기운다. 캐시안에도 고정256-parameter 특징의 조건 표현력, 유한 noise bank 일반화, 반대 조건 악화에 의한 margin 증가, 생성 요청 라벨의 충실도, downstream 전이, DP 아래 유지가 남는다. 반대로 관계안의 fixed feature 표현력과 cross-encoder 전이는 가볍게 볼 수 없다. 항목 개수를 성공 확률로 환산하지 않는다.

### 10.5 양쪽 수학의 한계를 똑같이 검사했다

새 [소규모 CPU 구성 예](two_design_inference_limits_20260918.py)와 [출력](spec_sources/two_design_inference_limits_20260918.json)은 다음 두 추론이 일반적으로 성립하지 않음을 확인한다.

- 캐시 CC: 정답 조건 출력은 그대로인 상태에서 오답 조건 오차만 커져도, 복원 항과 작은 anchor가 있는 전체 loss가0.9193→0.0740으로 줄어드는 예가 있다.
- 관계 증류: E1의 점별·관계 모멘트가 정확히 같은 real/synthetic 자료인데, 다른 E2에서 synthetic으로 학습한 분류기의 순위가 뒤집히는 예가 있다.

임의 배열의 논리적 반례이며 실제 의료 성능 예측이 아니다. 이 검사를 새 성능 gate나 대규모 환자 재감사의 시작으로 사용하지 않는다.

[ DPT 원문 Appendix A.4](https://arxiv.org/html/2403.04321v2)도 일정 tuning 이후 판별 성능과 생성 성능의 양상이 달라질 수 있음을 보고한다. [LGM](https://arxiv.org/html/2511.16674v1)은 gradient matching만으로 특정 encoder에 과적합할 수 있으며 전이에 표현·증강이 중요함을 보고한다. 문헌 역시 양쪽의 남은 전달 문제를 없애주지 않는다.

## 11. CovMatch와 noisy-moment 지적 반영 — 2026-09-18

사용자가 전달한 GPT의 최신 검토는 관계 증류를 다시 주력으로 권고하면서 CovMatch, 모멘트 보정, 관계 사용 가능 대조를 지적했다. **주력 권고는 유지하고 이 세 항목을 설계에 반영한다.** AI 간 추천 일치는 증거가 아니며, 이 문서는 성능·최초성·실행 계약의 확인이 아니다.

### 11.1 원문에서 확인한 중복과 차이

[CovMatch §3–4](https://arxiv.org/html/2510.18583v1)는 centered image–text cross-covariance와 feature mean을 맞춘다. 실제자료로 encoder를 반복 업데이트하며, 다른 architecture 전이도 평가한다. 우리 목적은 patient class-centroid 차분의 raw 2차 모멘트이며, 공개 고정 encoder와 환자 단위 보호 요약을 사용한다. 따라서 동일 알고리즘은 아니지만, “관계 통계로 학습을 보존하고 다른 모델에 전이”라는 넓은 원리는 이미 선행에 있다.

원문의 실제자료 encoder 업데이트를 사적 환자자료에 그대로 적용하면 일회 보호 요약만 사용하는 경계가 깨진다. 이 비교는 별도 보호·회계가 필요한 변경이다. 반대로 공개 encoder 고정과 환자-DP를 붙였다는 사실만으로 신규성이 자동 성립하지도 않는다.

### 11.2 차분 feature의 기존 moment matching과 같은 부분을 인정한다

u_i=[p_i;n_i], L=[I/2,−I/2]라 놓으면 정확히

δ_i=L u_i,  δ̄=L E[u_i],  C=L E[u_i u_iᵀ]Lᵀ.

따라서 같은 weighting·feature·release·손실을 쓰는 **δ_i의 표준 moment matching은 C의 관계 연산 자체**다. 이것을 새로운 알고리즘과 경쟁 baseline으로 두 번 세거나, 이름만 다른 구현을 약하게 만들어 비교하지 않는다. 이 동일성은 대수적 사실이며 새 환자 실험을 요구하지 않는다.

전체 paired-feature joint moments를 맞추는 대안은 더 많은 제약을 보존할 수 있다. 그것과 contrast moments만 보존하는 설계는 통계 차원·감도·이미지 실현 제약이 달라질 수 있다. 별도 비교를 채택하면 각 방법의 bounded patient contribution과 같은 총 privacy budget을 적용한다. 두 방법의 noisy query가 동일하다고 가정하거나 CovMatch 원 논문의 환자-DP 재현이라고 부르지 않는다.

이후 기여는 새로운 covariance matching 법칙이 아니라, **환자 대응 정보가 보호된 시각 자료로 전달되어 다른 learner에서도 추가 효용을 제공하는 구성과 그 가치**다. C>B와 C>D는 이 정보의 가치를 검증하지만 기존 관계 방법 대비 알고리즘 우위를 단독으로 증명하지 않는다.

### 11.3 수학·평가의 남은 경계

§4.3에서 “불가능한 noisy target이면 최적화가 잘못됐다”는 이전 표현을 철회했다. Synthetic H의 PSD성과 raw noisy-moment predictor의 안정성은 구분한다. 모멘트 투영은 이미지 실현이나 다른 encoder 전이를 보장하지 않는다.

C−B는 합성자료와 학습 규칙을 포함한 전체 방법 효과다. 같은 C 산출물의 관계 손실 유무는 학습 규칙의 역할을 확인하며, C−D는 사적102명의 실제 대응을 시험한다. 서로 대체하지 않는다. 다른 encoder E₂는 합성 최적화뿐 아니라 β·checkpoint·bank 선택에서도 제외하고, 고정된 모든 산출물에 한 번의 대응 평가를 적용한다. E₂ 결과를 본 뒤 수정했다면 이후 E₂는 미사용 encoder가 아니라 development 이력이 있는 encoder다.

이 검토에서는 primary source와 설계 수식만 읽고 문서를 수정했다. 새 환자 metadata/pixel/model/GPU/학습/합성/DP release는0이다. 기존 결과·명부·expert/reserved·실제 결과 포인터는 유지한다. 다음 작업의 방향은 동일한 통합 비교의 실행 명세·구현이며, 후보 주제 재선정이나 새 대규모 진단은 아니다.
