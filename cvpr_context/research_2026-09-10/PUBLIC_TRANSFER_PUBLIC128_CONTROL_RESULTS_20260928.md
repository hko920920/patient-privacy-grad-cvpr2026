# 3번 결과: 공개영상 128장과 기존 합성영상의 같은 라벨 계산 비교

2026-09-28 · Stage2 · 승인된 8개 라벨 대조 완료

## 결론

**이번 고정 조건에서는 별도로 제작한 합성영상의 추가 개발 효용이 확인되지 않았다.**

같은 두 DP 요약과 같은 라벨 계산을 허용했을 때, DenseNet AUROC의 합성−공개영상 평균 차이는:

- 공개 전달 **RN-only: −0.012491**, 95% 환자 구간 **[−0.035938, +0.009671]**.
- **DINO+RN Joint: −0.000997**, 구간 **[−0.024772, +0.022057]**.

두 recipe 모두 사전에 정한 합성영상 추가 투자 기준을 충족하지 못했다. 공개영상이 보편적으로 더 낫다거나 두 carrier가 동등하다는 결론은 아니다.

**여기서 공개128에도 기존 보호 요약으로 계산한 라벨을 붙였다.** 따라서 이 비교는 사적 정보의 필요성이 아니라, **그 정보를 전달하는 데 기존 합성영상 제작이 추가로 필요한지**를 물었다. 공개128을 완전한 public-only 방식으로 부르면 안 된다.

1번의 정의한 teacher-score KD 대비 개선은 그대로 남는다. 2번에서 Joint의 RN-only 대비 우위가 미확인이라는 결과도 유지한다. 이번 결과를 ‘공개영상 재라벨링이라는 새 기여를 완성했다’로 바꾸지 않는다.

공개128은 P의 813장/672명에서 선정했다. 양성 방문이 있는 6명은 각자 양성 영상 한 장을 포함하고, 나머지122명은 DINO/RN 공개 특징에서 고정된 farthest-first 규칙으로 골랐다. DP 목표·DenseNet 특징·V는 선정에 사용하지 않았다. 동일한 공개128을 두 release와 두 recipe에 재사용했다.

원본 공개영상과 기존 합성 PNG는 복제하거나 재가공하지 않고 경로·해시로 결속했다. 기존 전처리·조건·projection의 캐시를 재사용했으므로 **새 모델 forward는 0**이다.

## 공통 라벨 규칙과 역사적 결과의 관계

이번의 목표는 영상 carrier 비교다. 합성영상은 원래64:64 hard labels지만 공개 P의 양성 환자는6명이다. 한쪽의 원래 label anchor를 다른 쪽에 임의로 강제하지 않도록, 계획대로 **양쪽 모두 zero-centered regularizer**를 사용했다.

```text
min_{-1 <= l <= 1} ||A l - t||² + eta ||l||²
eta = 1e-3 * ||A||_F² / 128
```

모델별 공개 weighted target RMS와 모델 가중치는 같은 recipe의 양쪽 carrier에 동일하다. η는 같은 **산출 규칙**이며 operator가 달라 수치까지 같다는 뜻은 아니다.

원래 hard-anchor 합성 결과와 이번 zero-anchor 합성 AUROC를 기술적으로 비교하면 다음과 같다. 이는 주된 carrier contrast와 구분한다.

| 합성 조건 | 기존 hard-anchor | 이번 zero-anchor | 점차이 |
|---|---:|---:|---:|
| RN-only DP1 | 0.713564 | 0.712133 | −0.001431 |
| RN-only DP2 | 0.648230 | 0.648261 | +0.000031 |
| Joint DP1 | 0.686370 | 0.686256 | −0.000114 |
| Joint DP2 | 0.663404 | 0.663443 | +0.000039 |

따라서 이번 주 비교에서 합성군을 다른 라벨 규칙으로 새로 계산한 것은 맞지만, 해당 점추정이 과거 성능에서 크게 떨어진 상황은 아니었다. 이것만으로 regularizer의 일반적 무관성을 입증한 것은 아니다.

## 수치 검산과 최초 실패 보존

공개128의 greedy 선정은 별도 full-distance 구현과 정확히 일치했다. 라벨8개는 모두 봉인한 뒤에만 V를 읽었다.

최초 solver는 기본 TRF였다. DP2/SYN/RN-only에서 자체 성공 표시는 있었으나 독립 projected-gradient 값 **1.916×10⁻⁷**이 정한 **10⁻⁷** 기준을 넘었다. 성능 평가 전에 같은 목적함수를 active-set BVLS로 푸는 구현으로 통일했다.

- 목적함수·계수·라벨 범위·tol·max_iter를 변경하지 않았다.
- 모든8개 셀에 같은 BVLS를 적용했다.
- ±1에서 생긴 최대 **2.22×10⁻¹⁶**의 머신 오차만 canonicalize하고, 보정폭≤10⁻¹²를 확인했다.
- 최종 independent projected-gradient 최대 **1.11×10⁻¹⁶**.
- 평가 ridge primal/dual 예측 차이 최대 **6.66×10⁻¹⁶**.
- 기존 bootstrap 함수와 별도 sklearn 가중 지표 검산 차이 최대 **1.11×10⁻¹⁶**.

원본 계약·코드·첫4개 중간 label CSV·실패·진단은 [attempts](contribution_public128_control_20260928_v1/attempts/00_trf_projected_gradient_failure/failure.json)에 보존했다. 재계산은 수치 정확성 보정이며, V를 보고 label/solver를 선택한 것이 아니다. 최종8개 외에 첫시도5회·진단2회의 기술적 solve가 있었고 새 DP 잡음은 없었다.

검증 결과:
- 입력21개·구현17개·이전 결과보고서3개 해시 유지.
- 공개 원본128장과 모든 label packet의 이미지 해시 유지.
- 8개 CSV와 배열의 float roundtrip 정확히 일치.
- phase별 입력 접근 제한과 모든 라벨 봉인 후 최초 V 접근 확인.
- 추가 저장은 검증 시점 약 **3.45MiB**, 모델·이미지 복제 없음.

## 시간·보호 범위·해석 한계

공개128 선정 **0.50초**, 최종8개 라벨 계산·파일 작성 **2.047초**, 평가·bootstrap **13.188초**였다. 코드 연결·기존 전처리 확인·수치 실패 점검·기록을 포함한 실제 총시간은 `finalization.json`에 기록한다. 과거 합성영상 제작비용을 이번 계산시간에 다시 합산하지 않는다.

이번 새 Q 접근 **0**, 새 DP release **0**, pixel 학습 **0**, 모델 forward **0**. 기존 두 요약을 재사용한 후처리이며 과거 연구 전체를 DP로 보호한다는 주장이 아니다. 공개 영상에 붙인 라벨에는 DP 요약의 정보가 포함된다.

한 공개128 선정, 기존 두 합성 bank/DP release, 재사용한 DenseNet/V에서의 개발 결과다. 공개영상 선정 salt·합성 초기화·DP noise 모집단, full-network 학습, 새로운 환자집단 또는 untouched receiver에 대한 일반적 결론은 내리지 않는다. 공개 원본1024와 합성PNG224의 차이도 현재 carrier 구성의 일부이며, 모든 영상 제작 방식이 쓸모없다는 시험이 아니다.
