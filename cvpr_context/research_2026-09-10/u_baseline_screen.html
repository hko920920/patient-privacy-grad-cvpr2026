기존 SecMI 방법으로 확인한 E/U 진단

후속 실제 실행: PFAMI 고정 비교·독립 검산. 아래는 앞선 SecMI 실행 이력이며, 두 고정 진단의 결과를 전체 MIA의 실패로 일반화하지 않는다.

2026-09-14. 사용자의 실행 지시에 따라 기존 두 모델에서 SecMI-stat을 고정 설정으로 평가하고 독립 재검산을 완료했다. E와 핵심 U 모두 사전 진행 기준을 충족하지 못했다. 현재 후보 확대·R 튜닝·추가 target 학습은 보류한다.

1. 무엇을 확인하는가

핵심 연구 질문은 관측한 사진 자체가 학습에 없어도, 같은 환자의 다른 사진이 학습에 사용됐다는 신호를 얻을 수 있는가(U)다. 학습에 사용된 사진을 관측하는 E를 함께 평가한다. 후보 R의 새 기능을 더 조정하기 전에, 기존 공격에서 이 설정의 판별 신호가 확인되는지 검사한다.

  • 기존 개발 환자 8명과 방법 선택 환자 40명을 사용했다. 두 집단의 결과를 합치지 않는다.
  • 환자마다 E 후보 2장, U 관측 2장이다. 모델 1/2에서 참여 그룹을 교환한다. U 영상은 어느 모델에도 학습시키지 않았다.
  • 기존 non-DP LoRA 1,000-step 체크포인트 두 개를 사용한다. 두 모델은 같은 초기화·seed와 배경 환자를 공유하고 여러 환자의 포함 여부를 함께 바꾼다. 독립 seed 반복이나 한 환자만 바꾼 DP 이웃 모델이 아니다.
  • 방법 선택 40명은 앞서 공개 encoder 대조에서 사용한 개발 자료이며, 이번에 처음 target 공격 점수를 계산했다. 최종 시험 자료로 취급하지 않는다.

2. 고정 방법과 판정 규칙

확보된 CDI 저자 저장소의 SecMI-stat 구현을 현재 SD2.1 의료 모델에 이식했다. 저장된 클래스의 메서드를 그대로 호출하고, 모델·cached latent·prompt를 연결하는 어댑터를 추가했다. 원 SecMI 저자 저장소의 전체 재현, 전체 CDI 방법 재현 또는 최신 SOTA 전체 비교가 아니다.

  • VAE posterior-mode latent와 일반 흉부 X-ray prompt를 사용한다. 기존 FP16 cache와 모델 값을 FP32로 승격해 계산한다.
  • deterministic 경로 0→100을 10 간격으로 진행한 뒤 100→110→100의 왕복 오차를 구한다.
  • 영상 점수는 원 구현의 음의 L2 norm이다. 값이 클수록 참여 쪽으로 판별한다.
  • 환자 점수는 두 영상 점수의 평균이 주지표다. max 점수는 보조 설명에만 쓴다.
  • 이미지당 12 forward·0 backward, 총 384건·4,608 forward다. 여기서 forward는 이미지별 denoiser 계산 횟수이며 완성 이미지 생성 API 질의와 동일하지 않다.
  • denoiser와 모델 가중치에 접근하는 구현이다. 학습 데이터 전체를 모르는 설정과 양립하지만, 일반적인 완성 이미지 생성 API만으로 수행한 black-box 검증이라고 주장하지 않는다.

결과를 보기 전에 고정한 진행 기준: 선택 환자 40명의 평균 점수 AUC에 대해, 환자 bootstrap 95% 구간의 하한이 두 모델에서 모두 0.5를 넘어야 해당 조건의 순위 신호를 지지한다고 판정한다. E와 U를 따로 판정한다. bootstrap은 A/B 각 20명을 층화 재추출하며 seed 260914, 2,000회, 두 모델과 E/U에 같은 추출을 사용한다.

이 기준은 한 설정에서 다음 실험에 투자할지 결정하는 탐색적 기준이다. 검정력으로 산정된 최종 표본 규모나 독립 반복 실험의 확증 기준이 아니다. 기존 8명, max 또는 사후 점수 반전으로 주지표의 미통과를 뒤집지 않는다.

3. 실제 결과와 판정

주지표는 선택 환자 40명의 평균 점수다. 각 모델은 참여 20명·비참여 20명이며 AUC 0.5는 무작위 순위의 기준이다.

관측 조건 모델 1 AUC [환자 bootstrap 95%] 모델 2 AUC [환자 bootstrap 95%] 사전 진행 기준
E: 참여 환자에서 실제 학습에 들어간 영상 0.5225 [0.3350, 0.7025] 0.5000 [0.3125, 0.6825] 미충족
U: 같은 환자의 학습되지 않은 영상 0.4300 [0.2625, 0.6100] 0.5600 [0.3800, 0.7276] 미충족

판정: 현재 후보의 확대, 후보 R 튜닝 및 추가 target 학습을 보류한다. 핵심 U에서 다음 단계로 확대할 근거를 확보하지 못했고, E에서도 이 고정 공격이 일관되게 학습 참여를 구분한다는 양성 대조를 확보하지 못했다. 약한 결과의 원인이 학습 부족인지, 공격·prompt·timestep 적합성인지 또는 현재 조건의 작은 누출인지 이 결과만으로 구분하지 못한다.

기존 8명의 참고용 평균 점수 AUC는 E 0.5625/0.3750, U 0.5000/0.4375다. 이 표본과 보조 max 결과를 사용해 40명 주지표의 판정을 뒤집지 않는다.

4. 검증과 시간

  • 원시 latent 쌍 384개의 shape·dtype·hash와 L2, 환자 집계 192개를 별도 CPU 코드로 다시 계산했다. 실행기의 FP32 L2 384개는 모두 정확히 재현됐다.
  • 원시 FP32 tensor를 CPU float64로 승격해 L2를 별도로 계산했다. 최대 절대 차이는 8.2441×10⁻⁹이고, 16개 조건별 AUC 및 E/U 진행 판정은 바뀌지 않았다. GPU 연산 경로 전체의 FP64 재실행이라는 뜻은 아니다.
  • 평균 순위 방식으로 AUC를, 재추출 횟수 가중치 방식으로 2,000회 bootstrap 구간을 독립 검산했다. 별도 sklearn 계산에서도 16개 AUC가 일치했다.
  • 환자 분할·실제 학습 노출·E/U 정답·12단계 timestep과 scheduler alpha·출처 코드·checkpoint·cache hash를 확인했다. 보호 대상 원본 11개가 유지됐다.
  • 실행 중 가중치 불변은 실행기의 parameter version/gradient 검사와 모델별 adapter tensor 256개의 전후 동일성 검사에 근거한다. CPU verifier가 GPU 메모리를 별도로 재검사했다는 뜻은 아니다.

추가 target 학습, 후보 R의 새 환자 계산/튜닝, 보정·최종 시험 평가는 모두 0이다. 원본과 이번 결과는 별도 경로에 보존했다.

5. 해석 범위

이 실험은 현재 체크포인트, 고정 timestep·prompt·전처리에서 기존 공격의 신호를 확인한다. 미통과는 개인정보 누출이 없거나 환자 단위 MIA가 불가능하다는 증거가 아니다. 반대로 통과해도 후보 R의 우월성, 1% 환자 오탐률에서의 검출력, DP 보호 비교 또는 CVPR 기여가 입증되지는 않는다.

이전 후보 R은 기존 U 8명의 FP32 endpoint 평가에서 AUC 0.6875/0.2500으로 일관된 효과를 확인하지 못했다. 이번 진단은 후보 R을 40명에 확장하거나 튜닝하는 실행이 아니다. 장시간 추가 학습의 착수 여부도 이번 결과만으로 자동 승인하지 않는다.
