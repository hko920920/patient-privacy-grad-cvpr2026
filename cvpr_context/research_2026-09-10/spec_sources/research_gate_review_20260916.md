# 공개 기준선을 넘는 환자DP 생성 적응: 네 gate와 연구질문의 논리 검토
2026-09-16. 검토 대상은 전달된 네 gate/RQ 초안이다. 현재 [통합 계획](../REALISTIC_RESEARCH_PLAN_20260916.md)과 [실행가능성 메모](track1_replan_feasibility_20260916.md)도 직접 읽었다. 통합 계획에는 아래 정정이 이미 상당 부분 반영돼 있다. 새 실험·원자료 계산·기존 파일 수정은 없다.

## 1. 승인할 큰 방향
공개 적응으로 이미 얻는 이득을 분리하고, 공개+사적 비보호 참고점 → 보호 아래의 생성 효용 → 실제 전체 비용으로 연결하는 방향은 타당하다. 같은 환자 보호, 공개 정보, 표현, 목적을 맞춘 강한 DP-SGD를 비교하는 것도 필요하다. 표준 solver를 사용한 생성 적응 구성·실증 기여를 허용하고, 별도 solver 발명을 논문의 필수조건으로 두지 않는 현재 통합 계획에 동의한다.

다만 gate는 **투자 순서를 정하는 판단점**이어야 한다. 모든 선행의 실패나 인과원인의 완전한 확정을 새로운 후보 설계의 선행 허가조건으로 만들면 안 된다.

## 2. 반드시 고칠 표현과 조건
| 초안의 표현/조건 | 정확한 수정 |
|---|---|
| Public-only = 공개 상한 | 고정된 공개 baseline/reference. 특정 공개32 ridge가 모든 공개 학습법이나 생성 효용의 상한은 아니다. |
| Pooled 비DP = private incremental upper bound | 같은 표현·가중치·lambda·finite bank에서의 비보호 최적화 참고점. 해당 regularized training loss에서는 최적이지만 held-out MSE·생성 품질·모집단 추가 효용의 상한은 아니다. |
| Warm start = 별도 private transfer 능력 | 고정 특징·같은 목적·lambda>0의 convex ridge에서는 충분히 수렴한 해가 초기값과 무관하다. Warm start는 유한 계산, clipping, DP noise의 궤적을 바꾸는 대조다. Public-init private-only와 pooled objective도 서로 다르다. |
| Δtheta가 seed/환자 변화에 안정적인 구조여야 다음 단계 | 보편적인 필요조건이 아니다. 이 구조를 방법의 작동 설명으로 주장할 때 확인할 진단이다. 좌표 의존성·조건수 때문에 함수는 안정적인데 parameter 차이는 불안정할 수 있다. |
| Patient-specific residual | 현재는 환자별 평균 통계로 학습하는 **공유 생성 보정 head**다. 환자마다 별도 모델·보정값을 배포하거나 personalization을 하는 것이 아니다. |
| 작은 생성 비교에 우위 없으면 방법 설계 중단 | 수치·반복적 구조 붕괴면 현재 표현/구현의 확대를 보류할 수 있다. 작은 grid의 차이 부재는 일반적 효용 부재의 증명이 아니다. 평가가 불충분하면 “미확인”을 남긴다. |
| Public-only와 DP-SGD보다 모두 높은 utility·낮은 cost | 공개 baseline 대비 사적 추가 효용과 강한 DP baseline 대비 품질–비용 개선을 분리한다. 공개 baseline은 새 사적 자료에 대한 privacy 비용0이고 사적 처리 비용도 없다. 양쪽 모두에 엄격한 비용 우위를 필수로 요구하면 불필요하게 강하다. |

### Δtheta의 권장 해석
고정 모델에서 ΔW=W_pool−W_public이라 하더라도, feature covariance의 작은 고유값 방향으로 큰 ΔW가 발생하면 실제 예측 변화는 작을 수 있다. 동일 reference 입력에서의 변화 에너지는
`tr(ΔWᵀ A_ref ΔW)`
이며 단순 `||ΔW||²`와 다르다. Reference 분포를 먼저 고정하고 paired denoising predictions, timestep/조건별 효과를 보는 것이 parameter cosine만 보는 것보다 해석에 가깝다. 이것도 최종 생성 효용을 대신하지 않는다.

고정 finite bank의 정확한 ridge solve에는 optimizer seed 효과가 없다. 환자 재표집, noise bank, projection, DP noise, sampling seed가 각각 무엇을 바꾸는지 구분해야 한다. 안정적인 ΔW도 공통 편향일 수 있으며, 불안정한 ΔW만으로 유용한 예측 개선을 배제할 수도 없다.

## 3. 최소 수정한 gate 순서
**Gate 1 — 현재 함수족의 적용성과 추가 정보의 여지.**
고정 공개 baseline, private-only, 고정 비중의 pooled 비DP를 구분하고 실제 생성 wrapper의 출력 일치를 검증한다. 사적 추가 효용을 판별할 적절한 목적·평가가 있는지 함께 확인한다. MSE 미세 개선이나 소수 이미지의 인상으로 성공/실패를 확정하지 않는다. 현재 통합 계획의 pooled+생성 한 패키지가 이 역할이다.

**Gate 2 — 기여 명세와 필요한 구조 진단.**
무엇을 해결하고 어떤 연산으로 어떤 절충을 개선하려는지 한 장으로 고정한다. ΔW의 구조·안정성 검사는 필요할 때 병렬 진단으로 둔다. “안정적인 patient-specific residual이 확인되어야 연구를 계속한다”는 새 필수조건을 만들지 않는다. 공개 geometry/private residual은 가능한 표준 수단이며 자동으로 유일한 연구 주제가 되지 않는다.

**Gate 3 — 보호 아래의 공정한 효용 비교.**
Adjacency, epsilon/delta 상한, 보호 대상 환자, 고정 공개 정보, 표현/조건 입력, pooled/private-only 목적, 평가 자료를 명시한다. 동일 head의 public-aware DP-SGD와 공개 reference 방법을 직접 대조한다. 비교 주장이 표현력까지 포함하면 DP-LoRA 등도 별도 축으로 둔다. 공개 초기화만 했다는 이유로 원목적이 다른 baseline을 동일 비교라고 부르지 않는다. 정당한 공개 초기화/선택 자체는 사적 privacy budget을 소비하지 않는다.

**Gate 4 — 품질–비용을 함께 보고 주장 범위를 결정.**
공개 준비·사적 특징 추출·보호 fit·평가·sampling을 나누고, cold run/amortized run과 연구 반복 비용을 구분한다. 같은 품질에서 비용 감소, 같은 비용에서 효용 증가, 또는 명시한 Pareto 절충을 보인다. 효용이 낮은 millisecond solve를 전체 방법의 우월성으로 쓰지 않는다. 같은 head DP-SGD도 캐시를 쓰면 backbone backward0이라는 현재 사실을 유지한다.

Gate 2와 비용 profile은 Gate 1/3과 병렬로 할 수 있다. 위 순서는 “모든 진단을 통과해야 아이디어를 내도 된다”는 규칙이 아니다.

## 4. 권장 연구질문과 판단 문구
**주 연구질문**
> 공개 사전학습 생성모델과 공개 적응 정보를 활용할 때, 제한된 생성 보정 표현이 환자DP 아래 유용한 사적 추가 적응을 제공하면서 강한 보호 학습 기준선 대비 생성 효용–전체 비용의 절충을 개선할 수 있는가?

이를 두 검증 질문으로 나눈다.
1. 같은 운용 목적에서 공개 baseline에 사적 자료를 보호하여 추가할 실질적 효용이 있는가?
2. 그 효용을 얻는 비용/표현력/보호 강도의 절충이 강한 DP 기준선과 비교해 어디에서 개선되는가?

Public-only는 같은 private budget을 “쓴” 모델이 아니라 **0의 사적 privacy 비용을 가진 합법적인 기준선**이다. Epsilon8 비교에 들어갈 수 있지만 비용·접근권에서 그 차이를 감추지 않는다. 공개/사적이 실제로 겹치거나 공개 자료를 사적 자료에 의존해 선택했다면 이 해석과 증명 조건부터 다시 확인해야 한다.

**Continue:** 적절한 평가에서 목적상 유용한 추가 적응의 근거가 있고, 그것을 보호·비용 절충으로 발전시킬 구체 경로가 남음. **Revise:** 적용 경로·표현·목적·공개 접근권 중 무엇이 막히는지 특정됨. **Hold:** 현재 표본/평가로 실질 차이를 판별하지 못함. **Stop current expansion:** 현재 구성에서 반복적인 붕괴나 목적상 부적합이 확인되어 큰 계산을 더 투입할 이유가 없음. 어느 경우에도 작은 null 결과로 전체 환자DP 연구의 불가능성이나 평가논문의 자동 성립을 결론 내리지 않는다.

이 메모는 새 실험 gate나 수치 합격선을 추가하지 않는다. 기존 방법을 이 맥락에 설득력 있게 구성한 기여를 인정하면서, 경험적 참고점을 상한·필요조건·보장으로 과장하지 않도록 문구를 정리한 것이다.
