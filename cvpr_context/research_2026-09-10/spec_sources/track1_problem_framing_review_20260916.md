# 방향1 문제 정의에 대한 객관적 재검토

2026-09-16. 사용자 제공 의견을 현재 결과와 가까운 선행에 대조했다. 이번 작업은 해석 점검이며 새 학습·공격·수치 실험은 없다. 방향1 우선과 큰 단계2를 유지한다.

- 큰 환자 보호 문제와 연구 필요성은 존재한다. 구체적 문제 후보도 있으므로 '문제 자체가 전혀 없다'는 요약은 부정확하다. 반면 근접 선행이 해결하지 못한 좁은 기술 문제와 우리 방법의 우위는 미확정이다.
- 확인된 구체적 현상은 이번 joint-SSP에서 공개 선택된 스펙트럼 하한이 유용한 보정까지 억제했다는 것이다. 우리 초안의 확인된 손실 원인을 전체 기존 보호 방법의 미해결 한계로 확대하지 않는다.
- public-only32 full MSE .1740411864와 private-only80 비DP .1740069294의 작은 차이는 이 고정 보정층·코호트·개발40명·평균 denoising MSE에서의 관측이다. 두 방법의 통계적 동등성, 공개+사적 자료를 함께 쓸 때의 추가 효용 상한, 생성·임상 효용, 사적 의료자료 일반의 가치 부재는 입증하지 않았다.
- '공개 정보와 사적 잔차를 구분하지 않아서 기존 보호 설계가 잘못된 문제를 푼다'는 문장은 확인된 원인으로 채택하지 않는다. DOPE-SGD의 공개 gradient 중심 clipping과 공개 사전학습 후 DP 적응 선행이 있다. 공개 기준을 쓰는 것 자체는 새 기여가 아니다.
- 제안된 residual 보호는 검토할 해결 후보다. 잔차 통계가 0이 아니라는 사실과 사적 자료가 새로운 환자에서 유의미한 추가 효용을 준다는 사실은 다르다. 단순 재매개변수화와 실제 clipping·잡음·정규화의 변경도 구별한다.
- 더 중립적인 질문: '실제로 이용 가능한 공개자료를 충분히 활용했을 때, 사적 환자자료는 어떤 추가 효용을 제공하며 기존 환자DP 학습은 그 효용을 어디서 잃는가?' 이 질문에 residual 보호의 우위를 미리 가정하지 않는다. 기존 공개 참조 방법이 충분할 가능성도 남긴다.
- residual이 있으면 자동으로 방법 논문, 없으면 자동으로 평가 논문이 되는 것은 아니다. 전자는 기존 공개 참조 방법 대비 새 원리나 효용/비용 이득, 후자는 중요한 기존 판단을 바꾸는 재현 가능한 발견이 필요하다. 한 제한된 설정의 음성 결과만으로 평가 논문을 선언하지 않는다.
- 이전 E/U 사진 차이와 patient-FPR는 보호 평가 방향의 배경이다. 이것만으로 현재 공개/사적 적응 분해의 독창성이 입증되지는 않는다. 공개기준 잔차보호를 확정된 논문 주제나 자동 실행 순서로 승격하지 않는다.
