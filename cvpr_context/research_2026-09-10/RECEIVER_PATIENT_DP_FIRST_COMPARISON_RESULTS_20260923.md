# 첫 A2 환자-DP 비교 결과

2026-09-23 UTC 실행. 두 최종 PNG bank를 모두 고정한 뒤 평가했다. 사전에 정한 긍정적 개발 기준을 충족했다.

주 비교 DenseNet DP−공개전용: AUROC +0.115515, 환자 bootstrap 95% 구간 [+0.068791, +0.165723]; AP +0.022901, 구간 [+0.003706, +0.043453].

이 판단은 seed101 합성 초기화와 한 DP 잡음 실현, 이미 재사용한 개발 DenseNet/V에 대한 것이다. 독립 수신자·환자집단, 합성/잡음 반복, 강한 선행 우위를 확인한 결과는 아니다.

공개전용과 비DP는 기존 결과/예측을 그대로 재사용했다. 새 두 bank만 각각 128장·200회·seed101·microbatch16으로 만들었다. DenseNet은 개발 수신자이며 BioViL은 합성 목적에 사용한 source다.

제한-only−비DP는 기여 제한과 목표 복원 처리까지 포함한 차이다. DP−제한-only는 gradient 합계·class 분모의 잡음 및 그에 따른 안정화 처리를 함께 포함한다. 이를 gradient 잡음 하나의 효과로 해석하지 않는다.

이번 제한-only는 비DP보다 DenseNet AUROC가 낮았고 차이 구간도 음수였지만, 공개전용보다 높은 효용은 유지했다. DP 결과는 제한-only보다 점추정이 높으나 그 차이의 AUROC/AP 구간은 모두 0을 포함한다. 따라서 잡음이 성능을 개선하는 일반적 효과라고 주장하지 않는다.

DP와 비DP의 AUROC 점차이는 약 −0.01355이며 차이 구간은 0을 포함한다. 이는 동등성이나 비열등성 입증이 아니다. 현재 확실한 개발 결론은 DP−공개전용 차이의 AUROC와 AP 구간이 모두 양수라는 것이다.

V 2,026명/5,047장(양성 223장), 기존 환자 bootstrap 2,000회 및 point-only ridge 0.1을 재사용했다. sklearn 독립 대조 최대 오차 1.11e-16. 구간은 현재 bank와 잡음에 조건부이며 독립 합성/잡음 변동을 포함하지 않는다.

**보호 범위와 실제 실행**

- P는 공개, Q는 환자 한 명의 전체 방문 추가/제거 인접성이다.
- 두 encoder × 네 조건의 class별 환자 평균 gradient 및 class 존재 count를 하나의 546좌표 query로 묶었다. 전체 환자 norm≤1, 합계 감도1.
- P-only q95 제한 기준: 음성2.7412545531339387, 양성2.689519212597726. 전체 ε8/δ1e−5, analytic Gaussian σ0.6002290722589745.
- 보호된 class 분모를 사용하고 noisy 합계를 복원한 질량에 맞게 투영한다. 제한-only는 같은 절차에서 잡음만 제외했다.
- Q 보호 query와 잡음 생성은 1회다. 동일 보호 target의 200회 합성은 후처리이며, 결과에 따른 재추출·계수/중간 checkpoint 선택은 없다.
- 초기 공개 template·renderer·optimizer·RNG 상태는 기존 seed101과 일치했다. CLIP/DP8 각각 새로 시작했으며 다른 학습 checkpoint를 이어 쓰지 않았다.
- 동결 source 가중치/buffer 및 target 불변, 실제 parameter 갱신, 마지막 PNG/label/hash 검증을 통과했다. 이전 코드·입력·결과 해시도 보존됐다.
- protected_png에는 DP에서 유래한 PNG128장·합성 label·공개 학습 규칙과 파일 hash만 있다. 내부 checkpoint, Q 원통계/분모/cache hash, 실현 잡음/비밀 난수 상태, 원 평가 예측은 포함하지 않는다.
- 이 보호 범위는 고정한 구성에서 Q query와 그 후처리다. 과거 비DP Q/V 기반 방법 선택, 제한-only 대조, 내부 진단 및 이번 평가 공개를 소급하여 DP라고 주장하지 않는다. 실수 Gaussian 메커니즘의 수치 구현을 검산했으며 별도의 유한 정밀도 보안 증명을 완료한 것은 아니다.
- 외부 게시/배포는 하지 않았다. Expert·Reserved·확인용 수신자·추가 release/seed/학습 연장은 실행하지 않았다.
