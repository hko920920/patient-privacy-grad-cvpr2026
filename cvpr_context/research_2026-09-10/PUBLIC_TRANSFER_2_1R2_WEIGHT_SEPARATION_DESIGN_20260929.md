# 2-1R2 — 공개 모델 대응 가중치의 영향과 다음 교차 대조

실제 전체 소요 **19.43분** (실행 전 예상30~45분). 완료 시각 2026-09-29T15:25:46.632645+09:00.

작성일: 2026-09-29. **설계·공개자료 검산 완료. 새로운 downstream 성능 결과는 없음.**

현재 전달 방식 HR과 강화 KD의 차이 중, 다음에 우선 확인할 것은 **질환 분류용 class 균형 가중치를 공개 모델 대응 회귀에도 그대로 적용하는 효과**다. 공개자료의 환자 평균·clipping 순서·중심화도 분석했지만, 이번 수치에서 이들을 주된 개선 원인으로 먼저 내세울 근거는 약했다.

**선택한 가설:** 공개 양성이 6명뿐인 현재 조건에서는, class 균형이 필요한 질환 학습과 모델 사이의 대응 학습에 서로 다른 가중치를 쓰는 것이 전이에 유리할 수 있다. 이것이 현재 HR의 강화 KD 대비 이득 일부를 설명한다면, HR에 class 균형 대응 가중치를 주면 나빠지고, 강화 KD에 환자 균등 대응 가중치를 주면 좋아져야 한다.

다음 **2-2R2**는 이 양방향 예측을 한 묶음으로 확인한다. **기존 첫 공개128·기존 DP1/DP2에서 새 라벨4개와 readout8개**, 예상 **20~30분**이다. 새 영상 제작·DP release는 없다. 이번 작업에서는 라벨과 V 평가를 실행하지 않았다.

## 1. 기존 결과와 이번 작업의 역할

- 2-3R1에서 HR−ACKD의 DenseNet 두-release 평균 AUROC 차이는 +0.033434, 조건부95%CI [+0.016395,+0.051698]이었다. CKD 대비도 양수였지만 AKD 대비 CI는0을 포함했다.
- 첫 공개128에서 HR−DINO의 DP2 차이가 음수였던 기록도 그대로 유지한다.
- 따라서 이번은 원인을 특정하기 위한 **2-1의 두 번째 보완**이다. 원래2-3의 보류나2-3R1의 혼합 판정을 통과로 바꾸지 않는다. 독립 평가인3번도 미착수다.

기존 근거: [2-2R1 결과](PUBLIC_TRANSFER_2_2R1_KD_CORRECTIONS_RESULTS_20260928.md), [2-3R1 결과](PUBLIC_TRANSFER_2_3R1_SELECTION_REPEAT_RESULTS_20260928.md).

## 2. 실제 연산 비교

공개 P는672환자·813영상이다. 환자/class 묶음은675개(음성669, 양성6), 두 class가 함께 있는 환자는3명이다. 환자/class 묶음 중113개가 반복 영상을 가지며 최대3영상이다.

D와 R은 각각 공개 DINO64차원, ResNet18 128차원 특징이다. 질환용 영상 가중치 Ω는 기존대로 class마다0.5, 그 안에서 환자 균등·환자/class 내 방문 균등이다. 이 Ω로 만든 H_D=DᵀΩD+0.1I와 H_R=RᵀΩR+0.1I는 유지한다.

| 항목 | 기존 HR | 기존 강화 ACKD | 이번에 구분할 부분 |
|---|---|---|---|
| 공개 모델 대응의 표본 | 환자/class 평균675행 | 영상813행 | 기존 차이, 다음 대조에서는 각 recipe 내 고정 |
| 대응 회귀 가중치 | 각 환자 총합1/672, 두 class가 있으면 나눔(U) | 각 class 총합0.5(B) | **다음 대조의 유일한 설정 변경** |
| source 입력 | 환자/class 평균 후 cap0/cap1 적용 | 원래 영상 특징 | 고정 |
| 중심화 | 가중 평균을 뺀 affine 회귀 | 원점을 지나는 회귀 | 고정 |
| 공개 source 기준 | 공개 clipped class 평균 | 같은 공개 평균에서 만든 source head | 고정 |
| RN 공개 기준 | 위 공개 평균을 지도에 통과시킨 값 | 공개 실제 라벨의 RN ridge head | 각 recipe의 기존 규칙 유지 |
| 질환 readout/라벨 solver | 기존 class-balanced H_D/H_R, 공개128·RN-only solver | 동일 | **가중치 변경 대상 아님** |

HR의 두 지도는 각각의 cap을 **모든675행**에 적용해서 만든다. 양성지도에 양성6행만 쓰는 구현이 아니다.

새 HR-B에서는 대응 가중치 변경에 따라 fitted 중심·절편과 그로부터 유도되는 RN 공개 기준도 바뀐다. 따라서 이것을 기울기만 바꾼 대조라고 하지 않는다. 공개 source midpoint 자체와 모든 보호 head는 고정한다. ACKD-U의 실제 공개 RN 기준 head는 수치까지 그대로 둔다.

## 3. 공개자료에서 확인된 차이

아래는 고정된 기존 보호 DINO head를 새 공개 지도에 통과시켰을 때 **공개 P에서 계산한 RN 목표 예측의 상대 RMS 변화**다. AUROC 변화율이나 개선율이 아니다. HR의 기존 cap별 ridge 수치를 모두 고정했다.

| HR에서 바꾼 것 | DP1 상대 변화 | DP2 상대 변화 |
|---|---:|---:|
| clipping 제거 | 3.37% | 3.89% |
| 영상별 clip 후 환자 평균으로 순서 변경 | 0.85% | 1.63% |
| 중심화 제거 | 2.13% | 2.76% |
| 영상 수준에서 대응 회귀(환자 총가중치는 유지) | 5.64% | 6.75% |
| **대응 회귀에 class 균형 가중치 적용** | **38.65%** | **53.77%** |

가중치 차이가 이 국소 비교에서 가장 큰 목표 변화를 만들었다. 작은 목표 변화도 AUROC에 영향을 줄 수 있으므로, 다른 요소의 효과가 없다는 결론은 아니다.

### 가중치가 집중되는 정도

| 공개 대응 가중치 | 양성 class 행의 총질량 | 환자 총가중치로 계산한 Kish ESS | 최대 한 환자 질량 |
|---|---:|---:|---:|
| 환자 균등 U | 0.006696(약0.67%) | 672.00 | 0.001488 |
| class 균형 B | 0.5(50%) | 23.58 | 0.084081 |

ESS=1/Σ_i weight_i²는 **가중치 집중의 기술통계**다. 실제 표본 수가24명이라는 뜻도, 통계적 검정력이나 모델 위험을 보장하는 수치도 아니다.

같은 공개 환자5-fold에서 HR 입력을 RN 환자 평균으로 옮기는 회귀오차를 확인했다.

| 지도 | cap0 R² | cap1 R² |
|---|---:|---:|
| 기존 HR-U | 0.179868 | 0.182433 |
| 같은 HR에 B 적용 | 0.135550 | 0.140167 |
| 영상 수준 지도, 환자 총가중치 유지 | 0.193681 | 0.195483 |

B 적용 시 공개 환자 가중 MSE는 약5.4%/5.2% 증가했다. 양성6행의 MSE도0.5175/0.5188에서0.5463/0.5488로 커졌다. 다만 projection과 λ는 전체 P에서 고정된 값이고 양성환자는6명뿐이다. 독립 임상 성능 추정이나 Q→V 일반화 보장으로 사용하지 않는다.

또 공개 양성환자6명을 각각 한 명씩 **대응 지도 학습에서만** 제외한 진단에서, 기존 두 보호 head에 대한 공개 목표 예측 RMS 변화의 평균은 다음과 같았다.

| 가중치 | DP1 | DP2 |
|---|---:|---:|
| U | 0.001587 | 0.001468 |
| B | 0.014990 | 0.016731 |
| B/U 비율 | 9.45배 | 11.39배 |

분류용 H_D/H_R, 공개 midpoint, 보호 head, λ는 고정했다. 이것은 이 공개지도에 대한 민감도이며 DP noise 분산이나 downstream 안정성 검정이 아니다.

### 환자 평균과 clipping에 대한 판단

평균과 clipping은 일반적으로 교환되지 않는다. 실제로 cap0/cap1에서675묶음 중13/44묶음에 순서 차이가 있었다. 가중 상대 입력 차이는0.42%/2.40%였다.

같은 환자 총가중치를 방문으로 나누면 영상 공분산은 환자/class 평균 사이 공분산과 내부 공분산의 합이다. 공개 P의 내부 공분산 trace 비중은 환자 균등일 때4.39%, class 균형일 때2.41%였다. 이 항등식은7.51e-17 이하 오차로 확인했다.

따라서 **환자 평균·clip 정렬이 현재 개선의 주원인이라고 먼저 정하지 않는다.** 공개 CV에서는 영상 수준 지도도 더 낮은 오차를 냈다. 보호 단위를 맞추는 필요성과, downstream 효용이 더 높다는 주장은 구분한다.

## 4. 가설의 수학적 근거와 선행 경계

고정 λ에서 Z=[clipped patient features,1], J=diag(1,…,1,0)라 두면 가중 affine ridge의 계수는

Theta_W = (ZᵀWZ + λJ)^(-1) ZᵀWY

이고 두 가중치 사이에는 다음 항등식이 성립한다.

Theta_B − Theta_U
= (ZᵀBZ + λJ)^(-1) Zᵀ(B−U)(Y−Z Theta_U).

즉 가중치 변경의 영향은 대응 회귀의 잔차와 역공분산을 통해 나타난다. 표본 질량이 몇 명에 집중되는 것만으로 성능 저하를 단정할 수는 없다. 완전한 affine 관계를 충분한 rank에서 λ=0으로 정확히 맞추는 경우라면 양의 가중치를 바꿔도 해가 같을 수 있다. 이 항등식은 표준 ridge 대수이며 새 정리로 주장하지 않는다. 현재 두 cap에서 최대1.98e-13 오차로 검산했다.

| 직접 선행 | 이미 제공하는 것 | 현재 연구에서 별도로 확인할 것 |
|---|---|---|
| [Conditional Mean Embeddings as Regressors, ICML2012](https://icml.cc/Conferences/2012/papers/898.pdf), §3 식9–11 | 조건부 평균 전달과 vector-valued ridge의 대응 | 공개 환자자료의 구체적 가중치·보호 head·128개 라벨 전달에서 실제 효용 |

이번 확인은 공식 학회·저널 본문과 공식 서지/초록을 이용했다. CCKD PDF는 웹 도구에서 가져오지 못했으므로 세부 수식까지 재검토했다고 기록하지 않는다. 앞선 DP-KME/Label Solve와의 동치성 검토도 그대로 유효하다.

**기여 후보의 범위:** 이미 한 번 보호한 source head를, 공개 양성환자가 적은 상황에서 다른 모델이 이용할 자료로 전달하는 구체적 설계 문제다. 가중치 교차에서 예측이 확인되면 “왜 현재 처리가 도움 되는가”에 대한 설명 근거가 생긴다. 가중치 선택만으로 강한 표준 대안이 같은 효용을 내면 그 대안을 받아들인다. 어느 경우든 재가중치 또는 CME를 새 발명으로 이름 붙이지 않는다.

## 5. 다음 2-2R2: 대응 가중치 2×2 교차

새 가중치 계수나 ε를 찾지 않는다. 이미 존재하는 U와 B만 서로 허용한다.

| 목표 recipe | U: 환자 균등 대응 | B: class 균형 대응 |
|---|---|---|
| HR | 기존 DP1/DP2 재사용 | **새 라벨2개** |
| ACKD | **새 라벨2개** | 기존 DP1/DP2 재사용 |

공개128은 최초 선정 집합을 그대로 쓴다. HR·ACKD·DINO-only 기존12readout을 재사용하고, 새4라벨에 DenseNet 주평가·RN 참고평가를 적용해8readout만 추가한다. RN은 구성에 사용한 모델이며 독립 전이 receiver로 세지 않는다.

ACKD의 새 U 연산을 정확히 쓰면, C_RD(U)=RᵀUD, G_D(U)=DᵀUD에 대해

A_U = H_R(Ω)^(-1) C_RD(U) [G_D(U)+λ_C I]^(-1) H_D(Ω),
w_ACKD,U = w_RP + A_U (w_D−w_DP).

여기서 U는 각 환자/class 가중치를 해당 방문 수로 나눈 영상 가중치다. λ_C=3.0478093248587158e-5, HR cap별 λ=3.0107448502066288e-5 / 2.836862823850081e-5를 **수치까지 고정**한다. U/B에 따라 λ까지 다시 선정하지 않는다.

공개 source midpoint, 보호 DINO head, 질환용 Ω, readout ridge0.1, 공개128, RN-only label solve, bounds[-1,1], zero-anchor eta/RMS/BVLS 규칙은 그대로다. 네 라벨과 실행 해시를 모두 봉인한 후 V를 읽는다.

이것은 고정 λ 아래 가중치의 효과를 보는 요소 대조다. 가중치별로 최적화한 모든 ridge 대안의 우위 비교는 아니다. B의 집중도가 커지면 더 큰 regularization이 유리할 가능성도 있으므로, 한 번의 교차 결과를 모든 class-balanced 방식의 한계로 확대하지 않는다.

### 판정할 대비와 멈춤 규칙

주 대비는 **HR-U−HR-B**와 **ACKD-U−ACKD-B**다. 같은2,000회 환자-cluster bootstrap 안에서 각 release의 영상 AUROC/AP 차이를 계산하고, 두 차이를 평균한다. 예측을 평균한 앙상블이나 독립 환자 표본4개로 처리하지 않는다.

두 주 대비에 모두 기존 개발 hurdle(두 release AUROC 점차이 양수, 평균차이≥0.01, 평균차이95%하한>0, 평균AP≥0, 개별AP의 명확한 악화 없음)을 요구한다. 이는 강한 가설 지지에 필요한 engineering 기준이며 clinical threshold가 아니다.

| 결과 | 허용되는 결론과 후속 제한 |
