두 모델에서 엇갈린 PFAMI 결과 — 공통 순위와 참여 방향 변화

2026-09-14. 학습 참여를 교환한 두 모델에서도 환자 점수 순위가 거의 유지됐다. 핵심 U relative의 순위 상관은 0.99456이며, A/B 환자 400쌍 중 389쌍은 순서가 같았다. 반대 membership 라벨을 적용하면서 AUC가 0.3550/0.6575로 갈리는 구조를 저장 점수에서 확인했다. 다만 일관된 참여 방향 변화나 유용한 새 방법을 확인한 결과는 아니다.

사용자 “다음” 지시에 따라 앞선 PFAMI 고정 비교의 저장 결과만 재분석했다. 큰 순서의 1번 안에서 기존 점수를 이해하는 작업이다. 새 GPU·학습·환자 이미지 평가·threshold fitting은 0이다. 이전 PFAMI 주비교의 실패를 다른 지표로 통과시키지 않았다.

무엇을 구분했나

동일 환자의 모델 1/2 점수를 s1, s2라 놓았다.

  • 공통 성분 c=(s1+s2)/2: 두 모델 사이에서 대칭인 성분.
  • 변화 성분 d=(s1−s2)/2: 두 모델 사이에서 비대칭인 성분.
  • 참여 방향 변화 Δ=s_member−s_nonmember: A 환자는 s1−s2, B 환자는 s2−s1.

c가 순수한 환자 편향이라는 뜻도, d가 순수한 membership 효과라는 뜻도 아니다. 두 모델은 여러 환자를 함께 교환했으므로 다른 환자들의 교환·모델 적응 효과도 차이에 들어갈 수 있다.

이 분해는 두 모델과 정답을 가진 연구자의 진단이다. 실제 감사자에게 다른 target의 응답이나 학습 정답을 추가 입력으로 주지 않는다. Δ로 새 공격 AUC를 계산하지 않았다.

AUC가 반대로 나오는 구조

두 모델에 동일한 공통 점수 c를 사용하면 A를 member로 보는 AUC는 0.3450, B를 member로 보는 AUC는 0.6550이다. 반대 라벨을 적용하므로 두 AUC 합은 항상 1이다. 이는 tie를 포함하는 항등식이며, 자체로 bias를 증명하는 실험 결과는 아니다.

실제 점수에서는 AUC가 0.3550/0.6575가 되어 공통 점수보다 각각 +0.0100/+0.0025 바뀌었다. 두 모델 AUC 평균에서 0.5를 뺀 값은 +0.00625 [−0.00753, +0.02250]이다. 이것은 연구자의 두 모델 진단값이며 새로운 배포용 공격의 성능이 아니다.

A/B 환자 쌍마다 공통 차이를 a=c_A−c_B, 변화 차이를 b=d_A−d_B로 놓으면 평균 AUC 초과분에 대한 기여는 다음과 같다.

H(z) = 1 if z>0, 0.5 if z=0, 0 if z<0
pair contribution = 0.5 * [H(a+b) - H(a-b)]

|b|<|a|이면 이 쌍의 순서는 바뀌지 않는다. 실제 400쌍의 기여는 양수 8개·음수 3개·0인 쌍 389개였고, 합 2.5를 400으로 나누면 0.00625가 된다. 점수 변화가 있는 것과 그 변화가 환자 간 판별 순위를 개선하는 것은 서로 다른 조건임을 이번 값으로 구분했다.

높은 상관·높은 공통 분산 비중만으로 변화 부재를 판정하지 않는다. 또한 위 평균 AUC 초과분을 AUC(d)−0.5와 동일시하지 않는다.

E의 음의 원본 손실에서는 평균 Δ가 +0.0001829 [0.0000148, 0.0003552]인 양의 개발 관측이 있다. 이를 숨기거나 “아무 변화도 없다”고 정리하지 않는다. 하지만 해당 점수의 E AUC는 0.4650/0.5425였으며, U의 주결론·정규화 우위·실용적인 환자 판별을 입증하지 않는다. 여러 조건 중의 보조 관측이고 사후 선택을 보정한 확증 결과가 아니다.

공개 base 차감이 실제로 바꾼 것

같은 환자의 base 점수 b0를 두 target 점수에서 빼면 c는 c−b0로 바뀌지만 d와 Δ는 대수적으로 그대로다. 원시 영상·환자 집계에서 이를 확인했으며 환자별 Δ의 최대 오차는 2.78×10⁻¹⁷, 부호 변경은 0건이었다.

U에서 c의 표준편차는 0.0401297에서 0.0264798로 줄었고 d의 표준편차는 0.00150114로 그대로였다. 환자마다 다른 base 값을 빼므로 각 모델의 환자 간 순위와 AUC는 바뀔 수 있다. 실제 base-relative AUC는 0.4375/0.5775였다. 모델 간 참여 방향 변화가 새로 생겼거나 순수한 membership 신호만 남았다는 뜻은 아니다.

설계에 반영할 판단

이번에 좁힌 문제는 환자 간 점수 차이, 모델 간 점수 변화, 판별 순위의 개선을 분리해서 입증해야 한다는 점이다. 단순히 반응이 전달되거나 평균 값이 움직인다고 유용한 환자 판별이 따라오지는 않는다.

다음 방법의 근거가 되려면, 실제 감사자에게 허용된 단일 target·공개 base·보조자료로 무엇을 제거하거나 얻을 수 있는지 설명해야 한다. 이번 c나 정답 정렬 Δ를 그대로 공격 입력으로 쓰는 것은 허용된 설정이 아니다. 공통 성분을 보정한다는 방향만으로 신규성을 주장할 수도 없으며 기존 점수 보정·특징 결합과의 대조가 남는다. 기존 방법의 조건과 현재 R의 미확인 전제를 따른다.

이번 결과는 현재 R을 더 튜닝하거나 target 학습을 늘려야 할 근거를 추가하지 않았다. PFAMI의 저장 점수에서 확인한 구조를 R의 확정 실패 원인으로 옮기지도 않는다. 새로운 알고리즘을 찾았다고 보고하지 않고, 이 고정된 점수 진단은 여기서 닫는다.

검산·시간·기록

  • A/B 각 20명의 라벨 교환과 실제 checkpoint의 학습 노출을 확인했다. E는 member target에만 4–5회 노출되고 U는 양쪽 0회였다.
  • 두 target의 영상×10시점×2view noise seed/hash 3,200쌍이 같았다. 공통 학습 512장과 각 모델 전용 400장, 같은 초기화 seed를 확인했다. 단일 환자만 차이 나는 모델 쌍이 아니다.
  • 원 분석 소스를 import하지 않은 독립 검산기가 8조건·환자 행 320개·값 1,600개, 순위 비교 6,240건과 A/B 기여 3,200건을 대조했다. 이 비교 건수를 독립 표본 수로 쓰지 않았다.
  • sklearn AUC 32개(기존 AUC 16개 포함), 상관 16개, 표본 빈도 가중치 방식의 bootstrap 구간 16개가 일치했다. 최대 수치 차이는 3.33×10⁻¹⁶였다.
  • A/B 층화 bootstrap 2,000회, seed 260914, 원 PFAMI와 동일한 환자 순서·추출 hash를 사용했다. 고정 모델과 이미 관측한 개발 표본에 조건부인 사후 분석이며, 모델 학습 변동이나 이전 선택을 보정한 구간이 아니다.
  • 데이터 검산 CPU 0.498초, 분석 프로세스 약1.13초, 독립 통계 검산 CPU 0.319초(프로세스 약2.75초)였다. 새 GPU 연산은 0이다.
  • 전체 작업은 예상10–15분으로 안내했으며, 분석기·검산기 연결과 기록에 예상보다 시간이 들었다. 실제 시작은22:16 KST, 종료 시각·전체 소요는 최종 요약에 남긴다.
