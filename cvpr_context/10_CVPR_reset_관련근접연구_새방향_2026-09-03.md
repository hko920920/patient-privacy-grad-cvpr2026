- 기록일: 2026-09-03
- 기준시점: 2026-09-03 공개 1차 문헌과 현재 로컬 실행 증거
- 현재 authority: 이 문서와 11--13 결과 문서가 01--09의 방법 추천을 supersede한다.
- 결론 지위: **연구문제 1순위 선정; 새 방법과 논문 성공은 아직 미검증**

## 1. 결론부터

현재 CVPR 독립 논문 1순위는 **Patient-Set Private Diffusion (PSPD)**다.

> 한 환자를 여러 장의 독립 영상으로 쪼개 보호·생성하지 않고, 반복 X-ray 묶음 전체를 하나의
> privacy unit이자 하나의 생성 객체로 삼아, 묶음 내부의 환자 고유 시각 일관성과 기록별 소견
> 변화를 함께 재현하는 patient-level DP diffusion을 만든다.

이 방향은 “환자 gradient 평균을 조금 더 잘하는 법”이 아니다. 입력 단위, DP 인접성 단위,
모델 상호작용 단위, 최종 합성·평가 단위를 모두 **patient set**으로 맞추는 문제 재정의다.

## 2. 왜 이 방향이 지금 1순위인가

1. **PFDM이 의도적으로 남긴 단위를 정확히 잇는다.** PFDM은 hospital/client 안에 여러 개인이
   있는 cross-silo 상황에서 각 data point를 보호하는 sample-level LDP를 택한다. 이를 잘못된
   보장이라고 비판할 수는 없다. 다만 한 환자의 반복 영상 전체를 add/remove하는 patient
   adjacency와 joint patient-set generation은 다루지 않는다.
2. **기존 자산이 거의 그대로 들어간다.** NIH PA-only patient manifest, K2/K5/K10,
   patient-disjoint split, SD 2.1 VAE/LoRA, native patient-DP trainer, accountant, patient MIA,
   extraction, PP-Mark·audit 증거 경로가 이미 있다.
3. **CVPR에서 보일 수 있는 시각적 방법 기여가 생긴다.** 단순 DP 표가 아니라 독립 생성과 joint
   set generation의 이미지 묶음을 나란히 보여주고, same-patient consistency와 record-level
   pathology diversity를 동시에 평가할 수 있다.
4. **선행의 빈 교집합이 비교적 명확하다.** patient-level DP 학습, DP image diffusion,
   multi-image diffusion, longitudinal CXR generation은 각각 있지만, 이번 조사 범위에서
   `patient add/remove DP + joint synthetic image set`을 함께 다룬 직접 선행은 찾지 못했다.
   이것은 “최초” 확정이 아니라 2026-09-03 현재의 검색 결론이다.
5. **실패한 분기와 mechanism class가 다르다.** VAE coverage, timestep allocation, unit-local
   clipping placement, covariance template, antithetic corruption noise를 더 조정하는 방향이 아니다.

## 3. PFDM과의 정확한 관계

[PFDM (CVPR 2026)](https://openaccess.thecvf.com/content/CVPR2026/html/Patel_Personalized_Federated_Training_of_Diffusion_Models_with_Privacy_Guarantees_CVPR_2026_paper.html)은
client별 local denoiser와 server global denoiser를 결합하고, forward-noised 개별 영상을 서버에
보내 sample-level LDP를 보장한다. 실험은 CIFAR-10, colorized MNIST, CelebA다.

PSPD는 PFDM의 알고리즘을 의료 데이터에 단순 적용하지 않는다.

| 축 | PFDM | PSPD 제안 |
|---|---|---|
| 기본 단위 | client 안의 개별 sample | 한 환자의 가변 길이 image set |
| privacy | sample-level LDP | central patient add/remove DP |
| 생성 출력 | 개별 image | 서로 연관된 synthetic patient bundle |
| 핵심 구조 | global/local personalized denoisers | shared image denoiser + exchangeable cross-record adapter |
| 핵심 용도 | client collaboration·minority utility | 환자 단위 합성 데이터 공유·longitudinal/multi-record task |

따라서 논문의 표현은 “PFDM의 보장이 틀렸다”가 아니라 다음이어야 한다.

> PFDM은 sample-level privacy를 명시적으로 해결했다. 우리는 의료영상에서 자연스러운 보호·생성
> 단위가 반복 기록 전체인 경우를 별도 문제로 정의한다.

federation은 1차 논문에 넣지 않는다. patient set과 federation을 동시에 해결하면 비교축과
실패 원인이 너무 많아진다. multi-hospital extension은 후속 연구다.

### 이번 reset에서 추가로 닫힌 선행 경계

- [Blue Noise for Diffusion Models](https://arxiv.org/abs/2402.04930)은 training noise의 spatial
  correlation과 mini-batch 안 noise-image rectified mapping을 이미 다룬다.
- [Antithetic Noise in Diffusion Models](https://arxiv.org/abs/2506.06185)은 generation-time initial
  noise `z,-z`를 이미 다룬다.
- 일반 antithetic SGD도 mini-batch gradient의 음의 상관을 다룬다.
- 따라서 `z,-z` 자체, correlated noise 자체, timestep sharing 자체는 신규 claim이 아니다.

## 5. 제안 방법의 최소 형태

환자 `u`의 기록 집합을 `X_u={x_u1,...,x_um}`라 하고, 한 step에서 최대 `Q=4` records를
outcome-blind로 뽑는다. 각 영상을 고정 VAE로 latent로 만든 뒤, record별 timestep과 Gaussian
corruption noise는 **표준 IID**를 유지한다. 2026-09-03 UCAN 결과가 실패했으므로 antithetic
noise는 사용하지 않는다.

### 5.1 SetAdapter

1. 같은 SD 2.1 UNet을 모든 records에 공유한다.
2. UNet의 중간 해상도에서 record별 spatial feature를 pooling해 한 개 이상의 record token을
   만든다.
3. 작은 multi-head self-attention을 `Q` record 축에 적용한다.
4. 얻은 set context를 zero-initialized residual/FiLM adapter로 각 record feature에 돌려준다.
5. valid-record mask와 무작위 slot permutation으로 variable-size set과 permutation equivariance를
   처리한다. singleton에서는 adapter가 identity에 가깝게 동작한다.

처음부터 거대한 새 UNet을 학습하지 않는다. pretrained UNet은 고정하고 기존 rank-8 LoRA와
작은 SetAdapter만 학습한다. 첫 ablation은 `no adapter / mid-block one adapter / three-scale
adapter`다.

### 5.2 Patient-DP update

- 한 patient set의 valid-record denoising loss들을 평균한다.
- 그 전체 trainable-parameter gradient가 한 patient vector다.
- 이 vector를 `C_patient`로 한 번 clip한다.
- Poisson-sampled patient batch 합에 `N(0,sigma^2 C_patient^2 I)`를 더하고 고정 expected-batch
  denominator로 나눈다.

SetAdapter가 private records 사이를 보더라도 한 환자 안에서만 작동하고 최종 patient vector를
clip하므로 기존 M2 native patient-DP sensitivity/accountant를 그대로 사용할 수 있다. 정확한
보장은 구현 trace와 accountant 재검증 뒤에만 주장한다.

### 5.3 생성

generation 때 `Q` independent Gaussian latents를 같은 synthetic-set call에 넣고 SetAdapter로
공동 denoise한다. 출력은 특정 실제 환자의 follow-up 예측이 아니라, 새로 표본화된 가상 환자의
서로 연관된 X-ray 묶음이다. 시간 정보를 쓰는 버전은 NIH의 follow-up rank 한계 때문에 main이
아니라 ordered-set ablation으로 둔다.

## 6. 논문 기여를 세 줄로 제한

1. **Problem:** private diffusion의 image unit을 실제 반복 의료기록의 patient-set unit으로 바꾼다.
2. **Method:** variable-size patient set을 공동 denoise하는 parameter-efficient SetAdapter와 native
   patient-DP update를 결합한다.
3. **Evaluation:** single-image quality뿐 아니라 within-set identity/anatomy consistency,
   record-level pathology variation, real-patient linkage risk를 같은 patient-disjoint protocol에서
   평가한다.

AAAI compressed audit의 route-label·evidence sealing은 구현 신뢰성용 supplementary infrastructure다.
CVPR main novelty로 재사용하지 않는다.

## 7. 데이터와 적용·활용

### Core

- NIH ChestXray14 PA-only K10
- 이유: 42,423 exact PNG, 14,755 patients, patient-disjoint manifest와 DP trainer가 이미 검증됨
- 한계: 실제 촬영 날짜·정밀 report가 없어 “질병 진행 예측” claim은 금지

### Extension

- ISIC: 한 환자의 여러 피부병변/영상에 대한 unordered patient set 일반화
- CelebA identity groups: 의료 외부의 multi-record entity 일반화. privacy 의미를 환자로 부르지 않는다.
- MIMIC-CXR: 접근권한과 시간·report metadata가 확보될 때만 longitudinal external validation

### 실제 활용

- real scans를 공개하지 않고 prior/current 비교 모델이나 multi-record report model을 학습할
  synthetic patient bundles 제공
- 환자 수가 적은 희귀 소견에서 bundle 단위 data augmentation
- 의료 외에는 user photo album, camera burst, 동일 객체 multi-view set으로 확장 가능

된다. 두 축과 real-patient linkage를 반드시 동시에 표시한다.

## 9. Baselines

1. untouched SD 2.1 base
2. non-DP independent-record LoRA
3. non-DP joint-set LoRA+SetAdapter
4. image-DP LoRA at image budget
5. group-matched image-DP at target patient budget
6. native patient-DP independent-record M2: 현재 executable baseline
7. native patient-DP joint-set M2+SetAdapter: proposed
8. 가능하면 non-private M2M-style autoregressive conditioning

UCAN, retired PCM, timestep stratification은 main baseline으로 승격하지 않고 negative evidence로
supplement에만 둔다.

## 10. 지금까지의 새 실증

### UCAN 반증

16 새 NIH patients, 5 banks, 320 full gradients에서 complete antithetic/shared-t 방식은 shared-t
IID보다 clipped actual-B2 error가 `1.0742`배였고 CI `[0.9657,1.2069]`, bank leave-out win 1/5,
patient leave-out win 0/16으로 실패했다. ordinary IID 대비도 `1.0081`이었다. 구현을 중단한다.

### Patient-set data premise

이전 실험과 겹치지 않는 80 patients·320 images의 public DINOv2 probe에서:

- same-patient similarity AUC `0.8779`
- retrieval R@1 `0.6563`, 무작위 chance의 `69.8`배
- 다른 exact finding label인데 같은 환자인 pair cosine `0.9861`
- 다른 환자이면서 exact label이 같은 pair cosine `0.9748`
- 71.25% patients가 네 records 안에서 둘 이상의 exact finding-label set 보유
- label Jaccard distance 평균 `0.5008`

이는 안정된 patient-related visual signal과 record variation이 공존함을 강하게 시사한다. 그러나
사전 절대 cosine-gap `0.05` 조건에는 실제 `0.0111`로 미달했으므로 formal v1 status는 FAIL이다.
결과 뒤 threshold를 낮춰 PASS로 바꾸지 않는다. DINO cosine scale가 포화된 점을 반영한
scale-free fresh-cohort confirmation을 다음 public gate로 둔다.

후속 v2는 앞선 240명을 모두 제외한 exact 2--3 record patients 160명·400 images에서
scale-free 다섯 gate를 결과 전에 고정했고 모두 통과했다. pooled AUC `0.8806`, 네 cell AUC
`0.8633--0.9085`, patient ordering win `97.5%`, global R@1 `0.48`(`119.7x` chance), record-label
variation `75.625%`였다. 따라서 v1 FAIL을 지우지 않으면서도 데이터 전제는 독립 확인됐다.

이어 463,872-parameter mid-block SetAdapter의 실제 SD 2.1 Q=2 smoke도 통과했다. zero-init,
record-swap equivariance와 singleton identity의 max error는 모두 `0.0`, LoRA와 SetAdapter의 full
backward는 finite했고 peak allocated CUDA는 `1.819 GiB`였다. optimizer·DP noise·checkpoint는
없었다. 이는 실행 가능성 결과이며 generation utility 결과는 아니다. 상세는 13번 문서다.

## 12. 다음 실행 순서와 중단 기준

1. **완료--fresh public premise confirmation:** 비중복 2--3 record cohort의 다섯 scale-free
   gates가 모두 PASS했다.
2. **완료--architecture smoke:** public Q=2 mid-block SetAdapter의 invariance, cross-record
   connectivity, full backward와 memory gates가 모두 PASS했다.
3. **public non-DP falsification:** independent LoRA와 parameter/UNet-call matched SetAdapter를
   public patient-disjoint train/validation에서 비교한다.
4. **generation gate:** joint set consistency가 real-set distribution에 가까워지되 per-image quality와
   pathology diversity가 악화되지 않을 때만 private pilot로 간다.
5. **bounded patient-DP pilot:** 기존 M2 trainer에 연결하되 formal release가 아니라 RESEARCH_ONLY로
   실행한다. secure RNG 등록 전 release claim은 계속 차단한다.

다음 중 하나면 주방법을 중단한다.

- public matched baseline보다 set metric 개선이 없거나 single-image quality가 실질적으로 악화
- consistency 개선이 duplicate/copy collapse로 설명됨
- patient-DP에서 SetAdapter gradient가 clipping에 거의 항상 걸려 utility 이점 소실
- exact 선행이 `patient-level DP + joint image-set generation`을 이미 실질적으로 점유
- NIH만으로 얻은 효과가 ISIC 또는 비의료 entity set에서 재현되지 않음

## 13. 현재 허용되는 문장

> PSPD는 현재 가장 합당한 CVPR 연구 가설이다. 관련 문헌의 교집합이 비교적 비어 있고,
> low-multiplicity 반복 X-ray의 데이터 전제와 Q=2 구조 실행 가능성은 독립 public gates에서
> 확인됐다. 그러나 아직 matched generation 또는 DP utility 결과가 없어 “방법이 성공했다”나
> “CVPR-ready”라고 말할 단계는 아니다.
